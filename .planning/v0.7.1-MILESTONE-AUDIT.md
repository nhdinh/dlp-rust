### Unsatisfied Requirements

#### AUDIT-05: AGENT-UNKNOWN Remediation
- **Phase:** 38.3
- **Issue:** The `agent_unknown_app()` sentinel function exists in `dlp-common/src/endpoint.rs` and `skip_serializing_if` was removed from `AuditEvent` app identity fields. However, the audit emission path (`audit_emitter.rs`) never replaces `None` with `Some(agent_unknown_app())`. Audit events from file interception will have `source_application: null` and `destination_application: null` in the JSON output.
- **Fix:** In `audit_emitter.rs::emit_audit()`, replace `None` with `Some(agent_unknown_app())` for both fields before calling `EMITTER.emit()`.

### Partial Requirements

#### USB-06: Per-User Device Registry
- **Phase:** 38.4
- **PnP/DACL path:** Fully wired. `apply_tier_enforcement` resolves current process SID and calls `trust_tier_for_with_sid` with `cmp::min` merge logic.
- **I/O-path gap:** `UsbEnforcer::check()` passes `None` for the SID parameter to `trust_tier_for_with_sid`, always falling back to machine-wide entries. This creates inconsistency between the PnP enforcement on device arrival and the defense-in-depth I/O check.
- **Audit gap:** `owner_sid`/`owner_user` from `TrustTierResult` are not propagated to `UsbBlockResult` or the audit event in `interception/mod.rs`.
- **Fix:** (1) Pass `get_current_process_sid()` into `UsbEnforcer::check`. (2) Add `owner_sid`/`owner_user` to `UsbBlockResult` and propagate to audit event.

#### OP-04: Graceful Service Shutdown
- **Phase:** 38.6
- **Wired:** File monitor, event loop, heartbeats, config poll, registry poll, disk enum cancellation, device watcher, DACL restore, PnP re-enable, audit flush.
- **Gap:** `spawn_encryption_check_task` (encryption.rs line 659) is spawned fire-and-forget with no shutdown signal. The task's `tokio::time::interval` loop continues during shutdown and is only dropped by the 2s runtime timeout, potentially leaving WMI COM resources in an undefined state.
- **Fix:** Store the `JoinHandle`, add a `watch::Receiver<bool>` parameter to `spawn_encryption_check_task`, and await/cancel it in the shutdown sequence.
