<objective>
Add Audit-mode suppression guards to the three bypass alert emission paths in BypassCorrelator: handle_etw_event (efficiency — skips correlation), submit_bypass_alert (defense in depth for hook IPC), and emit_alert (final safety net). Add unit tests covering Audit suppression, Block/AuditAndBlock allowance, and backward-compatible default config.

Purpose: Close the MODE-01 gap identified in v0.10.0 milestone audit (INT-WARN-02). In Audit global mode, the hook DLL returns ALLOW for all operations, so the absence of a hook journal is expected behavior — not a bypass. Without this fix, the correlator emits false-positive NoHookJournal alerts in monitoring mode.
Output: Guarded alert emission paths + 4+ unit tests verifying suppression behavior per mode.
</objective>
