## Decisions Made

- Three guards provide defense in depth: if a future code path reaches `emit_alert` directly, the safety net still suppresses
- `trace!` for per-event suppression (expected behavior in Audit mode, high volume) avoids log noise
- `debug!` once at startup makes the mode visible to operators without per-event noise
- PerPolicy mode explicitly tested as regression safety — it is the default production config and must NOT suppress
