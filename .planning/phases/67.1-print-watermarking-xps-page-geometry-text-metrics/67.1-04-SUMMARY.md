## Decisions Made

- Used `sed` for bulk replacement rather than the Edit tool because em-dash characters in the source files caused encoding mismatches with the Edit tool's string matching.
- All link conversions preserve the original reference text as plain backticks, maintaining readability while eliminating rustdoc warnings.
