**DirectWrite COM font metrics with internal ComGuard RAII, XPS page geometry streaming parser, and bottom-right watermark placement math with iterative ellipsis truncation**

## Accomplishments

- XPS page geometry extraction via streaming XML parse of FixedPage Width/Height attributes
- FontMetrics trait with Send + Sync bounds for thread-safe measurement abstraction
- TestFontMetrics deterministic stub returning per-character widths for CI testing
- DirectWriteFontMetrics production implementation using windows-rs DirectWrite COM APIs
- ComGuard RAII struct for internal COM initialization with CoInitializeEx/CoUninitialize
- Arial -> Segoe UI font fallback with tracing::warn! logging
- WatermarkGeometry struct holding origin, font size, page dimensions, truncated text, padding
- Bottom-right placement computation with configurable padding (20 XPS units default)
- Iterative ellipsis truncation with O(n^2) re-measurement for bounded watermark strings
- pt_to_xps_units and dip_to_xps_units unit conversion helpers with 96 DPI documentation
- 21 unit tests covering all functions, edge cases, Unicode handling, and COM nested-init
