## UI Changes

### Conditions Builder — Enforcement Mode Dropdown

**Location:** Add a new row in the Conditions Builder form, positioned after the `action` row and before the existing `PolicyMode` (ALL/ANY/NONE) composition row.

**Label:** "Enforcement Mode" (left-aligned, same style as other form labels)

**Widget:** `ratatui::widgets::List` or custom dropdown (same pattern as existing `PolicyMode` dropdown)

**Values:**
| Display | Internal Value | Description |
|---------|---------------|-------------|
| `Audit` | `Audit` | Log violations but allow the operation |
| `Block` | `Block` | Deny violations (default, backward compatible) |
| `AuditAndBlock` | `AuditAndBlock` | Both log and deny violations |

**Interaction:**
- Focus: highlighted with `Color::Cyan` background (same as other focused fields)
- Selection: `Enter` or `Space` to open dropdown; arrow keys to navigate; `Enter` to confirm
- Esc: closes dropdown without changing selection

**Default:** `Block` (backward compatible with v0.9.0 policies)

**Global Override Indicator:**
When `global_enforcement_mode` is not `PerPolicy`, display a banner note below the dropdown:
- Text: `"Global override active: {global_mode}"` (e.g., "Global override active: Audit")
- Style: `Color::Yellow` (warning) with BOLD modifier
- This prevents operator confusion when per-policy mode is overridden system-wide

- Dropdown follows existing keyboard navigation pattern (Tab/Shift-Tab to move focus, arrows to select)
- Global override banner uses `Color::Yellow` (warning semantic) to draw attention without being alarming
- All three mode values are single-line text, no truncation on standard 80-column terminal
