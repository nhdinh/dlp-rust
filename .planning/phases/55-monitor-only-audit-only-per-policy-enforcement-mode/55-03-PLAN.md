<objective>
Wire the agent to parse enforcement mode config, compute effective mode in the hook IPC handler, and emit enriched audit events.

Purpose: The agent is the bridge between the server-side policy and the hook DLL. It must apply the same effective mode computation as the server so the hook DLL receives consistent decisions. This plan makes the agent mode-aware.
Output: Agent config has [enforcement] section, IPC handler computes effective mode, audit events carry policy_mode and would_have_denied.
</objective>
