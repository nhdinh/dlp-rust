<objective>
Wire the effective enforcement mode into the server-side ABAC evaluator, admin API payloads, and alert router severity logic.

Purpose: The server is the source of truth for policy evaluation. Every agent and TUI consumer depends on the server computing the same effective mode. This plan makes the server mode-aware.
Output: PolicyStore evaluates with effective mode, admin API round-trips enforcement_mode, alert router suppresses Audit-mode alerts.
</objective>

       Log the change via `tracing::info!` with the old and new values.

    The endpoint accepts and returns the `EnforcementMode` enum (not a raw `String`). Serde serializes it as a PascalCase string (e.g., `"Audit"`, `"Block"`, `"PerPolicy"`) via the existing `#[serde(rename_all = "PascalCase")]` on the enum.
