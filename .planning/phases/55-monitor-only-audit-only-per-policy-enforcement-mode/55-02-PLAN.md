<objective>
Wire the effective enforcement mode into the server-side ABAC evaluator, admin API payloads, and alert router severity logic.

Purpose: The server is the source of truth for policy evaluation. Every agent and TUI consumer depends on the server computing the same effective mode. This plan makes the server mode-aware.
Output: PolicyStore evaluates with effective mode, admin API round-trips enforcement_mode, alert router suppresses Audit-mode alerts.
</objective>

  <action>
    Extend `deserialize_policy_row()` to parse `enforcement_mode` from the DB row string:
    - Match lowercase against "audit" -> EnforcementMode::Audit, "block" -> Block, "auditandblock" -> AuditAndBlock
    - Defensive fallback to Block for unrecognized values (log a warning via tracing::warn!)
    - Add `enforcement_mode` to the `Policy` construction

    Modify `evaluate()` to compute effective mode:
    - Read `global_enforcement_mode` from `system_kv` table (key = "global_enforcement_mode", default "PerPolicy")
    - Parse global mode: "Audit" -> EnforcementMode::Audit, "Block" -> Block, "PerPolicy" -> use policy's mode
    - When a policy matches conditions, compute `effective_mode = if global_mode != "PerPolicy" { global parsed mode } else { policy.enforcement_mode }`
    - Compute `(decision, would_have_denied)` based on effective_mode:
      - Audit: (Decision::ALLOW, policy.action.is_denied())
      - Block: (policy.action, false)
      - AuditAndBlock: (policy.action, false)
    - Return enriched `EvaluateResponse` with `decision`, `matched_policy_id`, `reason` (include mode in reason string), `enforcement_mode: Some(effective_mode)`, `would_have_denied`
    - Default-deny fallback returns `EvaluateResponse::default_deny()` with `enforcement_mode: None` and `would_have_denied: false`

    Add unit tests:
    - `test_evaluate_audit_mode_allows_but_would_have_denied` — policy with DENY action in Audit mode returns ALLOW + would_have_denied=true
    - `test_evaluate_block_mode_denies` — policy with DENY action in Block mode returns DENY + would_have_denied=false
    - `test_evaluate_auditandblock_mode_denies` — policy with DENY action in AuditAndBlock returns DENY + would_have_denied=false
    - `test_evaluate_global_override_audit` — global_mode=Audit forces Audit even for Block policy
    - `test_evaluate_global_override_block` — global_mode=Block forces Block even for Audit policy
  </action>
  <verify>

  </verify>
