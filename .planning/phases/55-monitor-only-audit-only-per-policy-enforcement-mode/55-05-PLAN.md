<objective>
Ensure the alert routing and SIEM relay correctly handle Audit-mode events: alert router downgrades severity, SIEM relay forwards unchanged, and bypass alerts remain independent.

Purpose: Operators deploying in monitor mode must not receive pager alerts for policy violations that are intentionally allowed. The SIEM still receives full telemetry for tuning. Bypass alerts (real security events) are unaffected.
Output: Alert router suppresses Audit-mode alerts to info severity; SIEM relay unchanged; bypass alert severity independent.
</objective>

    - `test_send_alert_auditandblock_mode_no_downgrade` — event_type=Alert, policy_mode=Some("AuditAndBlock"), severity=crit -> remains crit
    - `test_send_alert_access_event_no_downgrade` — event_type=Access, policy_mode=Some("Audit"), severity=crit -> remains crit (only Alert events are downgraded)
    - `test_send_alert_none_policy_mode_no_downgrade` — event_type=Alert, policy_mode=None, severity=crit -> remains crit (defensive fallback)
