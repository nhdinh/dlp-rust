<objective>
Make the DACL tripwire mode-aware at the global level: when global_mode is Audit, skip ALL Deny ACEs and remove existing ones. When global_mode is Block or PerPolicy, apply Deny ACEs to all protected paths as before.

Purpose: Without this, Audit mode would still block at the kernel level via NTFS DACL, making monitor mode useless. Per-policy tripwire filtering is architecturally infeasible (protected_paths has no FK to policies, policies match via dynamic conditions). Global-mode-only filtering satisfies D-01 for the common case without scope creep.
Output: Tripwire reads global_mode and skips Deny ACEs when Audit; repair watcher mirrors this; existing ACEs are removed on Audit transition.
</objective>
