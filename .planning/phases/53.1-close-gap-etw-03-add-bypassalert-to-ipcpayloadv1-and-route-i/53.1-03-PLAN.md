## Phase 53.1 — Plan 03: Wrap BypassAlert in IpcEnvelope in Hook DLL

**Objective:** Update `dlp-hook-dll/src/ntdll_patcher.rs::emit_bypass_alert` to wrap the `BypassAlert` in `IpcEnvelope::V1(IpcPayloadV1::BypassAlert(...))` before serialization, and replace the response-waiting helper with a true one-way helper. Add a pure helper for testability.

**Purpose:** The hook DLL currently sends raw `BypassAlert` bytes without the versioned envelope. The agent's updated `handle_connection` (Plan 02) expects `IpcEnvelope`, so raw bytes would fail deserialization and be silently dropped. Additionally, the current `send_raw_request` waits for a response, which can deadlock with the agent (per REVIEW-H-02). This plan closes the emission side of INT-BLOCK-01. Per D-04 (Hook DLL Emission decision).

**Output:** `dlp-hook-dll/src/ntdll_patcher.rs` with envelope-wrapped emission via a pure helper; `dlp-hook-dll/src/pipe_client.rs` with a true one-way helper; passing unit tests.
