## Phase 53.1 — Plan 02: Route BypassAlert in Agent IPC Handler to BypassCorrelator

**Objective:** Update the agent's pipe server to deserialize `IpcEnvelope` and route `BypassAlert` payloads to the bypass correlator via a channel, while keeping `HookRequest` on the existing ABAC path.

**Purpose:** Closes the INT-BLOCK-01 gap where hook-emitted bypass alerts are silently dropped because the agent deserializes every frame as `HookRequest`. Per D-02 (Agent Routing decision) and D-03 (BypassCorrelator entry point decision).

**Output:** `dlp-agent/src/hook_ipc.rs` with envelope deserialization and payload routing; `dlp-agent/src/bypass_correlator.rs` with `submit_bypass_alert`; channel wiring in `service.rs`.
