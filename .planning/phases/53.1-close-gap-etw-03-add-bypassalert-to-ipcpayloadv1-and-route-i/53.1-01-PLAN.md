## Phase 53.1 — Plan 01: Extend IpcPayloadV1 with BypassAlert Variant

**Objective:** Add `BypassAlert(BypassAlert)` to `IpcPayloadV1` in `dlp-common/src/hook_ipc.rs` so the IPC protocol can carry hook-derived bypass alerts.

**Purpose:** This is the foundational type change that unblocks the entire gap closure. Without this variant, the hook DLL cannot send bypass alerts through the existing pipe, and the agent cannot deserialize them. Per D-01 (IPC Protocol decision in CONTEXT.md).

**Output:** `dlp-common/src/hook_ipc.rs` with the new variant and a passing round-trip unit test.
