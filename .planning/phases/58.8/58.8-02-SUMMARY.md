- Added integration tests covering auth failures, invalid hash, agent_id mismatch, successful ingest, and admin health response shapes.

## Decisions Made

- Followed the existing `DiagnosticSnapshotStore` pattern for the new `HealthSnapshotStore` to keep bounded in-memory stores consistent.
- Chose `tower-governor` per-agent rate limiting keyed by authenticated identity, falling back to path segment and IP, matching the existing rate-limiter design.
- Validated the configured agent auth hash synchronously inside `spawn_blocking` to avoid blocking the tokio reactor on SQLite reads.
- Returned `AppError::Internal` (HTTP 500) when snapshot stores are missing in POST handlers, satisfying the plan requirement that missing stores are server errors, not client errors.
