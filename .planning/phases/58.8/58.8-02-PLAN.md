<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent -> server POST /agents/{id}/health | Public telemetry endpoint; per-agent rate limit prevents abuse. No agent JWT middleware exists today. |
| admin TUI -> server GET /admin/health | Admin JWT required; health data is operational, not PII. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58.8-05 | Spoofing | POST /agents/{id}/health agent_id claim | accept | Ingest is best-effort telemetry; no sensitive action taken. Future phases may add agent JWT. Document the public nature in code comments. |
| T-58.8-06 | Denial of Service | Agent flooding health endpoint | mitigate | `per_agent_config()` rate limiter caps each agent_id to 200 requests per 60 seconds. |
| T-58.8-07 | Information Disclosure | Health snapshots stored on disk | mitigate | `HealthSnapshotStore` is in-memory only (`DashMap` + `VecDeque`); no disk persistence. |
| T-58.8-08 | Tampering | Admin health response manipulated | accept | Response is computed from in-memory store at request time; protected by TLS in transit and admin JWT. |
| T-58.8-SC | Tampering | npm/pip/cargo installs | mitigate | No new external packages required; all dependencies already locked. |
</threat_model>
