<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hook DLL -> agent override request | Untrusted user process sends override intent; agent treats it as unauthenticated user intent. |
| user UI -> agent Pipe1UiMsg::UserConfirmed | Justification crosses process boundary; must be validated before server submission. |
| agent -> server POST /agents/{id}/health | Agent-authenticated telemetry endpoint. |
| agent -> server POST /agents/{id}/diagnostics | Agent-authenticated diagnostic ingest endpoint. |
| admin TUI -> server GET /admin/health | Admin JWT required; health data is operational, not PII. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58.8-01 | Tampering | hook DLL override request payload | accept | Request contains only user identity/path/action; server approval workflow verifies authorization before grant. |
| T-58.8-02 | Denial of Service | repeated DENY operations flooding UI | mitigate | 30-second per-path cooldown in Plan 58.8-01 limits UI spam. |
| T-58.8-03 | Information Disclosure | override request content in logs | mitigate | Log only request_id and resource_path at info level; full request details at debug only per CLAUDE.md 9.13. |
| T-58.8-04 | Elevation of Privilege | fire-and-forget bypassing ABAC | accept | Original operation remains denied; approval only helps future operations via HookResponse.approval_override. |
| T-58.8-09 | Denial of Service | Agent health push interval too aggressive | mitigate | 60-second interval and per-agent rate limiting on the server cap push volume. |
| T-58.8-10 | Information Disclosure | HookHealthSnapshot over HTTP | accept | Health snapshots contain operational counters, not PII; transport is TLS in production. |
| T-58.8-11 | Repudiation | Agent submits forged health snapshot | mitigate | Agent auth hash required; spoofing requires knowledge of the configured hash. |
| T-58.8-SC | Tampering | npm/pip/cargo installs | mitigate | No new external packages required; all dependencies already locked. |
</threat_model>
