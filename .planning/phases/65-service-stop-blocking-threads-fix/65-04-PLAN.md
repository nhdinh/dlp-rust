Current initiate_stop() spawns a thread with the body directly:
```rust
std::thread::spawn(move || {
    debug_log("=== initiate_stop START ===");
    // ... spawn UI, poll file, verify password ...
});
```

If any operation panics (e.g., bcrypt::verify on malformed hash), the thread dies
and STOP_CONFIRMED is never set. The 120s timeout would normally call abort_stop(),
but if the panic happens in the same thread, the timeout never fires either.

The fix: wrap the entire thread body in catch_unwind:
```rust
std::thread::spawn(move || {
    let result = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
        // ... existing thread body ...
    }));
    if let Err(e) = result {
        error!(panic = ?e, "password_stop thread panicked — aborting stop");
        abort_stop();
    }
});
```

Note: AssertUnwindSafe is needed because the closure captures request_id and
response_path (String) which are Send but the closure itself may not be UnwindSafe
due to the file operations. Since we're not sharing state across catch_unwind
boundaries, AssertUnwindSafe is correct.

For the PowerShell script:
- Current Stop-DlpAgentService uses `Stop-Service -Force` which is ineffective in StopPending

- Need to check if the service process is still running after Stop-Service reports "success"
- Provide actionable error: "Service is stuck in StopPending. Use psexec -s taskkill /F /IM dlp-agent.exe or restart the machine."

    function Stop-DlpAgentService {
        $svc = Get-Service -Name $ServiceName -ErrorAction SilentlyContinue
        if (-not $svc) {
            Write-Host "Service $ServiceName not found." -ForegroundColor Yellow
            return
        }

        if ($svc.Status -eq 'StopPending') {
            Write-Host "Service is already stopping (StopPending)." -ForegroundColor Yellow
            Write-Host "If it remains stuck, use: psexec -s taskkill /F /IM dlp-agent.exe" -ForegroundColor Cyan
            Write-Host "Or restart the machine." -ForegroundColor Cyan
            return
        }

        if ($svc.Status -eq 'Stopped') {
            Write-Host "Service is already stopped." -ForegroundColor Green
            return
        }

        try {
            Stop-Service -Name $ServiceName -Force -ErrorAction Stop
            Write-Host "Stop command sent. Waiting for service to stop..." -ForegroundColor Cyan

            # Wait up to 30 seconds for the service to actually stop
            $stopped = $svc.WaitForStatus('Stopped', [TimeSpan]::FromSeconds(30))
            if ($svc.Status -eq 'Stopped') {
                Write-Host "Service stopped successfully." -ForegroundColor Green
            } else {
                Write-Host "Service did not stop within 30 seconds — it may be stuck in StopPending." -ForegroundColor Red
                Write-Host "Recovery options:" -ForegroundColor Yellow
                Write-Host "  1. Restart the machine (guaranteed)" -ForegroundColor Cyan
                Write-Host "  2. Run from SYSTEM context: psexec -s taskkill /F /IM dlp-agent.exe" -ForegroundColor Cyan
                Write-Host "  3. Then re-register: sc.exe delete $ServiceName; .\Manage-DlpAgentService.ps1 -Action Install" -ForegroundColor Cyan
            }
        } catch {
            Write-Error "Failed to stop service: $_"
        }
    }
