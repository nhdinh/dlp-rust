<objective>
Add shutdown signal polling to the Chrome pipe server, health monitor, and session monitor. Each subsystem checks `crate::service::shutdown_requested()` and breaks its loop or drops its runtime to allow clean thread termination.

CRITICAL REVIEW FIXES:
- Chrome: Same pipe-handle-close pattern as IPC pipes (Plan 65-02) to unblock ConnectNamedPipeW
- Health monitor: Use tokio::select! with a shutdown-aware sleep instead of pure interval.tick() to bound shutdown latency
- Session monitor: Check shutdown flag before tick to avoid waiting a full interval
- All subsystems: Log confirmation at task exit for shutdown diagnostics
</objective>

Chrome handler (dlp-agent/src/chrome/handler.rs):
- Has `accept_loop` similar to IPC pipes, using `ConnectNamedPipeW`
- Blocks on `ConnectNamedPipeW` between client connections
- Pattern: same as IPC pipes — check shutdown flag before ConnectNamedPipe, close handle on exit

Health monitor (dlp-agent/src/health_monitor.rs):
- Runs a tokio current-thread runtime inside a std::thread
- `run()` calls `rt.block_on(async { tokio::join!(ping_task, pong_task, timeout_task) })`
- The tasks run in an infinite loop (`loop { interval.tick().await }`)
- Review concern: shutdown latency is unpredictable because tasks tick at different intervals
- Fix: Replace pure interval.tick() with tokio::select! between interval.tick() and a short sleep that checks shutdown

Session monitor (dlp-agent/src/session_monitor.rs):
- `session_loop` is an async function with `tokio::time::interval(POLL_INTERVAL)` (2s)
- It polls `WTSEnumerateSessionsW` every 2 seconds
- Review concern: WTSEnumerateSessionsW can block on DC timeout; check shutdown BEFORE tick
- Fix: Check shutdown_requested() before interval.tick() so we don't wait up to 2s

Review feedback incorporated:
- Codex HIGH: Chrome needs same unblock mechanism as IPC pipes
- Codex MEDIUM-HIGH: Health monitor timing unpredictable; use select! or pre-tick check
- OpenCode MEDIUM-HIGH: Health monitor block_on can hang if task doesn't check signal promptly
- OpenCode MEDIUM: Session monitor edge case with WTS DC timeout
- Both reviewers: Add tracing at task exit for shutdown confirmation
