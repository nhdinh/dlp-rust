Chrome handler (dlp-agent/src/chrome/handler.rs):
- Has `accept_loop` similar to IPC pipes, using `ConnectNamedPipeW`
- Blocks on `ConnectNamedPipeW` between client connections
- Pattern: same as IPC pipes — check shutdown flag before ConnectNamedPipe

Health monitor (dlp-agent/src/health_monitor.rs):
- Runs a tokio current-thread runtime inside a std::thread
- `run()` calls `rt.block_on(async { tokio::join!(ping_task, pong_task, timeout_task) })`
- The tasks run in an infinite loop (`loop { interval.tick().await }`)
- To shut down: need to break the loops OR drop the runtime
- Since the runtime is local to the thread, dropping it from inside is tricky
- Better approach: add shutdown check in each task's loop, using tokio::select!
  with a shutdown future that completes when shutdown_requested() is true

Session monitor (dlp-agent/src/session_monitor.rs):
- `session_loop` is an async function with `tokio::time::interval(POLL_INTERVAL)`
- It polls `WTSEnumerateSessionsW` every 2 seconds
- Simple approach: check shutdown_requested() at top of loop before tick
- Or use tokio::select! with a shutdown check

        let mut interval = tokio::time::interval(PING_INTERVAL);
        loop {
            interval.tick().await;

                break;

    For `pong_task`: the `rx.recv().await` will return None when the channel closes.
    We also need a way to close the channel. Add a shutdown check as an alternative

    ```rust
    loop {
        tokio::select! {
            biased;
            _ = tokio::time::sleep(Duration::from_millis(500)) => {
                if crate::service::shutdown_requested() {
                    break;
                }
            }
            Some(event) = rx.recv() => {
                // ... existing handling ...
            }
            else => break,
        }
    }
    ```

    Actually, the simplest approach: check shutdown in the pong_task loop body:
    ```rust
    loop {
        if crate::service::shutdown_requested() {
            break;
        }
        match rx.recv().await {
            // ...
        }
    }
    ```

    For `timeout_task`: similar check in the loop.

    When all three tasks exit, `tokio::join!` completes, `rt.block_on` returns,
    `run()` returns, and the std::thread exits naturally.
