# Decisions Made

- **Manual validation over regex**: dlp-server validation uses char-by-char checks instead of regex crate to avoid adding a dependency. Fingerprint: `starts_with("v1:") && len==67 && all lowercase hex`. MAC: `len==12 && all uppercase hex`.
- **DeviceHealth mapped to DeviceTrust in admin TUI**: `ConditionAttribute` enum doesn't have `DeviceHealth`. The condition_to_prefill and condition_display functions map `DeviceHealth` to `DeviceTrust` as a placeholder. Full TUI integration is out of scope for this phase.
- **All Subject literals get `device_health: DeviceHealthStatus::default()`**: Cross-crate backward compatibility achieved by adding the field with `#[serde(default)]` and Default derive.
