## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent -> Server HTTP | Heartbeat payload crosses network; HTTPS encrypts in transit |
| Server DB | SQLite stores device identity; access controlled by pool |
| Server validation | MAC and fingerprint format validation before persistence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-64-07 | Tampering | Heartbeat payload tampered in transit | mitigate | HTTPS TLS encryption; server validates field formats |
| T-64-08 | Information Disclosure | MAC addresses stored in SQLite | accept | MACs are not secrets; DB is server-local |
| T-64-09 | Denial of Service | Large mac_addresses JSON floods DB | mitigate | MAC list is bounded by physical NIC count (typically < 20); TEXT column has no practical limit but data is bounded |
| T-64-10 | Elevation of Privilege | Agent sends arbitrary health_status | mitigate | Health status is agent-reported telemetry; policy decisions use it as one signal among many |
| T-64-11 | Spoofing | Agent sends malformed MAC/fingerprint | mitigate | Server-side validation rejects invalid formats; graceful degradation to defaults |
</threat_model>
