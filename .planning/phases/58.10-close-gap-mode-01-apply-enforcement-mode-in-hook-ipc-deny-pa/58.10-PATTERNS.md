```rust
    &self,
    classification: Classification,
    op: HookOp,
) -> Option<crate::fail_closed::DenyReturn> {
    match (classification, op) {
        (Classification::T3 | Classification::T4, HookOp::Write) => {

        }
        (Classification::T1 | Classification::T2, _) => None,

}
```

**New `global_mode()` accessor — add to the `CacheView` impl** (pattern from RESEARCH Pattern 3; read `_reserved[0]`, default unrecognized → Block fail-closed per ASVS V5):
```rust
impl CacheView {
    /// Read the global enforcement mode byte from the header (_reserved[0]).
    /// Defaults to Block (0) for any unrecognized value (fail-closed).
    pub fn global_mode(&self) -> u8 {
        let b = unsafe { (*self.header)._reserved[0] };
        match b {
            1 => 1, // Audit
            2 => 2, // AuditAndBlock
            3 => 3, // PerPolicy
            _ => 0, // Block (default / fail-closed)
        }
    }
}
```

**Reuse guidance:**
- `CacheView.header` is `pub(crate)` (line 148) — trampolines can read it directly, but prefer the `global_mode()` accessor to keep the byte-offset/encoding in one place.

- Do NOT touch `compute_checksum` (lines 264-286) — it already folds `_reserved` in via `chunks_exact(8)` (lines 279-284). The mode byte is integrity-protected with no checksum change.

**New global-Audit skip** (pattern from RESEARCH Pattern 3 — on global Audit, do NOT return; fall through to the pipe so the agent applies the mode + emits the parity audit):
```rust
if let Some(classification) = cache_classification {
    classification_source = ClassificationSource::CacheHit;
    // NEW: under global Audit, skip the autonomous T3/T4 write-deny and
    // fall through to the pipe so the agent applies the mode + emits audit.
    let global_audit = cache_lookup.map(|c| c.global_mode() == 1).unwrap_or(false);

        if let Some(deny) = cache_lookup.and_then(|c| c.decide(classification, op)) {

        return None;
```

**Reuse guidance:**
- Apply the SAME skip at the DEGRADED cache-hit branch (lines 614-625, the `decide()` call at line 621).

- DEGRADED pipe throttle (A3): under global Audit, force the pipe attempt regardless of `should_retry_pipe()`'s every-10th-call throttle so the agent (not the DLL) makes the mode-aware decision. Surface to user during planning.
- `decide_isolated`/`decide_degraded` (`fail_mode.rs:409,441`) STAY fail-closed even under global Audit (A1) — when the pipe is DOWN no parity audit can be emitted, so relaxing them would ALLOW writes with no audit trail (violates D-07). Document as an explicit limitation.

```rust
pub fn compute_effective_mode(
    global_mode: EnforcementMode,
    policy_mode: EnforcementMode,
) -> EnforcementMode {
    if global_mode != EnforcementMode::PerPolicy {
        global_mode
    } else {
        policy_mode
    }
}
```
