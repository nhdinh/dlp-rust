<objective>
Close the agent-side half of gap MODE-01: make the hook IPC decision closure in `service.rs` enforcement-mode-aware so that under a global Audit override an Audit DENY from `offline_decision` is flipped to ALLOW and a full-parity audit is emitted — satisfying Phase 55 Success Criterion #2 on the hook path, not just the interception path.

Purpose: The hook IPC closure (`service.rs:2187`) currently returns `offline.offline_decision(&evaluate_req)` verbatim, ignoring enforcement mode. This is the cache-miss pipe path. The reference implementation (`interception/mod.rs:413-465`) already computes the effective mode and flips Audit DENY -> ALLOW; this plan mirrors that exact pattern in the closure and extracts the gate into a pure, unit-testable helper.

Output: A mode-aware hook IPC closure, an extracted pure helper `apply_effective_mode_to_hook_decision`, and a `hook_ipc_mode_gate` unit-test module sampling the global {Audit,Block,PerPolicy,AuditAndBlock} x cache {hit,miss} x tier {T3/T4,T1/T2} matrix.
</objective>
