Complete the full-chain MODE-01 fix on the DLL side: make the cache-hit fast-path in `trampolines.rs` mode-aware so that under a global Audit override the autonomous T3/T4 write-deny is skipped and the operation falls through to the agent pipe (which applies the mode and emits the parity audit), and add the end-to-end integration test that proves SC#2 on the hook path.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DLL fast-path (in-process) -> agent pipe | On a global-Audit cache-hit the DLL now pipes to the agent instead of denying autonomously; the pipe is the trusted path to the ABAC authority + audit emitter. |
| shared-memory mode byte -> DLL skip decision | The DLL honors the global-mode byte (read from shared memory) to decide whether to skip the deny; a forged byte must fail closed. |
| pipe DOWN (DEGRADED/ISOLATED) | When the agent is unreachable there is no authority to apply the mode or emit the audit; relaxing the deny here would ALLOW writes with no audit trail. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58.10-09 | Repudiation | global-Audit cache-hit ALLOWs a write with no audit trail | mitigate | The skip ALWAYS falls through to the pipe so the AGENT emits the full-parity audit (D-07); the DLL never emits its own audit (centralized, DRY). Pipe-down fail-mode paths (decide_isolated/decide_degraded) stay fail-closed (A1) precisely because no audit can be emitted without the agent. |
| T-58.10-10 | Elevation of Privilege | forged/stale mode byte causes the DLL to skip the deny | mitigate | The skip is gated on `global_mode()==1` (Audit) read from a header that passed full_validation (magic + layout_version==2 + checksum). Unrecognized bytes default to Block (Plan 02). The mapping is SDDL-restricted (SYSTEM writes only) and the DLL maps read-only. Even if the byte were Audit, the fall-through still requires the agent pipe to ALLOW — the agent re-applies the mode authoritatively. |
| T-58.10-11 | Denial of Service | DEGRADED forced-pipe under global Audit adds pipe load | accept | A3 forces the pipe attempt in DEGRADED under global Audit (bypassing the every-10th-call throttle) so the agent makes the mode-aware decision. This adds pipe load only in the (global Audit AND DEGRADED) intersection, which is an operator-chosen audit configuration during a degraded window; the alternative (9/10 hits denied by decide_degraded) would break SC#2. Accepted as a deliberate tradeoff; documented at the skip site. |
| T-58.10-12 | Tampering | e2e test harness trusts a mock that bypasses the real closure | mitigate | The Task-2 test asserts the DLL-visible HookResponse through the real mode-aware closure path (not a mock that short-circuits the gate); a Block-mode control test proves the DENY path is intact, so a no-op gate would fail the control. |
| T-58.10-SC | Tampering | cargo installs | accept | No new packages this phase (in-tree crates only); Package Legitimacy Gate trivially satisfied per RESEARCH. |
