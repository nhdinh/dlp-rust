# Phase 58.1 Plan 02: BypassCorrelator bypass_rx Routing Summary

**One-liner:** Wired `HookIpcServer` to forward `IpcPayloadV1::BypassAlert` alerts from the hook DLL over the named pipe into a bounded crossbeam channel, consumed by `BypassCorrelator::run()` via a dedicated `spawn_blocking` task that enriches and batches each alert for eventual `BypassAlertRepository::insert_batch` flush, with full integration test coverage for routing, audit-mode suppression, batch boundaries, retry batch_id semantics, and graceful channel close.
