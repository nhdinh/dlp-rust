# Plan 58.1-04: OPS-04 UAT Execution Handoff Script

**Goal:** Produce a self-contained, executable PowerShell script and markdown companion that a human operator can run on a physical Windows 11 host to execute all 36 UAT scenarios from `.planning/milestones/v0.10.0-UAT.md`, with exact CRIT-04 benchmark protocol, artifact capture automation, and pass/fail recording.

**Requirement:** SC-58.1-04 (derived from ROADMAP success criterion 4: OPS-04 UAT executes on physical Windows 11 hardware and results are recorded)

**Depends on:** Phase 57 (UAT test plan exists in `.planning/milestones/v0.10.0-UAT.md`), Phase 55 (monitor mode exists), Phase 56 (volume-class ABAC exists)

---

## Threat Model

| Threat | STRIDE | Mitigation |
|--------|--------|------------|
| Fabricated UAT results | Tampering | D-14: actual execution is deferred to a human operator; Claude cannot operate physical devices; script produces no fabricated evidence |
| Incomplete scenario coverage | Information Disclosure | Script contains all 36 scenarios from v0.10.0-UAT.md; companion markdown has checklist preventing omission |
| CRIT-04 benchmark protocol error | Tampering (detection) | Script encodes the exact `Measure-Command` protocol with warm-up runs, median computation, and overhead formula |
| Missing artifact capture | Information Disclosure | Script auto-creates artifact directories and timestamps filenames per UAT naming convention |

**ASVS Level:** 1 (operational documentation)
**Blocking threshold:** None — this is a handoff artifact, not executable code that affects runtime security.

### Task 1: Create UAT execution PowerShell script

<read_first>
- .planning/milestones/v0.10.0-UAT.md (all 36 scenarios, artifact naming convention, CRIT-04 protocol)

- .planning/phases/58.1-close-v0-10-0-ship-gap-verification-items/58.1-PATTERNS.md (PowerShell scenario pattern, Measure-Command pattern)
</read_first>

<action>
Create `scripts/Uat-Execute-v0.10.0.ps1` — a self-contained PowerShell script that:
1. **Preamble**: Requires `-RunAsAdministrator`, validates Windows 11 OS, checks for `dlp-agent` service, validates `signtool.exe` in PATH, creates `C:\UAT\v0.10.0\` artifact directory tree with subdirectories per category (A-J).
2. **Environment capture**: Auto-fills the Environment table from v0.10.0-UAT.md by querying OS build, CPU, RAM, disk, EDR processes, cloud client versions, DLP agent version. Outputs to `C:\UAT\v0.10.0\environment.json`.
3. **Scenario execution functions**: One function per category (A-J), each containing the exact PowerShell steps from v0.10.0-UAT.md. Each function:
   - Prints the scenario ID and description
   - Executes the prerequisite checks
   - Runs the steps
   - Prompts the operator for Pass/Fail/N/A with a `Read-Host` dialog
   - Captures the operator's notes
   - Auto-captures agent log snippet (last 100 lines) to `C:\UAT\v0.10.0\{category}\{scenario_id}_agent.log`
   - Records timestamp and result to `C:\UAT\v0.10.0\results.json`
4. **CRIT-04 benchmark automation**: `Invoke-Crit04Benchmark` function that:
   - Runs the warm-up protocol (cargo clean + cargo build --workspace --release, discarded)
   - Runs 3 baseline runs (agent stopped) with `Measure-Command`
   - Runs 3 with-hooks runs (agent started, 30s wait)
   - Computes median for each set
   - Calculates overhead: `((median_with - median_baseline) / median_baseline) * 100`
   - Records raw values, medians, and overhead to `C:\UAT\v0.10.0\crit04_results.json`
   - Uses the `Invoke-CargoBuildCommand` helper pattern from the quick task "fix-uat-benchmark-warmup" (avoids `$ErrorActionPreference = 'Stop'` treating cargo stderr as terminating error)
5. **Artifact naming**: All auto-captured files follow the convention `UAT-57-{CATEGORY}{NN}_{artifact_type}_{YYYYMMDD_HHMMSS}.ext`.
6. **Results summary**: After all scenarios, generates `C:\UAT\v0.10.0\UAT-Summary.md` with:
   - Total scenarios, passed, failed, N/A counts
   - Blocking failures list
   - CRIT-04 results
   - Known limitations (auto-populated from N/A entries)
   - Ship/No-Ship recommendation based on the decision matrix from 57-VERIFICATION.md
7. **Error handling**: Every function uses `try/catch` with `Write-Error` and continues to the next scenario (no hard stop on failure).
8. **N/A protocol**: If a peripheral is absent, the operator marks N/A and the script auto-populates the justification field with the operator's input.

The script must be executable from an elevated PowerShell with a single command: `& "C:\UAT\v0.10.0\Uat-Execute-v0.10.0.ps1"`. Include a `-WhatIf` parameter that prints all scenario IDs and descriptions without executing anything.
</action>

<acceptance_criteria>
- `scripts/Uat-Execute-v0.10.0.ps1` exists and is valid PowerShell 5.1+ syntax
- Script contains all 36 scenario IDs from v0.10.0-UAT.md (A01-A04, B01-B06, C01-C04, D01-D02, E01-E05, F01-F03, G01-G02, H01-H03, I01-I02, J01-J05)
- Script has `-RunAsAdministrator` requirement check at start
- Script auto-creates `C:\UAT\v0.10.0\` directory tree with category subfolders
- Script auto-captures environment data (OS build, CPU, RAM, EDR processes, cloud client versions)
- Script implements `Invoke-Crit04Benchmark` with warm-up, 3 baseline + 3 with-hooks runs, median computation, overhead formula
- Script uses `Invoke-CargoBuildCommand` helper (not `$ErrorActionPreference = 'Stop'` for cargo)
- Script prompts operator for Pass/Fail/N/A per scenario
- Script auto-captures agent log snippets per scenario
- Script generates `results.json`, `crit04_results.json`, and `UAT-Summary.md`
- Script has `-WhatIf` parameter for dry-run listing
- Script handles errors with try/catch and continues
</acceptance_criteria>

<action>
Create `.planning/milestones/v0.10.0-UAT-EXECUTION.md` — a markdown companion to the PowerShell script that:
1. **Prerequisites section**: Lists hardware, software, and account prerequisites with checkboxes. Includes: Windows 11 Pro/Enterprise, admin rights, PowerShell 5.1+, Windows SDK (for signtool), Rust toolchain (for CRIT-04), physical peripherals (USB, SD, optical, printer), cloud clients (OneDrive, Google Drive, Dropbox, Box), DLP v0.10.0 installed and signed.
2. **Pre-flight checklist**: Step-by-step instructions to prepare the host: stop all non-essential processes, verify agent service status, verify EDR allowlist, verify policy bundle, create test directories (`C:\Protected\Test\`, `C:\Temp\`), create T1/T2/T4 test files.
3. **Script execution guide**: How to run the PowerShell script, what to expect at each prompt, how to handle N/A scenarios, how to capture manual screenshots (for scenarios requiring UI interaction like admin TUI).
4. **Manual screenshot guide**: For scenarios that require UI interaction (admin TUI, Process Hacker, EDR console), provides exact UI navigation steps and expected screenshots. These are the scenarios the script cannot auto-capture:
   - A01: Process Hacker showing injected DLL
   - A02: Process Hacker showing allowlisted process modules
   - A03: Process Hacker showing x86 DLL in 32-bit process
   - E01-E04: Windows Explorer / Device Manager screenshots
   - F01: icacls output
   - G01: Process Hacker unload screenshot, Notepad save dialog
   - H01-H03: Admin TUI screenshots (policy mode dropdown)
   - J01: signtool verify output
   - J02: EDR console screenshot
   - J04: Confirm-SecureBootUEFI output
5. **CRIT-04 protocol**: Repeats the exact benchmark protocol from the script with additional guidance: close all other applications, ensure no Windows Updates running, use SSD for consistent disk I/O, run each category in isolation with reboots between categories.
6. **Artifact upload guide**: Instructions for packaging `C:\UAT\v0.10.0\` into a zip file and uploading to the milestone audit location.
7. **Ship decision worksheet**: A fillable markdown table where the operator records the final ship/no-ship decision, severity tier breakdown, and sign-off fields (Engineering Lead, QA Lead, Date).
8. **Troubleshooting section**: Common issues and resolutions: agent service not starting, hook not injecting, EDR quarantine, missing peripherals, benchmark variance.

The document must be self-contained: an operator who has never seen the DLP codebase should be able to execute UAT using only this document and the PowerShell script.
</action>
