  <name>Task 1: Refactor UniversalInjector to use ProcessClassifier</name>
  <files>dlp-agent/src/universal_injector.rs</files>
  <behavior>
    - Test: In `ClassificationMode::Universal`, a process event results in injection.
    - Test: In `ClassificationMode::Targeted`, a high-confidence process event results in injection.
    - Test: In `ClassificationMode::Targeted`, a low-confidence process event records `Skipped(LowConfidence)` and does not queue a retry.
    - Test: In `ClassificationMode::Monitor`, no injection occurs; registry records `SkipMonitoring` or `Skipped(LowConfidence)`.
    - Test: Allowlisted/PPL events still skip before reaching the classifier.
    - Test: Injection failures still queue a retry with +200ms delay.
  </behavior>
  <action>
    Modify `dlp-agent/src/universal_injector.rs`.

    1. Add `use crate::process_classifier::{ClassificationDecision, ProcessClassifier};`.

    2. Extend `UniversalInjector` with an optional classifier:
       - Add field `classifier: Option<Arc<ProcessClassifier>>`.
       - Add `with_classifier` constructor or update `new`/`with_retry_queue` to accept it.
       - Keep backward compatibility: tests using `UniversalInjector::new` should still compile. Provide a default no-classifier behavior that behaves as `ClassificationMode::Universal` (inject all).

    3. Refactor `handle_event`:
       - Keep atomic claim, canonical image path, and allowlist/PPL pre-checks exactly as they are.
       - After pre-checks, if a classifier is configured:
         - Call `classifier.classify(key, event.pid, &event.image_path, &self.matcher)`.
         - If `ClassificationDecision::SkipAllowlisted(reason)` or `SkipMonitoring`, record skipped and return.
         - If `ClassificationDecision::SkipLowConfidence`, record `Skipped(SkipReason::LowConfidence)` and return (do NOT queue retry — lazy injection handles it).
         - If `ClassificationDecision::InjectImmediately { .. }`, proceed to injection.
       - If no classifier is configured, proceed to injection as before.

    4. Update `LatencyHistogram` recording to include classification time optionally (log a `tracing::debug!` with `classification_reason`).

    5. Update existing tests to pass a classifier where needed, or rely on the no-classifier default. Add new tests for the behaviors above.
  </action>
  <verify>
    <automated>cargo test -p dlp-agent universal_injector</automated>
  </verify>
  <done>`cargo test -p dlp-agent universal_injector` passes; classification gate behavior verified.</done>
