Integrate the classifier and lazy injector into the live service path, replace the concrete `HookInjector` dependency with a trait seam, fix the broken retry semantics, and broadcast ETW Kernel-File events through an explicit fanout so both the bypass correlator and the lazy injector receive every event.

Purpose: This is the main blast-radius plan identified in `58.6-REVIEWS.md`. It turns the new components into an operational subsystem while preserving the Phase 49 universal baseline and closing the work-sharing receiver bug.
Output: `UniversalInjector` refactored around `InjectProcess` and `ProcessClassifier`, `service.rs` wired with ETW fanout and lazy injection, and `ProcessRegistry` retry semantics fixed.
</objective>

  <behavior>
    - Test: A `ClassificationMode::Universal` event injects immediately (backward-compatible baseline).
    - Test: A `ClassificationMode::Targeted` event with `InjectImmediately` injects and records `Injected { injection_path: Immediate }`.
    - Test: A `ClassificationMode::Targeted` event with `SkipLowConfidence` records `Skipped(LowConfidence)` and does not queue a retry.
    - Test: A `ClassificationMode::Monitor` event records `Skipped(Monitoring)` and never injects.
    - Test: `SkipAllowlisted` records the matching skip reason without injection.
    - Test: A retryable first failure records `PendingRetry` and queues a retry; the retry task reclaims the key, injects successfully, and records `Injected`.
    - Test: A retryable second failure records `Skipped(Failed(...))` and does not queue another retry.
    - Test: Creation-time mismatch immediately before `inject` records `Skipped(Failed(Timeout))`.
  </behavior>
  <action>
    Refactor `dlp-agent/src/universal_injector.rs` around a single `classify_and_inject` helper and fix the retry path so failed PIDs are no longer marked processed before retry.

    1. Extend `UniversalInjector`:
       - Add `classifier: Option<Arc<ProcessClassifier>>`.
       - Add `with_classifier(self, classifier: Arc<ProcessClassifier>) -> Self` so service.rs can attach it after construction.

    2. Add `pub async fn classify_and_inject(
         &self,
         key: ProcessKey,
         pid: u32,
         image_path: &str,
         source: EventSource,
         event_timestamp: Option<Instant>,
         is_retry: bool,
         _sweep_trigger: Option<&mpsc::Sender<SweepTrigger>>,
       )`:
       - Determine the classification decision:
         - If `self.classifier` is `Some`, call `classifier.classify(key, pid, image_path, &self.matcher)`. The classifier already runs allowlist/PPL checks, so do not duplicate them.
         - If `self.classifier` is `None`, treat the decision as `InjectImmediately(UniversalMode)` and keep the legacy allowlist/PPL pre-check.
       - For `InjectImmediately`:
         - Re-query `get_process_creation_time(pid)`; if it does not match `key.creation_time`, record `Skipped(Failed(InjectionFailure::Timeout))` and return.
         - Call `self.injector.inject(pid)`.
         - On success, record `record_injected(key, "x64".into())` (the extended `record_injected` defaults to `InjectionPath::Immediate`).
         - If `event_timestamp` is `Some`, record latency in the histogram.
         - On failure, categorize with `categorize_error`:
           - `AccessDenied` -> record `Skipped(Ppl(LikelyProtectedAccessDenied))`.
           - `Timeout` -> record `Skipped(Failed(Timeout))`.
           - `RemoteThreadFailed` / `InjectionFailed`:
             - If `is_retry`, record `Skipped(Failed(failure))`.
             - Else, record `PendingRetry` via `self.registry.record_pending_retry(key)` and queue the retry with a 200 ms delay.
       - For `SkipLowConfidence`, `SkipMonitoring`, and `SkipAllowlisted(reason)`, record the corresponding `Skipped` state and return.

    3. Update `handle_event` to call `classify_and_inject(key, event.pid, &event.image_path, event.source, Some(event.event_timestamp), false, Some(sweep_trigger)).await`.

    4. Update `handle_retry` to call `classify_and_inject` with `is_retry: true` and `event_timestamp: None`.

    In `dlp-agent/src/process_registry.rs`:
    - Add `Monitoring` to `SkipReason`.
    - In `try_claim`, treat an existing `ProcessState::PendingRetry` entry as claimable: transition it to `Discovered`, bump the sequence number, and return `ClaimResult::Claimed`.
    - Update `counts()` and `skipped_by_reason()` to count `SkipReason::Monitoring`.
    - Ensure `record_pending_retry` (added in Plan 01) inserts `ProcessState::PendingRetry`.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service orchestrator -> Injection subsystems | Mis-wiring must not disable existing allowlist/PPL checks or create duplicate injection paths |
| ETW Kernel-File fanout -> Consumers | Every consumer must see the same event stream; work-sharing clones would split events |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58.6-15 | Tampering | `ClassificationMode::Targeted` bypasses allowlist | mitigate | `ProcessClassifier` runs `AllowlistMatcher::check` and PPL detection before any immediate-injection signal; `UniversalInjector` defers to the classifier for these checks. |
| T-58.6-16 | Denial of Service | Two ETW receivers race or split events | mitigate | Replace `Receiver::clone()` work-sharing with an explicit fanout thread that clones each event into independent channels for the bypass correlator and lazy injector. |
| T-58.6-17 | Elevation of Privilege | Lazy injector spawned without classification cache | mitigate | `LazyInjector::run` checks `classification_cache.is_some()` and returns immediately if absent; service.rs only constructs it when the cache and lazy config are present. |
| T-58.6-R1 | Tampering | Retry queue cannot reclaim failed PIDs | mitigate | `ProcessRegistry::try_claim` treats `PendingRetry` as claimable; `UniversalInjector` records `PendingRetry` instead of `Skipped(Failed)` on first retryable failure. |
</threat_model>
