  <action>
    Create `dlp-agent/src/process_classifier.rs`.

    1. **`ClassificationDecision` enum** (derive Debug, Clone, PartialEq, Eq):
       - `InjectImmediately { reason: ImmediateReason }` where `ImmediateReason` is one of `UniversalMode`, `PeScore`, `KnownFileHandler`, `CommandLineIndicator`.
       - `SkipLowConfidence` — process is not known to handle files; eligible for lazy injection.
       - `SkipAllowlisted(SkipReason)` — existing allowlist/PPL/WoW64/system-critical skip.
       - `SkipMonitoring` — `ClassificationMode::Monitor` is active.

    2. **`ProcessClassifier` struct**:
       - Fields:
         - `mode: ClassificationMode`
         - `scanner: PeImportScanner`
         - `cli_reader: CommandLineReader`
         - `cache: DashMap<ProcessKey, (ClassificationDecision, Instant)>` (or `Arc<Mutex<...>>`)
         - `cache_ttl: Duration`
         - `universal_injector_style_skip: bool` — if true, treat `ClassificationMode::Universal` as inject-all.
       - `new(config: &AgentConfig, scanner: PeImportScanner, cli_reader: CommandLineReader) -> Self`.
       - `pub fn classify(&self, key: ProcessKey, pid: u32, image_path: &str, matcher: &AllowlistMatcher) -> ClassificationDecision`:
         - Return cached decision if present and not expired.
         - **Step 1 — Existing exclusions** (reuse logic from `UniversalInjector::handle_event`):
           - Canonicalize `image_path`.
           - If `matcher.check(pid, canonical, key.creation_time)` returns a category, return `SkipAllowlisted(SkipReason::from_category(category))`.
           - Call `detect_ppl(pid)`. If `Protected` or `LikelyProtectedAccessDenied`, return `SkipAllowlisted(SkipReason::Ppl(...))`. If `QueryFailed`, log `warn!` and continue (fail-closed on coverage: attempt injection).
         - **Step 2 — Mode gate**:
           - If `mode == ClassificationMode::Universal`, return `InjectImmediately(UniversalMode)`.
           - If `mode == ClassificationMode::Monitor`, return `SkipMonitoring`.
         - **Step 3 — Targeted signals**:
           - If `scanner.is_file_operation_likely(Path::new(image_path))`, return `InjectImmediately(PeScore)`.
           - If `cli_reader.classify(pid, image_path) == FileHandler`, return `InjectImmediately(KnownFileHandler)`.
         - **Step 4 — Fallback**:
           - Return `SkipLowConfidence`.
       - Cache the final decision before returning.

    3. **Helper re-exports**: Re-use `detect_ppl` from `dlp-agent/src/universal_injector.rs` (it is already `pub`). Do not duplicate the implementation.

    4. **Non-Windows stub**: `classify` returns `SkipLowConfidence` for all non-allowlisted PIDs.

    5. **Tests**: Add unit tests for every behavior listed. Mock `AllowlistMatcher`, `PeImportScanner`, and `CommandLineReader` by accepting trait objects or by constructing them with test configs. Prefer concrete structs with configurable test data over traits unless the code becomes unwieldy.
