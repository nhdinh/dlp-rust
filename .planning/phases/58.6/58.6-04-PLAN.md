       - `InjectImmediately { reason: ImmediateReason }`
       - `SkipLowConfidence` — process is not known to handle files; eligible for lazy injection.
       - `SkipAllowlisted(SkipReason)` — existing allowlist/PPL/system-critical skip.

    3. **`ProcessClassifier` struct**:
       - Fields:
         - `mode: ClassificationMode`
         - `pe_source: Arc<dyn PeScoreSource>`
         - `cli_source: Arc<dyn CliSignalSource>`
         - `cache: DashMap<(ProcessKey, i64), (ClassificationDecision, Instant)>` (review concern: cache key includes `allowlist_version` from `AgentConfig`).
         - `cache_ttl: Duration`
         - `max_cache_entries: usize` (default 10,000)
         - `pe_threshold: u32`
         - `fallback_universal_sweep: bool`
         - `allowlist_version: i64`
       - `new(config: &AgentConfig, pe_source: Arc<dyn PeScoreSource>, cli_source: Arc<dyn CliSignalSource>) -> Self`.
       - `pub fn classify(&self, key: ProcessKey, pid: u32, image_path: &str, matcher: &AllowlistMatcher) -> ClassificationDecision`:
         - Return cached decision if present, not expired, and cached with the current `allowlist_version`.
         - **Step 1 — Existing exclusions** (reuse logic from `UniversalInjector::handle_event`):
           - Canonicalize `image_path` via `crate::allowlist::canonicalize_path`.
           - If `matcher.check(pid, canonical, key.creation_time)` returns a category, return `SkipAllowlisted(SkipReason::from_category(category))`.
           - Call `detect_ppl(pid)` from `dlp-agent/src/universal_injector.rs` (already `pub`). If `Protected` or `LikelyProtectedAccessDenied`, return `SkipAllowlisted(SkipReason::Ppl(...))`. If `QueryFailed`, log `warn!` and continue (fail-closed on coverage: attempt injection).
         - **Step 2 — Mode gate**:
           - If `mode == ClassificationMode::Universal`, return `InjectImmediately(UniversalMode)`.
           - If `mode == ClassificationMode::Monitor`, return `SkipMonitoring`.
         - **Step 3 — Targeted signals**:
           - Compute `pe_score = self.pe_source.score(Path::new(image_path))`.
           - If `pe_score.is_some_and(|s| s >= self.pe_threshold)`, return `InjectImmediately(PeScore)`.
           - Compute `cli = self.cli_source.classify(pid, image_path)`. If `cli.command_line_match`, return `InjectImmediately(CommandLineIndicator)`.
           - If `cli.basename_match`, log `debug!` that a known basename was seen but is not sufficient alone.
         - **Step 4 — Fallback**:
           - If `self.fallback_universal_sweep`, return `InjectImmediately(UniversalFallback)`.
           - Otherwise return `SkipLowConfidence`.
         - Cache the final decision keyed by `(key, self.allowlist_version)` before returning.
         - If the cache exceeds `max_cache_entries`, prune expired entries first; if still over limit, remove the oldest inserted entry.

    4. **Non-Windows stub**: `classify` returns `SkipLowConfidence` for all inputs; does not reference `AllowlistMatcher`.

    5. **Tests**: Add unit tests for every behavior listed. Use mock implementations of `PeScoreSource` and `CliSignalSource` (simple structs with configurable return values) so tests do not need real PEs or PEB reads.
