  <action>
    Add a new `TargetedInjectionConfig` struct and a `ClassificationMode` enum to `dlp-agent/src/config.rs`.

    - `ClassificationMode` variants (derive Debug, Clone, Copy, PartialEq, Eq, serde::Serialize, serde::Deserialize, Default):
      - `Universal` — inject every non-allowlisted user process (Phase 49 behavior, default per Research open question Q1). Mark with `#[default]`.
      - `Targeted` — inject only processes classified as file-operation likely; lazy-inject the rest on first T3/T4 ETW event.
      - `Monitor` — classify and emit telemetry but do not inject (safe evaluation mode).

    - `TargetedInjectionConfig` fields (derive Debug, Clone, Serialize, Deserialize, PartialEq, Default):
      - `mode: ClassificationMode` (default `ClassificationMode::Universal`).
      - `pe_import_threshold: u32` (default `3`).
      - `pe_max_scan_bytes: u64` (default `16_777_216`) — maximum bytes to read for PE import scanning.
      - `enable_lazy_injection: bool` (default `true`).
      - `fallback_universal_sweep: bool` (default `false`) — when true, low-confidence or un-scannable processes are still injected rather than skipped.
      - `known_file_handler_basenames: Vec<String>` (default built-in list: `["winword.exe", "excel.exe", "powerpnt.exe", "outlook.exe", "acrord32.exe", "msedge.exe", "chrome.exe", "firefox.exe", "notepad.exe", "wordpad.exe"]`).
      - `command_line_path_indicators: Vec<String>` (default `["*.docx", "*.xlsx", "*.pptx", "*.pdf", "*.txt", "C:\\Data\\*", "C:\\Confidential\\*"]`).
      - `classification_cache_ttl_secs: u64` (default `300`).
      - `lazy_injection_rate_limit_ms: u64` (default `1000`).

    Add `pub targeted_injection: TargetedInjectionConfig` to `AgentConfig` with `#[serde(default)]`.

    Update the two manual `AgentConfig` struct literals in `config.rs` tests (around lines 710 and 760) to include `targeted_injection: TargetedInjectionConfig::default()`.

    Add unit tests covering:
    - Default mode is `Universal`.
    - TOML round-trip for a fully populated `[targeted_injection]` section.
    - Unknown keys are ignored via `serde_ignored` (existing behavior).
    - Backward compatibility: an `AgentConfig` TOML without `[targeted_injection]` parses and yields defaults.
    - `save()` serializes the new section (review concern: old TOML saves back with defaults).
