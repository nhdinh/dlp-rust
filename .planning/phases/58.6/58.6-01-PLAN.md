<task type="auto">
  <name>Task 2: Add TargetedInjectionConfig and ClassificationMode to config.rs</name>
  <files>dlp-agent/src/config.rs</files>
  <action>
    Add a new `TargetedInjectionConfig` struct and a `ClassificationMode` enum to `dlp-agent/src/config.rs`.

    - `ClassificationMode` variants (derive Debug, Clone, Copy, PartialEq, Eq, serde::Serialize, serde::Deserialize, Default):
      - `Universal` — inject every non-allowlisted user process (Phase 49 behavior, default per Research open question Q1).
      - `Targeted` — inject only processes classified as file-operation likely; lazy-inject the rest on first T3/T4 ETW event.
      - `Monitor` — classify and emit telemetry but do not inject (safe evaluation mode).

    - `TargetedInjectionConfig` fields (derive Debug, Clone, Serialize, Deserialize, PartialEq, Default):
      - `mode: ClassificationMode` (default `ClassificationMode::Universal`).
      - `pe_import_threshold: u32` (default `3`) — minimum file-I/O score from `pe_import_scanner` to trigger immediate injection.
      - `enable_lazy_injection: bool` (default `true`) — whether ETW Kernel-File T3/T4 events trigger on-demand injection for skipped processes.
      - `fallback_universal_sweep: bool` (default `false`) — if true, periodic backstop sweep still injects all remaining non-allowlisted processes.
      - `known_file_handler_basenames: Vec&lt;String&gt;` (default built-in list from Research A1: winword.exe, excel.exe, powerpnt.exe, outlook.exe, msedge.exe, chrome.exe, firefox.exe, opera.exe, brave.exe, notepad.exe, notepad++.exe, explorer.exe, 7z.exe, 7zfm.exe, winrar.exe, code.exe, code-insiders.exe, cursor.exe, windsurf.exe, traesetup.exe, slack.exe, teams.exe, zoom.exe, acrobat.exe, acrord32.exe, onedrive.exe, googledrivesync.exe, dropbox.exe, box.exe).
      - `command_line_path_indicators: Vec&lt;String&gt;` (default `["*.docx", "*.xlsx", "*.pptx", "*.pdf", "*.txt", "C:\\Data\\*", "C:\\Confidential\\*"]`).
      - `classification_cache_ttl_secs: u64` (default `300`) — TTL for the in-memory PE-import classification cache.
      - `lazy_injection_rate_limit_ms: u64` (default `1000`) — minimum interval between lazy injection attempts for the same PID.

    Add `pub targeted_injection: TargetedInjectionConfig` to `AgentConfig` with `#[serde(default)]`.

    Add unit tests covering:
    - Default mode is `Universal`.
    - TOML round-trip for a fully populated `[targeted_injection]` section.
    - Unknown keys are ignored via `serde_ignored` (existing behavior).
    - Backward compatibility: an `AgentConfig` TOML without `[targeted_injection]` parses and yields defaults.
  </action>

  <action>
    Extend the process lifecycle model in `dlp-agent/src/process_registry.rs` so telemetry can distinguish targeted-injection outcomes.

    - Add `LowConfidence` to `SkipReason` — process passed allowlist/PPL checks but the classifier decided it was not file-operation likely.
    - Extend `ProcessState::Injected` payload to include an optional `injection_path: InjectionPath` enum with variants `Immediate` and `Lazy`.
      - Preserve backward compatibility by defaulting new entries to `Immediate` in existing call sites (`record_injected` keeps its current signature and passes `InjectionPath::Immediate`).
    - Add `record_lazy_injected(key: ProcessKey, arch: String)` which calls `record_injected_with_path(key, arch, InjectionPath::Lazy)`.
    - Update `ProcessCounts` to track:
      - `classified_injected: u64` — processes injected immediately because the classifier scored them file-operation likely.
      - `lazy_injected: u64` — processes injected lazily via ETW Kernel-File.
      - `skipped_low_confidence: u64` — processes skipped by the classifier.
    - Update `counts()` and `skipped_by_reason()` to populate the new counters.
    - Add unit tests for `record_lazy_injected`, `record_skipped(..., SkipReason::LowConfidence)`, and the updated counts.
