<objective>
Implement the static PE import-table classifier that scores how likely a process is to perform file operations, with caching to avoid re-parsing the same executable repeatedly.

Purpose: Static analysis of the on-disk image provides the primary signal for immediate injection decisions and is harder to evade than basename matching alone.
Output: `dlp-agent/src/pe_import_scanner.rs` with `PeImportScanner`, `file_io_score`, and a TTL-backed `ImportCache`.
</objective>

  <behavior>
    - Test: `file_io_score(image importing kernel32.dll + CreateFileW)` exceeds `pe_import_threshold` because specific API symbols are weighted.
    - Test: `file_io_score(image only importing user32.dll and gdi32.dll)` is below `pe_import_threshold`.
    - Test: `file_io_score(image with ntdll.dll imports NtCreateFile, NtOpenFile, NtWriteFile)` gets a ntdll syscall bonus.
    - Test: `PeImportScanner::score(image_path)` returns a cache hit on the second call with the same path and does not re-read the file.
    - Test: `score` returns 0 for a non-existent or malformed PE file and logs a warning.
    - Test: `score` returns a non-zero result for a PE file whose size exceeds `pe_max_scan_bytes` (the scanner reads only up to the cap).
  </behavior>
  <action>
    Create `dlp-agent/src/pe_import_scanner.rs`.

    1. **Constants**:
       - `FILE_IO_DLLS: &[&str]` matching Research Pattern 1: `kernel32.dll`, `kernelbase.dll`, `shell32.dll`, `shlwapi.dll`, `ntdll.dll`, `advapi32.dll`, `ole32.dll`, `comdlg32.dll`.
       - `FILE_IO_APIS: &[&str]` = specific file-operation APIs such as `CreateFileW`, `CreateFileA`, `WriteFile`, `WriteFileEx`, `ReadFile`, `ReadFileEx`, `SetFilePointer`, `SetFilePointerEx`, `MoveFileExW`, `CopyFileExW`, `DeleteFileW`, `ReplaceFileW`, `SetFileInformationByHandle`, `GetFileAttributesW`, `FindFirstFileW`.
       - `NTDLL_FILE_SYSCALLS: &[&str]` = `["NtCreateFile", "NtOpenFile", "NtWriteFile", "NtSetInformationFile"]`.

    2. **`file_io_score(image_bytes: &[u8]) -> anyhow::Result<u32>`**:
       - Parse with `goblin::pe::PE::parse(image_bytes)?`.
       - Iterate `pe.imports.unwrap_or_default()`.
       - For each import whose `dll` (lowercased) is in `FILE_IO_DLLS`, add `1`.
       - If the DLL is `ntdll.dll`, iterate its symbols and add `2` for each symbol whose name starts with any entry in `NTDLL_FILE_SYSCALLS` (case-insensitive).
       - For symbols in any `FILE_IO_DLLS` whose name starts with any entry in `FILE_IO_APIS`, add `3`.
       - Return the total score.

    3. **`ImportCache`**: A thread-safe cache keyed by `u64` hash of the canonical image path (use `dlp_common::path_hash::fnv1a_64`). Store `(score, cached_at: Instant)`.
       - Use `DashMap<u64, CacheEntry>` (the project already depends on `dashmap`).
       - Provide `new(ttl: Duration)` and `get_or_insert(path: &Path, loader: F) -> u32`.

    4. **`PeImportScanner`**:
       - Fields: `cache: ImportCache`, `threshold: u32`, `cache_ttl: Duration`, `max_scan_bytes: usize`.
       - `new(config: &TargetedInjectionConfig) -> Self`.
       - Implement the `PeScoreSource` trait defined in Plan 04 (or define it here and re-export):
         - `pub fn score(&self, image_path: &Path) -> u32`:
           - Canonicalize via `crate::allowlist::canonicalize_path` before hashing.
           - On cache hit and not expired, return cached score.
           - On cache miss, read the file with `std::fs::read` capped at `max_scan_bytes`. If the file is larger than the cap, read only the first `max_scan_bytes` bytes and attempt to parse that slice; do not reject the file outright.
           - Call `file_io_score`, store in cache, return score. On any error, log `warn!` and return 0.
       - `pub fn is_file_operation_likely(&self, image_path: &Path) -> bool`: returns `score >= threshold`.

    5. **Non-Windows stub**: Provide `PeImportScanner::new` and `score` stubs that always return 0 so CI on Linux/macOS compiles.

    6. **Tests**: Add `#[cfg(test)] mod tests` with the behaviors listed above. Use small synthetic PE bytes where possible; for real-file tests, use `C:\Windows\System32\notepad.exe` only when running on Windows and skip gracefully if not available.
  </action>
