<task type="auto" tdd="true">
  <name>Task 2: Implement PeImportScanner and ImportCache</name>
  <files>dlp-agent/src/pe_import_scanner.rs</files>
  <behavior>
    - Test: `file_io_score(kernel32+shell32+ntdll imports) >= pe_import_threshold`.
    - Test: `file_io_score(no_file_dlls) < pe_import_threshold` where the image only imports `user32.dll` and `gdi32.dll`.
    - Test: `PeImportScanner::score(image_path)` returns a cache hit on the second call with the same path and does not re-read the file.
    - Test: `score` returns 0 for a non-existent or malformed PE file and logs a warning.
    - Test: `ntdll.dll` imports of `NtCreateFile`, `NtOpenFile`, and `NtWriteFile` add bonus points.
  </behavior>
  <action>
    Create `dlp-agent/src/pe_import_scanner.rs`.

    1. **Constants**: Define `FILE_IO_DLLS: &[&str]` matching Research Pattern 1:
       `kernel32.dll`, `kernelbase.dll`, `shell32.dll`, `shlwapi.dll`, `ntdll.dll`, `advapi32.dll`, `ole32.dll`, `comdlg32.dll`.
       Define `NTDLL_FILE_SYSCALLS: &[&str]` = `["NtCreateFile", "NtOpenFile", "NtWriteFile", "NtSetInformationFile"]`.

    2. **`file_io_score(image_bytes: &[u8]) -> anyhow::Result<u32>`**:
       - Parse with `goblin::pe::PE::parse(image_bytes)?`.
       - Iterate `pe.imports.unwrap_or_default()`.
       - For each import whose `dll` (lowercased) is in `FILE_IO_DLLS`, add `1`.
       - If the DLL is `ntdll.dll`, iterate its symbols (flattening nested iterators) and add `2` for each symbol whose name starts with any entry in `NTDLL_FILE_SYSCALLS` (case-insensitive).
       - Return the total score.

    3. **`ImportCache`**: A thread-safe cache keyed by `u64` hash of the canonical image path (use `dlp_common::path_hash::fnv1a_64` or `std::collections::hash_map::DefaultHasher` if not available; prefer `sha2` only if already imported). Store `(score, cached_at: Instant)`.
       - Use `DashMap<u64, CacheEntry>` or `Arc<Mutex<HashMap<...>>>` — prefer `DashMap` because the project already depends on it.
       - Provide `new(ttl: Duration)` and `get_or_insert(path: &Path, loader: F) -> u32`.

    4. **`PeImportScanner`**:
       - Fields: `cache: ImportCache`, `threshold: u32`, `cache_ttl: Duration`.
       - `new(config: &TargetedInjectionConfig) -> Self`.
       - `pub fn score(&self, image_path: &Path) -> u32`:
         - Canonicalize via `crate::allowlist::canonicalize_path` before hashing.
         - On cache hit and not expired, return cached score.
         - On cache miss, read the file with `std::fs::read(image_path)` capped at a reasonable maximum (16 MiB) to avoid mapping huge executables; if larger, log `warn!` and return 0.
         - Call `file_io_score`, store in cache, return score. On any error, log `warn!` and return 0.
       - `pub fn is_file_operation_likely(&self, image_path: &Path) -> bool`: returns `score >= threshold`.

    5. **Non-Windows stub**: Provide `PeImportScanner::new` and `score` stubs that always return 0 so CI on Linux/macOS compiles.

    6. **Tests**: Add `#[cfg(test)] mod tests` with the behaviors listed above. Use small synthetic PE bytes where possible; for real-file tests, use `C:\Windows\System32\notepad.exe` only when running on Windows and skip gracefully if not available.
  </action>
