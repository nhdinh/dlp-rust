## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| On-disk executable -> Agent parser | Malformed or attacker-controlled PE file must not crash the agent |
| Cache writer -> Cache reader | Normalization divergence would cause false bypass alerts or incorrect tier decisions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58.6-03 | Denial of Service | `file_io_score` parser | mitigate | Use `goblin` (approved crate) instead of hand-rolled parser; cap file read at `pe_max_scan_bytes`; catch errors and return `None`. |
| T-58.6-04 | Tampering | Cache key collision | mitigate | Hash canonicalized and normalized path; collisions only affect score caching, not injection allowlist decisions. |
| T-58.6-05 | Elevation of Privilege | Reading malicious PE | accept | Scanner reads file bytes only; no execution, no memory mapping of untrusted code. |
| T-58.6-R2 | Tampering | Path-hash mismatch with classification cache | mitigate | Writer uses `dlp_common::path_hash::normalize_path` then `fnv1a_64`; reader uses `path_hash` which applies the same normalization. Documented by code comment. |
</threat_model>
