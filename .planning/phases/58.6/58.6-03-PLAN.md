  <behavior>
    - Test: `remote_command_line(current_pid)` returns a non-empty string on Windows for the current process.
    - Test: `basename_classifier("winword.exe", config)` returns `FileHandler`.
    - Test: `basename_classifier("totally_unknown.exe", config)` returns `Unknown`.
    - Test: `command_line_classifier("C:\\Program Files\\App\\app.exe C:\\Data\\secret.docx", config)` returns `FileHandler` because `*.docx` is in indicators.
    - Test: `command_line_classifier("C:\\Windows\\System32\\svchost.exe -k netsvcs", config)` returns `Unknown`.
    - Test: `CommandLineReader::classify(pid, image_path, config)` combines signals and treats PEB-read failure as `Unknown` (not an error).
  </behavior>
  <action>
    Create `dlp-agent/src/command_line_reader.rs`.

    1. **`BaselineClassification` enum** (derive Debug, Clone, Copy, PartialEq, Eq):
       - `FileHandler` — basename or command line strongly suggests file operations.
       - `Unknown` — no strong signal.

    2. **`remote_command_line(pid: u32) -> anyhow::Result<String>`** (Windows only):
       - Open the process with `PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_VM_READ`.
       - Call `NtQueryInformationProcess(handle, ProcessBasicInformation, &mut pbi, ...)` to obtain `PebBaseAddress`.
       - Read the PEB structure with `ReadProcessMemory` to obtain `ProcessParameters`.
       - Read the `RTL_USER_PROCESS_PARAMETERS` structure to obtain `CommandLine` (`UNICODE_STRING`).
       - Read the `CommandLine.Buffer` into a `Vec<u8>` of length `CommandLine.Length` and decode as UTF-16LE.
       - Return the decoded string.
       - On any `AccessDenied` or read failure, return the error; callers must treat this as "unknown command line".
       - Use descriptive `tracing::warn!` for unexpected failures.

    3. **`basename_classifier(image_path: &str, basenames: &[String]) -> BaselineClassification`**:
       - Extract the basename (case-insensitive).
       - If it matches any entry in `basenames` (case-insensitive), return `FileHandler`; else `Unknown`.

    4. **`command_line_classifier(command_line: &str, indicators: &[String]) -> BaselineClassification`**:
       - For each indicator:
         - If it starts with `*.`, treat as extension match (e.g., `.docx` anywhere in command line).
         - Otherwise treat as glob via `glob::Pattern` (project already depends on `glob`).
       - Return `FileHandler` on first match; else `Unknown`.

    5. **`CommandLineReader`**:
       - Fields: `basenames: Vec<String>`, `indicators: Vec<String>`.
       - `new(config: &TargetedInjectionConfig) -> Self` copies `known_file_handler_basenames` and `command_line_path_indicators`.
       - `pub fn classify(&self, pid: u32, image_path: &str) -> BaselineClassification`:
         - First check basename; if `FileHandler`, return immediately.
         - Then attempt `remote_command_line(pid)`; on success, run `command_line_classifier`.
         - On `AccessDenied` or any error, log `tracing::debug!` (not error — PPL failure is expected) and return `Unknown`.

    6. **Non-Windows stub**: All functions return `Unknown` or an error indicating unsupported platform.

    7. **Tests**: Add unit tests for all behaviors listed above. For `remote_command_line`, test against `std::process::id()` on Windows and skip on non-Windows.
  </action>
