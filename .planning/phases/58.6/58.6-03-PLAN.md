<objective>
Implement the secondary classifier signal: read the target process command line from its PEB and match basenames/command-line content against curated lists of file-handling applications and path indicators.

Purpose: Many modern apps dynamically load file APIs or have sparse import tables; basename and command-line heuristics catch them before they touch T3/T4 data. Splitting the two signals lets Plan 04 require stronger evidence than basename alone.
Output: `dlp-agent/src/command_line_reader.rs` with `CommandLineReader`, `remote_command_line`, and `CliClassification`.
</objective>

    - Test: `basename_classifier("winword.exe", config)` returns `true` for basename_match.
    - Test: `basename_classifier("totally_unknown.exe", config)` returns `false`.
    - Test: Tokenized `command_line_classifier` for `C:\Program Files\App\app.exe C:\Data\secret.docx` returns `true` for command_line_match because `*.docx` matches a token.
    - Test: Tokenized `command_line_classifier` for `C:\Windows\System32\svchost.exe -k netsvcs` returns `false`.
    - Test: `CommandLineReader::classify(pid, image_path, config)` returns a `CliClassification` where basename_match and command_line_match are reported independently.
    - Test: `CommandLineReader::classify` treats PEB-read failure as `CliClassification::unknown()` (not an error).
  </behavior>
  <action>
    Create `dlp-agent/src/command_line_reader.rs`.

    1. **`CliClassification` struct** (derive Debug, Clone, Copy, PartialEq, Eq):
       - `basename_match: bool`
       - `command_line_match: bool`
       - `pub fn unknown() -> Self` returns both false.
       - `pub fn is_file_operation_likely(&self) -> bool` returns `self.command_line_match` (basename alone is intentionally not enough).

    2. **`remote_command_line(pid: u32) -> anyhow::Result<String>`** (Windows only):
       - Open the process with `PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_VM_READ`.
       - Call `NtQueryInformationProcess(handle, ProcessBasicInformation, &mut pbi, ...)` to obtain `PebBaseAddress`.
       - Read the PEB structure with `ReadProcessMemory` to obtain `ProcessParameters`.
       - Read the `RTL_USER_PROCESS_PARAMETERS` structure to obtain `CommandLine` (`UNICODE_STRING`).
       - Read the `CommandLine.Buffer` into a `Vec<u8>` of length `CommandLine.Length` and decode as UTF-16LE.
       - Cap the read length at 32 KiB; if the command line is longer, truncate and return the prefix.
       - Return the decoded string.
       - On any `AccessDenied` or read failure, return the error; callers must treat this as "unknown command line".
       - Use descriptive `tracing::warn!` for unexpected failures.

    3. **`basename_classifier(image_path: &str, basenames: &[String]) -> bool`**:
       - Extract the basename (case-insensitive).
       - Return `true` if it matches any entry in `basenames` (case-insensitive).

    4. **`tokenize_command_line(command_line: &str) -> Vec<&str>`**:
       - Split the command line on whitespace, respecting simple double-quoted tokens. The goal is to match indicators against individual arguments, not the full raw string.

    5. **`command_line_classifier(command_line: &str, indicators: &[String]) -> bool`**:
       - Tokenize `command_line`.
       - For each token and each indicator:
         - If the indicator starts with `*.`, treat as extension match (token ends with the extension).
         - Otherwise treat as glob via `glob::Pattern` (project already depends on `glob`) and match the token.
       - Return `true` on first match; else `false`.

    6. **`CommandLineReader`**:
       - Fields: `basenames: Vec<String>`, `indicators: Vec<String>`.
       - `new(config: &TargetedInjectionConfig) -> Self` copies `known_file_handler_basenames` and `command_line_path_indicators`.
       - Implement the `CliSignalSource` trait defined in Plan 04 (or define it here and re-export):
         - `pub fn classify(&self, pid: u32, image_path: &str) -> CliClassification`:
           - Compute `basename_match = basename_classifier(image_path, &self.basenames)`.
           - Attempt `remote_command_line(pid)`; on success, compute `command_line_match = command_line_classifier(&cmd_line, &self.indicators)`.
           - On `AccessDenied` or any error, log `tracing::debug!` (not error — PPL failure is expected) and return `CliClassification { basename_match, command_line_match: false }`.

    7. **Non-Windows stub**: All functions return `CliClassification::unknown()` or an error/empty string so cross-platform `cargo check` works.

    8. **Tests**: Add unit tests for all behaviors listed above. For `remote_command_line`, test against `std::process::id()` on Windows and skip on non-Windows.
  </action>
