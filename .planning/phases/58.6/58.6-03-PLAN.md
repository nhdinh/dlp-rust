  <action>
    Create `dlp-agent/src/command_line_reader.rs`.

    1. **`CommandLineStatus` enum** (derive Debug, Clone, PartialEq, Eq):
       - `Known(String)` — successfully read command line.
       - `AccessDenied` — PEB read denied (expected for PPL).
       - `UnsupportedArch` — target is WoW64 from a 64-bit agent; PEB layout differs.
       - `ParseError` — decoded command line is invalid or buffer read failed.

    2. **`CliClassification` struct** (derive Debug, Clone, PartialEq, Eq — review fix: do NOT derive `Copy`):
       - `basename_match: bool`
       - `command_line_match: bool`
       - `status: CommandLineStatus` (review concern: explicit status instead of collapsing all failures to booleans).
       - `pub fn unknown() -> Self` returns both false with `status: CommandLineStatus::AccessDenied`.
       - `pub fn is_file_operation_likely(&self) -> bool` returns `self.command_line_match` (basename alone is intentionally not enough).

    3. **`remote_command_line(pid: u32) -> CommandLineStatus`** (Windows only):
       - Open the process with `PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_VM_READ`.
       - Before reading the PEB, determine if the target is WoW64 when the agent is x64:
         - Call `IsWow64Process(handle, &mut is_wow64)` if the agent is x64 (`cfg(target_arch = "x86_64")`).
         - If `is_wow64` is true, return `CommandLineStatus::UnsupportedArch` and log `tracing::debug!`.
       - Call `NtQueryInformationProcess(handle, ProcessBasicInformation, &mut pbi, ...)` to obtain `PebBaseAddress`.
       - Define the exact Windows structs needed for the PEB read and verify buffer bounds before every `ReadProcessMemory` call (review fix: specify structs and bounds checks):
         - `struct PROCESS_BASIC_INFORMATION { Reserved1: [isize; 2], PebBaseAddress: *mut c_void, Reserved2: [isize; 4], UniqueProcessId: usize, Reserved3: usize }`
         - `struct UNICODE_STRING { Length: u16, MaximumLength: u16, Buffer: *mut u16 }`
         - `struct RTL_USER_PROCESS_PARAMETERS { Reserved1: [u8; 16], Reserved2: [PVOID; 10], CommandLine: UNICODE_STRING }`
         - Read the PEB structure with `ReadProcessMemory` to obtain `ProcessParameters`.
         - Read the `RTL_USER_PROCESS_PARAMETERS` structure to obtain `CommandLine` (`UNICODE_STRING`).
         - Read the `CommandLine.Buffer` into a `Vec<u8>` of length `CommandLine.Length` and decode as UTF-16LE.
       - Cap the read length at 32 KiB; if the command line is longer, truncate and return the prefix.
       - Return `CommandLineStatus::Known(decoded_string)`.
       - On `AccessDenied`, return `CommandLineStatus::AccessDenied`.
       - On any other unexpected failure, log `tracing::warn!` and return `CommandLineStatus::ParseError`.

    4. **`basename_classifier(image_path: &str, basenames: &[PathBuf]) -> bool`**:
       - Extract the basename (case-insensitive).
       - Return `true` if it matches any entry in `basenames` (case-insensitive). Store basenames as `PathBuf` to avoid locale issues.
       - Default basename list (from `TargetedInjectionConfig::known_file_handler_basenames`): `["winword.exe", "excel.exe", "powerpnt.exe", "outlook.exe", "acrord32.exe", "msedge.exe", "chrome.exe", "firefox.exe", "notepad.exe", "wordpad.exe"]`.

    5. **`tokenize_command_line(command_line: &str) -> Vec<String>`**:
       - On Windows, convert the command line to a wide string and call `CommandLineToArgvW` to obtain Windows-correct tokenization. Free the returned buffer with `LocalFree`.
       - On non-Windows, split on whitespace respecting simple double-quoted tokens as a compile/test fallback.

    6. **`command_line_classifier(command_line: &str, indicators: &[PathBuf]) -> bool`**:
       - Tokenize `command_line`.
       - For each token and each indicator:
         - If the indicator string starts with `*.`, treat as extension match (token ends with the extension, case-insensitive).
         - Otherwise treat as glob via `glob::Pattern` (project already depends on `glob`) and match the token.
       - Return `true` on first match; else `false`.

    7. **`CommandLineReader`**:
       - Fields: `basenames: Vec<PathBuf>`, `indicators: Vec<PathBuf>`.
       - `new(config: &TargetedInjectionConfig) -> Self` copies `known_file_handler_basenames` and `command_line_path_indicators` into `PathBuf`s.
       - Provide an inherent `classify` method (Plan 04 defines the `CliSignalSource` trait and implements it for `CommandLineReader`):
         - `pub fn classify(&self, pid: u32, image_path: &str) -> CliClassification`:
           - Compute `basename_match = basename_classifier(image_path, &self.basenames)`.
           - Attempt `remote_command_line(pid)`; on `Known(cmd_line)`, compute `command_line_match = command_line_classifier(&cmd_line, &self.indicators)` and return `CliClassification { basename_match, command_line_match, status: Known(cmd_line) }`.
           - On `AccessDenied`, `UnsupportedArch`, or `ParseError`, log `tracing::debug!` (not error — PPL/unsupported arch is expected) and return `CliClassification { basename_match, command_line_match: false, status }`.

    8. **Non-Windows stub**: All functions return `CliClassification::unknown()` or `CommandLineStatus::AccessDenied` so cross-platform `cargo check` works.

    9. **Tests**: Add unit tests for all behaviors listed above. For `remote_command_line`, test against `std::process::id()` on Windows and skip on non-Windows. Use `CommandLineStatus::UnsupportedArch` for the WoW64 test by injecting a mock `is_target_wow64` helper. Add a compile-time assertion that `CliClassification` does not implement `Copy`.
