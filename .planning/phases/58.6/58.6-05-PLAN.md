<objective>
Implement the on-demand injection backstop: a `LazyInjector` that listens to ETW Kernel-File events and injects processes that were skipped with low confidence but are now observed touching T3/T4 paths. Make the tier lookup testable via a `TierResolver` trait, and make the channel capacity public so service.rs can fan out events without accessing private constants.

Purpose: Closes the coverage gap left by the targeted classifier. The first T3/T4 event from a low-confidence process is intentionally logged as missed; the process is injected before subsequent events, so event-level coverage converges to the required threshold.
Output: `dlp-agent/src/lazy_injector.rs` with `LazyInjector` and `LazyInjectorConfig`, a `TierResolver` trait, and `ClassificationCache::resolve_tier`.
</objective>

  <action>
    Create `dlp-agent/src/lazy_injector.rs`.

    1. **`LazyInjectorConfig`** (derive Clone):
       - `rate_limit: Duration` (from `TargetedInjectionConfig::lazy_injection_rate_limit_ms`).
       - `enabled: bool` (from `TargetedInjectionConfig::enable_lazy_injection`).

    2. **`LazyInjector` struct**:
       - Fields:
         - `registry: Arc<ProcessRegistry>`
         - `injector: Arc<dyn crate::inject_process::InjectProcess>`
         - `config: LazyInjectorConfig`
         - `last_attempt: DashMap<ProcessKey, Instant>` (rate-limit cache)
         - `tier_resolver: Option<Arc<dyn TierResolver>>`
         - `emit_context: Option<Arc<crate::audit_emitter::EmitContext>>`
         - Event-level T3/T4 counters live in `ProcessRegistry` (Plan 07) so the registry remains the single source of truth; `LazyInjector` calls `registry.record_t3t4_event_covered()` and `registry.record_t3t4_event_missed()`.

    3. **`new(registry, injector, config, tier_resolver, emit_context) -> Self`**.

    4. **`pub fn run(&self, event_rx: Receiver<EtwFileEvent>)`** (synchronous, not async):
       - Loop on `event_rx.recv()` (blocking).
       - If `!config.enabled` or `tier_resolver.is_none()`, return immediately.
       - Resolve the tier of `event.file_name` via `tier_resolver.resolve_tier`. If `None` or `Classification::T1`/`T2`, continue.
       - Build `ProcessKey { pid: event.pid, creation_time: get_process_creation_time(event.pid).unwrap_or(0) }`.
       - Look up registry state:
         - If `Injected { .. }`, call `self.registry.record_t3t4_event_covered()` and continue.
         - If `Skipped` for any reason other than `LowConfidence` (or if not `Discovered`/`Skipped(LowConfidence)`), call `self.registry.record_t3t4_event_missed()` and continue.
         - If `Discovered` or `Skipped(LowConfidence)`, call `self.registry.record_t3t4_event_missed()` and proceed to injection attempt.
       - Rate-limit check: if `last_attempt.get(&key)` exists and elapsed < rate_limit, continue.
       - Verify creation-time immediately before injection:
         - Query `get_process_creation_time(event.pid)` again; if it does not match `key.creation_time`, record `Skipped(Failed(InjectionFailure::Timeout))` and continue.
       - Attempt injection:
         - Call `injector.inject(event.pid)`.
         - On success, record `record_lazy_injected(key, "x64".into())`, update `last_attempt`, and emit `EventType::LazyInjectionAttempt` via `emit_context` if present.
         - On failure, log `tracing::warn!`, record `record_skipped(key, SkipReason::Failed(...))` to avoid repeated attempts, and emit `EventType::LazyInjectionFailure` via `emit_context` if present.

    5. **Non-Windows stub**: `run` returns immediately.

    6. **Tests**: Use a mock `ProcessRegistry`, mock `InjectProcess` spy, a `MockTierResolver`, and a fake `Receiver<EtwFileEvent>` to verify all behaviors.
  </action>
