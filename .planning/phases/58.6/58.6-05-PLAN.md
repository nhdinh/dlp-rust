<objective>
Implement the on-demand injection backstop: a `LazyInjector` that listens to ETW Kernel-File events and injects processes that were skipped with low confidence but are now observed touching T3/T4 paths. Define a cross-platform `TierResolver` trait in `dlp-agent/src/tier_resolver.rs` so `LazyInjector` compiles and tests on non-Windows targets, and implement the trait for `ClassificationCache` on Windows using the same path normalization contract as the cache writer. Ensure lazy injection cannot bypass allowlist/PPL/classification for untracked PIDs, and ensure the ETW Kernel-File consumer starts whenever lazy injection is needed even if bypass correlation is disabled.
</objective>
