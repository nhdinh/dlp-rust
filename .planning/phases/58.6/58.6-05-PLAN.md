  <action>
    Create `dlp-agent/src/lazy_injector.rs`.

    1. **`LazyInjectorConfig`** (derive Clone):
       - `rate_limit: Duration` (from `TargetedInjectionConfig::lazy_injection_rate_limit_ms`).
       - `enabled: bool` (from `TargetedInjectionConfig::enable_lazy_injection`).

    2. **`LazyInjector` struct**:
       - Fields:
         - `registry: Arc<ProcessRegistry>`
         - `injector: Arc<HookInjector>`
         - `config: LazyInjectorConfig`
         - `last_attempt: DashMap<ProcessKey, Instant>` (rate-limit cache)
         - `classification_cache: Option<Arc<ClassificationCache>>` — optional because the production cache may not always be available; if `None`, lazy injection is disabled.

    3. **`new(registry, injector, config, classification_cache) -> Self`**.

    4. **`pub async fn run(&self, mut event_rx: Receiver<EtwFileEvent>)`**:
       - Loop on `event_rx.recv()`.
       - If `!config.enabled` or `classification_cache.is_none()`, continue.
       - Build `ProcessKey { pid: event.pid, creation_time: get_process_creation_time(event.pid).unwrap_or(0) }`.
       - Look up registry state:
         - If `Injected` (any variant) or `Skipped` for any reason other than `LowConfidence`, skip.
         - If `Discovered` or `Skipped(LowConfidence)`, proceed.
         - If the key is not present, skip (lazy injection only acts on processes the classifier already evaluated).
       - Check path tier:
         - Use `classification_cache.resolve_tier(&event.file_name)` or equivalent existing API. If the cache API does not expose tier lookup directly, use `dlp_common::Classification` helpers and the protected-paths list from config. The goal is to identify T3/T4 paths.
         - If the path is not T3/T4, skip.
       - Rate-limit check: if `last_attempt.get(&key)` exists and elapsed < rate_limit, skip.
       - Attempt injection:
         - Call `injector.inject(event.pid)`.
         - On success, record `record_lazy_injected(key, "x64".into())` and update `last_attempt`.
         - On failure, log `tracing::warn!` and record `record_skipped(key, SkipReason::Failed(...))` to avoid repeated attempts.

    5. **Non-Windows stub**: `run` returns immediately.

    6. **Tests**: Use a mock `ProcessRegistry`, mock `HookInjector` (or a test spy), and a fake `Receiver<EtwFileEvent>` to verify all behaviors. For the classification cache, provide a test stub that returns T3/T4 for specific paths.
