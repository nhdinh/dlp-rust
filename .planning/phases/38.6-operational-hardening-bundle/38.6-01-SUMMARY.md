## Changes Made

### Task 1: OP-01 Disk Enumeration Error Resilience

**dlp-common/src/disk.rs:**
- `enumerate_fixed_disks_windows()`: Added per-disk error handling — when BOTH `query_bus_type_ioctl` AND `is_usb_bridged_pnp_walk` fail for a disk, emit `tracing::error!` with `instance_id`, `ioctl_error`, and `pnp_error`, then `continue` to the next disk (do NOT push a `DiskIdentity` for the failing disk).
- `disk_number_for_instance_id()`: Changed final error from `DiskError::SetupDiFailed` with generic message to `DiskError::DeviceOpenFailed` with the failing `instance_id` in the message.
- `query_bus_type_for_handle()`: Include Win32 error code in `DiskError::IoctlFailed` message: `format!("DeviceIoControl failed: {e}")`.
- `find_drive_letter_for_instance_id()`: Already handled `Err` gracefully — verified, no changes needed.

**dlp-agent/src/detection/disk.rs:**
- Added documentation test verifying retry delay sequence (200ms, 1000ms, 4000ms).
- Added signature verification test for `on_disk_arrival` error path including `device_path`.

**Tests added (5):**
- `test_query_bus_type_for_handle_includes_win32_error` — verifies Win32 error in message
- `test_disk_number_for_instance_id_returns_err_for_unknown` — verifies `DeviceOpenFailed` with instance_id
- `test_find_drive_letter_returns_none_on_disk_number_err` — verifies graceful None return
- `test_spawn_disk_enumeration_retry_delays_documented` — documents retry behavior
- `test_on_disk_arrival_error_includes_device_path` — signature verification

### Task 2: OP-02 USB Enforcement Structured Logging

**dlp-agent/src/usb_enforcer.rs:**
- Added `resolve_tier_for_identity()` helper that queries `DeviceRegistryCache::trust_tier_for_with_sid` and returns the effective `UsbTrustTier`.
- `UsbEnforcer::check()` now emits `tracing::info!` spans for ALL decision paths:
  - **Unregistered device** (default-deny): `vid`, `pid`, `serial`, `drive`, `action`, `tier=Blocked`, `decision=DENY`, `rule="default-deny: unregistered device"`
  - **Registered device** (allow): `vid`, `pid`, `serial`, `drive`, `action`, `tier=<actual>`, `decision=ALLOW`, `rule="registered device: <tier>"`
  - **Known-USB-without-identity** (defense-in-depth): `drive`, `action`, `tier=Blocked`, `decision=DENY`, `rule="default-deny: known USB without captured identity"`

**dlp-agent/src/detection/usb.rs:**
- `apply_tier_enforcement()` enhanced with `tracing::debug!` spans:
  - Before PnP disable: `vid`, `pid`, `serial`, `drive`, `tier="Blocked"`, `action="PnP disable"`
  - Before DACL deny-all: `drive`, `action="DACL deny-all"`
  - Before ReadOnly DACL: `drive`, `action="DACL read-only"`
  - FullAccess tier: added `action="none"` to existing debug span
- All `tracing::error!` spans in `apply_tier_enforcement` now include full structured context: `vid`, `pid`, `serial`, `drive`, `tier`, `error`.

**Tests added (5):**
- `test_resolve_tier_for_identity_registered` — verifies tier lookup for registered device
- `test_resolve_tier_for_identity_unregistered_defaults_blocked` — verifies Blocked default
- `test_unregistered_block_result_fields` — verifies block result field population
- `test_known_usb_without_identity_block_result_fields` — verifies unknown identity fields
- `test_fullaccess_registered_returns_none_with_tier` — verifies FullAccess allow path
