# Phase 38.6 Plan 02: OP-03 + OP-04 Operational Hardening Summary

**One-liner:** Agent config TOML field-range validation with clamping/rejection and a 10s timeout-bound graceful shutdown that cancels in-flight tasks, flushes audits, restores DACLs, and unregisters device notifications.

---

## Tasks Completed

### Task 1: Agent Config TOML Field-Range Validation (OP-03)

**Files:** `dlp-agent/src/config.rs`, `dlp-agent/Cargo.toml`
**Commit:** `fc45445`

- Added `serde_ignored` dependency for unknown TOML key detection.
- Added `poll_interval_secs: Option<u64>` to `AgentConfig` with serde default.
- Added `resolved_cache_ttl()` method clamping `ldap.cache_ttl_secs` to [60, 3600] with `warn!` log.
- Added `resolved_poll_interval()` method: defaults to 30s, rejects values < 5s (returns default with `warn!` log).
- Updated `resolved_recheck_interval()` minimum from 300s to 60s per OP-03 spec.
- Added `serde_ignored::deserialize` in `AgentConfig::load()` to detect unknown keys, log warning, and continue loading.
- Added 8 unit tests covering:
  - recheck_interval clamp low (30 -> 60)
  - recheck_interval clamp high (100000 -> 86400)
  - cache_ttl clamp low (30 -> 60)
  - cache_ttl clamp high (5000 -> 3600)
  - poll_interval rejection below 5 (3 -> 30)
  - poll_interval pass-through (10 -> 10)
  - poll_interval default (None -> 30)
  - unknown TOML key warns but loads
  - invalid TOML syntax falls back to defaults

### Task 2: Graceful Service Shutdown with Timeout (OP-04)

**Files:** `dlp-agent/src/service.rs`, `dlp-agent/src/detection/disk.rs`, `dlp-agent/src/detection/usb.rs`
**Commit:** `ec4fdfa`

- Added `SHUTDOWN_TIMEOUT` (10s) and `DISK_ENUM_CANCEL_TIMEOUT` (5s) constants.
- Modified `spawn_disk_enumeration_task` to:
  - Accept `shutdown_rx: watch::Receiver<bool>` for cancellation.
  - Return `tokio::task::JoinHandle<()>` so caller can await.
  - Check shutdown signal before each enumeration attempt.
- Wrapped entire shutdown sequence in `tokio::time::timeout(SHUTDOWN_TIMEOUT, async { ... })`.
- On shutdown:
  1. Stop file monitor and await file handle.
  2. Drop event loop handle.
  3. Signal and await heartbeat, Pipe 1 heartbeat.
  4. Signal and await config poll, device registry poll, managed origins poll.
  5. Cancel disk enumeration (send shutdown signal, await up to 5s).
  6. Unregister device watcher (USB handlers complete via thread join).
  7. Restore volume DACLs for all USB drives (best-effort, debug log on failure).
  8. Re-enable PnP-disabled USB devices (best-effort, debug log on failure).
  9. Kill UI processes.
  10. Signal and await audit buffer flush.
- If shutdown exceeds 10s, logs error and force-terminates.
- Added `get_device_controller()` public accessor in `usb.rs` for shutdown path.
