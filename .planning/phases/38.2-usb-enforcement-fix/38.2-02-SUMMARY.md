# Plan 38.2-02 Summary

## What Was Built

Rewrote `DeviceController::disable_usb_device` and `enable_usb_device` to resolve actual CM instance IDs via dlp-common helpers instead of constructing them from VID/PID/serial.

## Key Changes

| File | Change |
|------|--------|
| `dlp-agent/src/device_controller.rs` | New signatures: `(dbcc_name, identity)` instead of `(vid, pid, serial)` |
| `dlp-agent/src/device_controller.rs` | Added `map_resolution_error()` helper |
| `dlp-agent/src/device_controller.rs` | Primary resolution via `resolve_instance_id_from_dbcc_name` |
| `dlp-agent/src/device_controller.rs` | Fallback via `find_instance_id_by_vid_pid_serial` |
| `dlp-agent/src/detection/usb.rs` | Updated call sites with temporary `dbcc_name` construction |

## Functions Modified

- `disable_usb_device(&self, dbcc_name: &str, identity: &DeviceIdentity) -> Result<(), DeviceControllerError>`
  - Primary: `resolve_instance_id_from_dbcc_name(dbcc_name)`
  - Fallback: `find_instance_id_by_vid_pid_serial(&identity.vid, &identity.pid, &identity.serial)`
  - `CR_NO_SUCH_DEVNODE` on initial resolution returns `Err` (D-03)
  - `CR_NO_SUCH_DEVNODE` after successful locate returns `Ok(())` with warn

- `enable_usb_device(&self, dbcc_name: &str, identity: &DeviceIdentity) -> Result<(), DeviceControllerError>`
  - Symmetric logic using `CM_Enable_DevNode` with `CM_ENABLE_ABSOLUTE`
