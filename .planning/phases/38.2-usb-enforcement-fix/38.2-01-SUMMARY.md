## Functions Added

- `resolve_instance_id_from_dbcc_name(dbcc_name: &str) -> Result<String, UsbResolutionError>`
  - Uses `CM_Get_Device_Interface_PropertyW` with `DEVPKEY_Device_InstanceId`
  - Two-step buffer pattern (query size, allocate, retrieve)
  - Validates `dbcc_name` starts with `\\?\USB#` before CM API call

- `find_instance_id_by_vid_pid_serial(vid, pid, serial) -> Result<String, UsbResolutionError>`
  - SetupDi enumeration fallback for startup scan path
  - Handles `(none)` serial per D-04/D-05
  - Returns error on ambiguous matches when serial is `(none)`
