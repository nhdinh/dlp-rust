# Plan 38.2-03 Summary

## What Was Built

Wired `dbcc_name` device path through the entire USB enforcement pipeline. Implemented D-06 (DACL always attempts even if PnP fails; unified Err if both fail) and D-07 (structured tracing spans for all enforcement outcomes).

## Key Changes

| File | Change |
|------|--------|
| `dlp-agent/src/detection/usb.rs` | `apply_tier_enforcement` signature changed to `(letter, identity, dbcc_name) -> Result<(), String>` |
| `dlp-agent/src/detection/usb.rs` | Blocked tier: always attempts PnP disable + DACL deny-all; returns unified Err if both fail (D-06) |
| `dlp-agent/src/detection/usb.rs` | Structured tracing spans with vid, pid, serial, drive_letter, tier, pnp_result, dacl_result (D-07) |
| `dlp-agent/src/detection/usb.rs` | `reconcile_identity_with_unmapped_drive` accepts `dbcc_name` parameter |
| `dlp-agent/src/detection/usb.rs` | `on_usb_device_arrival` passes `device_path` through reconciliation chain |
| `dlp-agent/src/detection/usb.rs` | `handle_volume_event` pending reconciliation passes `""` dbcc_name (fallback path) |
| `dlp-agent/src/detection/usb.rs` | `scan_existing_usb_identities` passes `""` dbcc_name (fallback path) |
| `dlp-agent/src/detection/usb.rs` | `on_usb_device_removal` passes `device_path` directly to `enable_usb_device` |
| `dlp-agent/src/detection/device_watcher.rs` | No changes needed — dbcc_name already flows correctly via `read_dbcc_name` -> dispatch |
| `dlp-common/src/usb.rs` | Fixed clippy `collapsible_if` in `find_instance_id_by_vid_pid_serial` |

## Functions Modified

- `apply_tier_enforcement(letter, identity, dbcc_name) -> Result<(), String>`
  - Returns `Err` when both PnP disable and DACL deny-all fail
  - Returns `Ok(())` when at least one layer succeeds (defense-in-depth)
  - Emits `error!`, `warn!`, or `info!` structured spans depending on outcome

- `reconcile_identity_with_unmapped_drive(&self, identity, dbcc_name) -> Option<char>`
  - Passes `dbcc_name` through to `apply_tier_enforcement`

## Call Site Updates

- `on_usb_device_arrival`: `reconcile_identity_with_unmapped_drive(&identity, device_path)`
- `handle_volume_event`: `apply_tier_enforcement(*letter, &identity, "")`
- `scan_existing_usb_identities`: `apply_tier_enforcement(letter, &identity, "")`
- `on_usb_device_removal`: `enable_usb_device(device_path, &parsed)`
