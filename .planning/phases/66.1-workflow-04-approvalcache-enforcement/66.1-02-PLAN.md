<objective>
Populate `matched_label_id` in server-side ABAC evaluation so the agent can construct `ApprovalCacheKey` without re-resolving labels.

Purpose: The server already resolves path -> label during ABAC evaluation. Returning the matched label ID eliminates redundant label resolution on the agent and enables approval cache lookups.
Output: `PolicyStore::evaluate` returns `matched_label_id` in `EvaluateResponse`; `LabelService` provides a method that returns both tier and label ID.
</objective>
