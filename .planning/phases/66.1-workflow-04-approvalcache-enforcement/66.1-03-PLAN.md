## Review feedback addressed in this plan

- **HIGH: ApprovalCache lacks `get()` method (Claude review):** The original plan called `cache.get(&key)` which does not exist. The revised helper uses `cache.check(&key, dst)` ONLY — no `get()` call. `check()` already performs full JWT re-verification, so there is no need for a separate `get_unchecked`.

- **HIGH: Tests call `run_event_loop` directly (OpenCode review):** There is only ONE production call site for `run_event_loop` (in `spawn_event_loop` at service.rs:3000). No test files call `run_event_loop` or `spawn_event_loop` directly (verified by grep). To avoid future breakage and keep the signature clean, `approval_cache` is passed as `Option<Arc<ApprovalCache>>` with a default of `None` in `spawn_event_loop`, making it backward-compatible. The `run_event_loop` parameter is also `Option<Arc<ApprovalCache>>`.

- **MEDIUM: 8th positional parameter is a code smell (OpenCode review):** Using `Option<Arc<ApprovalCache>>` keeps the parameter optional. A future refactor can introduce `InterceptionOptions` if more parameters are added. This plan documents the pattern without over-engineering.

           pub fn from_evaluation(
               response: &EvaluateResponse,
               sid: &str,
               action: &str,
               dst: Option<&str>,
           ) -> Option<Self> {
               let obj_id = response.matched_label_id.as_deref()?;

    2. `check_approval_override` — free function that wraps `cache.check()` and returns both the override response AND the claims for audit enrichment. Uses `cache.check()` ONLY (no `get()` — that method does not exist):
       ```rust
       pub fn check_approval_override(
           cache: &ApprovalCache,
           response: &EvaluateResponse,
           sid: &str,
           action: &str,
           dst: Option<&str>,
       ) -> Option<(EvaluateResponse, ApprovalClaims)> {
           let key = ApprovalCacheKey::from_evaluation(response, sid, action, dst)?;
           // check() performs: cache lookup + expiry + JWT re-verify + scope match.
           let ovr = cache.check(&key, dst)?;
           // To return claims for audit enrichment, we need the cached entry.
           // Since check() already verified the entry is valid, we can safely
           // read it from the DashMap without re-verification.
           let entry = cache.cache.get(&key.encode())?;
           Some((ovr, entry.claims.clone()))
       }
       ```
       Note: `cache.cache` is `pub` on `ApprovalCache`, so `cache.cache.get(...)` is accessible. The entry is guaranteed to exist because `check()` just succeeded. This avoids adding a new `get_unchecked` method.
