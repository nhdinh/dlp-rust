    1. Add `MutationContext` struct with fields: `label_id: String`, `action: String`, `old_state: Option<String>`, `new_state: Option<String>`, `path: String`, `tier: String`.

    2. Add `with_mutation` method to `LabelService`:
       ```rust
       pub fn with_mutation<F>(
           &self,
           pool: &Pool,
           mutation: F,
       ) -> Result<MutationContext, AppError>
       where
           F: FnOnce(&UnitOfWork) -> Result<MutationContext, AppError>,
       ```
       The method:
       - Acquires a connection from the pool
       - Creates a `UnitOfWork`
       - Calls the mutation closure, receiving a `MutationContext`
       - Emits the audit event INSIDE the transaction using `audit_store::store_events_sync_uow` (taking `&UnitOfWork` instead of `&Pool`)
       - If audit emission fails, returns an error (transaction is NOT committed, rolls back on drop)
       - Commits the UnitOfWork
       - Calls `self.invalidate_cache()` AFTER successful commit (per D-15)
       - Returns the `MutationContext`

    3. If `audit_store::store_events_sync_uow` (taking `&UnitOfWork`) does not exist, add it to `audit_store.rs`. It should delegate to `AuditEventRepository::insert_batch(uow, &rows)`.

       - `update_label`: wrap update + audit in with_mutation
       - `confirm_label`: wrap update_state + audit in with_mutation
       - `reject_label`: wrap update_state + audit in with_mutation
       - `expire_label`: wrap update_state + audit in with_mutation
       - `delete_label`: wrap delete + audit in with_mutation

    Per D-14: Audit emission is mandatory (not best-effort). If audit insertion fails, the transaction rolls back.
    Per D-15: Cache invalidation happens after successful transaction commit.
    Addresses review HIGH: "Audit guarantees overstated" — now truly transactional.
