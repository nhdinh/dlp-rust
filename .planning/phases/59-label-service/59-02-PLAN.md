Add the following to `dlp-server/src/admin_api.rs`:

1. **Request/response types** (in the admin_api module, near existing request types):
   ```rust
   #[derive(Debug, Clone, serde::Deserialize)]
   struct CreateLabelRequest {
       path: String,
       object_type: String,
       tier: String,
       label_state: String,
       owner_sid: Option<String>,
       parent_label_id: Option<String>,
       acl_snapshot_id: Option<String>,
       hash: Option<String>,
   }
   ```

2. **Helper: validate_label_request** — returns `Result<(), AppError>`:
   - `path` must be absolute: starts with `\\` (UNC) or `X:\` where X is A-Z (case-insensitive). If not, return `AppError::UnprocessableEntity("path must be absolute".into())`.
   - `object_type` must be one of `"file"`, `"folder"`, `"archive"`. Case-insensitive match.
   - `tier` must be one of `"T1"`, `"T2"`, `"T3"`, `"T4"`, `"Unclassified-Blocked"`. Case-insensitive match.
   - `label_state` must be one of `"temporary"`, `"confirmed"`, `"rejected"`, `"expired"`. Case-insensitive match.
   - If `parent_label_id` is Some: query DB to verify it points to a label with `object_type = 'folder'`. If not, return `AppError::UnprocessableEntity("parent_label_id must reference a folder label".into())`.
   - Normalize path: no trailing backslash/slash (except root `C:\` or `\\server\share`).

3. **Helper: row_to_label_json** — converts `LabelRow` to `serde_json::Value` with field names matching dlp-common `Label` struct.

4. **Handler: list_labels** — `GET /admin/labels`:
   - Optional query params: `?state=`, `?tier=`, `?owner_sid=`
   - If `state` param present: call `LabelRepository::list_by_state(pool, state)`
   - Else: call `LabelRepository::list(pool)`
   - Filter by `tier` and `owner_sid` in memory if those params are present
   - Return `Json<Vec<serde_json::Value>>`
   - Wrap DB call in `tokio::task::spawn_blocking`

5. **Handler: get_label** — `GET /admin/labels/:id`:
   - Call `LabelRepository::get_by_id(pool, &id)`
   - Return 404 if not found
   - Return `Json<serde_json::Value>`

6. **Handler: create_label** — `POST /admin/labels`:
   - Parse `Json<CreateLabelRequest>`
   - Call `validate_label_request`
   - Generate UUID v4 for `id` using `uuid::Uuid::new_v4().to_string()`
   - Set `created_at` and `updated_at` to current UTC ISO-8601 timestamp (`chrono::Utc::now().to_rfc3339()`)
   - Build `LabelUpsertRow` with all fields
   - Open UnitOfWork, call `LabelRepository::insert`, commit
   - Call `state.label_service.invalidate_cache()`
   - Emit audit event: `audit_store::emit_admin_action(&pool, "label_create", &format!("created label {} at {}", id, req.path), "admin")`
   - Return `Json<serde_json::Value>` with created label

7. **Handler: update_label** — `PUT /admin/labels/:id`:
   - Parse `Json<CreateLabelRequest>` (reuse same request type)
   - Call `validate_label_request`
   - Verify label exists (get_by_id), return 404 if not
   - Keep original `created_at`, set `updated_at` to now
   - Build `LabelUpsertRow` with original id
   - Update via UnitOfWork
   - Invalidate cache, emit audit event "label_update"

8. **Handler: confirm_label** — `POST /admin/labels/:id/confirm`:
   - Verify label exists
   - Verify current state is `temporary` (per D-15), return 422 if not
   - Call `LabelRepository::update_state(uow, &id, "confirmed", &now)`
   - Commit, invalidate cache, emit audit event "label_confirm"

9. **Handler: reject_label** — `POST /admin/labels/:id/reject`:
   - Same as confirm but set state to `"rejected"`
   - Audit event "label_reject"

10. **Handler: delete_label** — `DELETE /admin/labels/:id`:
    - Verify label exists
    - Delete via UnitOfWork
    - Commit, invalidate cache, emit audit event "label_delete"

11. **Router registration** — In `admin_router()` function, add:
    ```rust
    .route("/admin/labels", get(list_labels).post(create_label))
    .route("/admin/labels/:id", get(get_label).put(update_label).delete(delete_label))
    .route("/admin/labels/:id/confirm", post(confirm_label))
    .route("/admin/labels/:id/reject", post(reject_label))
    ```
    These routes are under `/admin/*` so JWT auth is already applied.

Per D-03: Follow disk_registry/device_registry pattern.
Per D-04: Use dlp-common Label type for response serialization (convert LabelRow to Label JSON).
Per D-05: Validate absolute path, valid enums, parent_label_id → folder.
Per D-08: Call invalidate_cache() after every mutating operation.

```rust
pub fn emit_admin_action(pool: &Pool, action: &str, details: &str, user: &str) -> Result<(), rusqlite::Error> {
    let conn = pool.get().map_err(|e| rusqlite::Error::ToSqlConversionFailure(Box::new(e)))?;
    conn.execute(
        "INSERT INTO audit_events (timestamp, event_type, user_sid, user_name, resource_path, classification, action_attempted, decision, agent_id, session_id) \
         VALUES (?1, 'AdminAction', ?2, ?3, ?4, 'T1', ?5, 'ALLOW', 'server', 0)",
        rusqlite::params![
            chrono::Utc::now().to_rfc3339(),
            user,
            user,
            details,
            action,
        ],
    )?;
    Ok(())
}
```
