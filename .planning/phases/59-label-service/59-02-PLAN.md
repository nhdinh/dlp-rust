    2. Add `with_mutation` method to `LabelService`:
       ```rust
       pub fn with_mutation<F>(
           &self,
           pool: &Pool,
           mutation: F,
       ) -> Result<MutationContext, AppError>
       where
           F: FnOnce(&UnitOfWork) -> Result<MutationContext, AppError>,
       ```
       The method:
       - Acquires a connection from the pool
       - Creates a `UnitOfWork`
       - Calls the mutation closure, receiving a `MutationContext`
       - Emits the audit event INSIDE the transaction using `audit_store::store_events_sync(&uow, &[audit_event])`
       - If audit emission fails, returns an error (transaction is NOT committed, rolls back on drop)
       - Commits the UnitOfWork
       - Calls `self.invalidate_cache()` AFTER successful commit (per D-15)
       - Returns the `MutationContext`
