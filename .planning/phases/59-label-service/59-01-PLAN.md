## Current Code State

The existing `dlp-server/src/label_service.rs` has:
- `LabelCache` storing `HashMap<String, (Tier, Instant)>` — only Tier, no source
- `resolve_tier` returning `rusqlite::Result<Tier>` — no source semantics
- Resolution order: exact match (returns immediately) -> parent walk -> fallback
- **BUG**: Exact match returns without comparing against parent tier strictness, violating LABEL-02
- **BUG**: Cache loses whether result was Exact or Inherited
