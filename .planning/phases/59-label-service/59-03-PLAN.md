<objective>
Integrate label-aware ABAC evaluation: when the `label_aware_evaluation_enabled` system flag is true, the PolicyStore resolves `Resource.classification` from the LabelService instead of using the request's hardcoded classification. Unlabeled resources fall back to `UnclassifiedBlocked`.

Purpose: This is the enforcement-time integration that makes labels meaningful. Without it, labels are just metadata. With it, the ABAC engine uses the central label database for tier decisions.
Output: Label-aware ABAC evaluation gated by a system flag (default off).
</objective>

2. Modify `PolicyStore::evaluate()` method signature to accept `Option<&LabelService>`:
   ```rust
   pub fn evaluate(
       &self,
       ctx: &AbacContext,
       label_service: Option<&crate::label_service::LabelService>,
   ) -> EvaluateResponse
   ```
   
   At the start of evaluate():
   ```rust
   let mut resource = ctx.resource.clone();
   
   // Label-aware evaluation: resolve tier from LabelService when enabled
   if let Some(service) = label_service {
       if let Some(ref path) = ctx.resource_path {
           match Self::is_label_aware_enabled(&self.pool) {
               Ok(true) => {
                   match service.resolve_tier(path) {
                       Ok(tier) => {
                           if let Some(classification) = tier.to_classification() {
                               resource.classification = classification;
                           } else {
                               // UnclassifiedBlocked: set to T4 (most restrictive)
                               // The policy engine will DENY everything since no policy
                               // typically allows T4 for general users.
                               resource.classification = Classification::T4;
                           }
                       }
                       Err(e) => {
                           tracing::error!(error = %e, path, "label resolution failed — using request classification");
                       }
                   }
               }
               Ok(false) => {} // label-aware disabled, use request classification
               Err(e) => {
                   tracing::error!(error = %e, "failed to read label_aware_evaluation_enabled flag");
               }
           }
       }
   }
   ```

   fn is_label_aware_enabled(pool: &Pool) -> rusqlite::Result<bool> {

           None => Ok(false), // default off per D-11
       }
