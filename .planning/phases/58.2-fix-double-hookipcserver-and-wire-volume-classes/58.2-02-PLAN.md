     - "WRITE" | "CREATE" | "NT_WRITE" -> WRITE

     - subject.user_sid = caller_sid
     - resource.path = req.path.clone()
     - action = map_hook_action_to_abac(&req.action)
     - source_volume_class = req.source_volume_class
     - destination_volume_class = req.destination_volume_class
     - agent, source_application, destination_application, source_origin, destination_origin = None (per D-08)
  3. Add `fn get_caller_sid(pid: u32) -> Option<String>` as a thin wrapper around the existing `get_process_user_sid` (or identical logic). Per D-10, it resolves the subject SID from req.pid. Per D-11, if resolution fails (pid=0, process exited, access denied), return None so the caller can return DENY.

  5. Add `warn!(...)` logging per D-09: when the hook action is "COPY" or "MOVE" and either source_volume_class or destination_volume_class is None, emit a `tracing::warn!` with the request path and action to surface potential hook DLL classification gaps.
