# Phase 38.4: Per-User Device Registry — UI Design Contract

## Scope

Minimal UI change: add `owner_sid` and `owner_user` columns to the existing Admin TUI device registry table.

## Screen: Device Registry List

### Changes

| Element | Change |
|---------|--------|
| Table columns | Insert `owner_sid` and `owner_user` between `serial` and `trust_tier` |
| Column header | "Owner SID" / "Owner User" |
| Empty value | "(all users)" for machine-wide entries (NULL in DB) |
| Column width | `owner_sid`: 28 chars (SIDs are long); `owner_user`: 15 chars |
| Truncation | Truncate with "..." if SID exceeds width |

### No other UI changes

No new screens, no new interactions, no new forms. The existing POST/DELETE flows remain unchanged.
