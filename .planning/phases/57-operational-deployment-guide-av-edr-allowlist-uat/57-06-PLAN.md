    | Cloud Sync Regression | `scripts/Uat-CloudSync.ps1` | Real OneDrive/Google Drive/Dropbox/Box clients |

    | Performance Benchmark | `scripts/Uat-Benchmark.ps1` | Same endpoint, no extra hardware |
    | Volume Class (SD/Optical/Virtual) | Manual steps | Physical SD card, optical drive, or virtual mount |

    ### Execution Order

    1. **Pre-flight checks** (see Pre-Flight Checks section above)
    2. **EDR allowlist** (see EDR Allowlist Procedures section above) -- wait for propagation
    3. **Install DLPAgent.msi**
    4. **Reboot** (required for complete hook coverage)
    5. **Run UAT scripts** in order:
       ```powershell
       # 1. Cloud sync regression
       .\scripts\Uat-CloudSync.ps1

       # 2. Print enforcement
       .\scripts\Uat-PrintBlock.ps1

       # 3. Hook DLL injection
       .\scripts\Uat-HookDll.ps1

       # 4. DACL tripwire
       .\scripts\Uat-DaclTripwire.ps1

       # 5. ETW + ntdll + monitor mode
       .\scripts\Uat-EtwNtdll.ps1

       # 6. USB enforcement
       .\scripts\Uat-UsbBlock.ps1

       # 7. Performance benchmark
       .\scripts\Uat-Benchmark.ps1
       ```
    6. **Manual volume class tests** (if hardware available):
       - Insert SD card, verify VolumeArrival event with `volume_class=SDCard`
       - Mount optical disc, verify `volume_class=Optical`
       - Mount VHD/ISO, verify `volume_class=Virtual`
    7. **Record results** in `.planning/milestones/v0.10.0-UAT.md`
    8. **Sign off** with Tester, QA Lead, and Release Manager

    ### CRIT-04 Benchmark Gate

    The benchmark gate requires <= 25% wall-clock overhead on representative workloads. For full benchmark preconditions, see the script's inline documentation (`.\scripts\Uat-Benchmark.ps1 -?`).

    | Workload | Baseline | Hooked | Overhead | Gate |
    |----------|----------|--------|----------|------|
    | `cargo build --release` (small project) | Median of 3 runs | Median of 3 runs | <= 25% | PASS |
    | Microsoft Word launch | Median of 3 runs | Median of 3 runs | <= 25% | PASS |

    **Benchmark preconditions (see script for full details):**
    - Disable Windows Update
    - Pause AV real-time scans
    - Close all unnecessary applications
    - Ensure > 4GB free RAM
    - Run 3 times, take median
    - Exclude outliers > 2 standard deviations

    If either workload exceeds 25% overhead, the benchmark FAILs and the release is blocked pending performance investigation.

    ### UAT Pass Criteria

    UAT is considered PASS when:
    - All automated scripts exit with code 0
    - All manual tests are marked PASS in the test matrix
    - CRIT-04 benchmark gate holds (both workloads <= 25%)
    - No unexplainable FAIL or WARN results
    - Sign-off completed by all three roles

    Optional tests (Volume Class) that are skipped due to missing hardware do NOT block UAT completion. Mark them N/A and note the missing hardware.

    If any test FAILs:
    - Investigate the root cause
    - Fix the issue or document as known issue
    - Re-run the failed test
    - If the issue cannot be resolved, escalate to the release manager
