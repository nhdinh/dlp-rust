       ```markdown
       ### Hash Generation

       To generate SHA-256 and SHA-512 hashes for all binaries, run:

       ```powershell
       $binaries = @(
         "dlp-agent.exe",
         "dlp-server.exe",
         "dlp-admin-cli.exe",
         "dlp-user-ui.exe",
         "dlp-hook-dll.dll",
         "dlp-hook-dll-x86.dll"
       )

       foreach ($binary in $binaries) {
         $path = "C:\Program Files\DLP\$binary"
         if (Test-Path $path) {
           $sha256 = (Get-FileHash $path -Algorithm SHA256).Hash
           $sha512 = (Get-FileHash $path -Algorithm SHA512).Hash
           Write-Output "$binary | $sha256 | $sha512"
         }
       }
       ```
       ```
    2. A "Hash Verification" subsection with a script that recomputes hashes and compares to RELEASE_NOTES.md:
       ```powershell
       # Verify hashes match RELEASE_NOTES.md
       $releaseNotes = Get-Content .\RELEASE_NOTES.md
       foreach ($binary in $binaries) {
         $path = "C:\Program Files\DLP\$binary"
         $actualSha256 = (Get-FileHash $path -Algorithm SHA256).Hash
         $expectedLine = $releaseNotes | Select-String "$binary.*$actualSha256"
         if ($expectedLine) {
           Write-Output "PASS: $binary SHA-256 matches"
         } else {
           Write-Output "FAIL: $binary SHA-256 MISMATCH"
         }
       }
       ```
    3. Also add to the deployment guide's "Post-Install Verification" section a step to verify hashes match RELEASE_NOTES.md.
