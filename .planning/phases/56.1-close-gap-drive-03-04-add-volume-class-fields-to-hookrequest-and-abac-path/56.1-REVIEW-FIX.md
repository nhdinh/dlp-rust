## Skipped Issues

### CR-03: Bincode backward compatibility broken for `HookRequest` (old peers cannot deserialize)

**File:** `dlp-common/src/hook_ipc.rs:102-136`
**Reason:** The fix requires architectural changes beyond the scope of a single fix. The correct approach is to bump the `IpcEnvelope` protocol version and only include volume class fields in `IpcEnvelope::V2` (or later), never in raw `HookRequest` bincode. This requires: (1) bumping `CURRENT_PROTOCOL_VERSION` to 2, (2) adding a new `IpcEnvelope::V2` variant, (3) modifying the hook DLL to use envelope wrapping for all `HookRequest` sends, (4) updating the agent's fallback logic. The hook DLL currently sends raw `HookRequest` via `pipe_client::send_request`, not envelope-wrapped. This is a multi-file, multi-crate protocol change that should be its own phase.
