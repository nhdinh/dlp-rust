## Decisions Made

- **Placeholder SID documented as known limitation:** The `hook_request_to_evaluate_request` doc comment explicitly states that `user_sid: "S-1-5-21-hook"` is synthetic and real PID-to-SID resolution is deferred. Tests use only resource/action/environment conditions.
- **Sync-only hook handler:** The hook handler calls `offline_decision` synchronously with no async bridging constructs. This is documented in code comments and verified by grep gates in acceptance criteria.
- **Cache hint from request classification:** `build_cache_hint` now accepts `Option<Classification>` from the `EvaluateRequest.resource.classification` (resolved by `PolicyMapper::provisional_classification`) rather than parsing the path string. This is more accurate because the classification is already resolved during request construction.
- **start_mock_server available in integration tests:** Removed `#[cfg(test)]` gate from `start_mock_server` so integration tests can use the same mock server helper as unit tests.
