## Objective

Add `source_volume_class` and `destination_volume_class` fields to the IPC `HookRequest` payload and the ABAC `EvaluateRequest` wire format, then update the `From<EvaluateRequest> for AbacContext` conversion to forward these fields instead of hardcoding `None`. This is the foundational type change that enables the rest of the data flow (hook DLL population in Plan 02, agent ABAC evaluation in Plan 03).

Purpose: Without these fields on `HookRequest`, the hook DLL cannot communicate volume class information across the IPC boundary. Without them on `EvaluateRequest`, the REST API cannot carry volume class to the Policy Engine. Without forwarding in the `From` impl, `AbacContext` always has `None` for volume classes regardless of what the request carries.

Output: Updated `HookRequest`, `EvaluateRequest`, and `AbacContext` conversion with full backward-compatibility tests.
