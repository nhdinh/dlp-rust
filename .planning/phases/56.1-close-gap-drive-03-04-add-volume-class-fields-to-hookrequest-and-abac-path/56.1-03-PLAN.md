## Objective

Wire the agent's hook IPC handler to perform real ABAC evaluation using the volume class data from the hook DLL's `HookRequest`. Replace the placeholder `build_cache_hint` heuristic with a proper `HookRequest` → `EvaluateRequest` conversion that forwards `source_volume_class` and `destination_volume_class`, then calls `OfflineManager::evaluate` for authoritative policy decisions.

Purpose: After Plans 01 and 02, the `HookRequest` IPC payload carries volume class fields and the hook DLL populates them. This plan closes the final gap: the agent must convert the `HookRequest` into an `EvaluateRequest` (with volume class forwarded), evaluate it through the real ABAC pipeline, and return the authoritative decision to the hook DLL. Without this, volume-class policies still won't fire for hook-intercepted operations.

Output: Agent hook IPC path with real ABAC evaluation and volume-class-aware integration tests.
