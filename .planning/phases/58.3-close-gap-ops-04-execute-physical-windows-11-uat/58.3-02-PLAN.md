    The script's Word benchmark (lines 491-557) only starts WINWORD.EXE, sleeps 3 seconds, and kills the process. It does NOT open or save a document, so it does not exercise the Office file-I/O path that the UAT plan I02 requires. Per D-01, the script is used exactly as-is; however, the tester must supplement the script-generated data with a manual COM automation benchmark to ensure the CRIT-04 evidence is valid for the intended workload.

    1. After the script completes, examine C:\UAT\v0.10.0\crit04_results.json. If the `word_launch` section exists and shows only process start/exit times (not open/save operations), run the manual COM automation benchmark below.
    2. Create a T4 Word document template at `C:\Protected\Test\t4_template.docx` (create a new document in Word, save it to the protected path, and ensure it is classified T4).
    3. Run the manual Word COM automation benchmark using the same warm-up + 3 baseline + 3 hooked protocol:

    ```powershell
    # Baseline (agent stopped)
    Stop-Service dlp-agent -Force; Start-Sleep -Seconds 5
    $wordPath = Join-Path $env:ProgramFiles 'Microsoft Office\root\Office16\WINWORD.EXE'
    if (-not (Test-Path $wordPath)) { $wordPath = Join-Path ${env:ProgramFiles(x86)} 'Microsoft Office\root\Office16\WINWORD.EXE' }

    # Warm-up (discarded)
    $word = New-Object -ComObject Word.Application; $word.Visible = $false
    $doc = $word.Documents.Open('C:\Protected\Test\t4_template.docx')
    $doc.Save(); $doc.Close(); $word.Quit()
    [System.Runtime.Interopservices.Marshal]::ReleaseComObject($word) | Out-Null

    # 3 baseline runs
    $baselineTimes = @()
    for ($i = 1; $i -le 3; $i++) {
        $sw = [System.Diagnostics.Stopwatch]::StartNew()
        $word = New-Object -ComObject Word.Application; $word.Visible = $false
        $doc = $word.Documents.Open('C:\Protected\Test\t4_template.docx')
        $doc.Save(); $doc.Close(); $word.Quit()
        [System.Runtime.Interopservices.Marshal]::ReleaseComObject($word) | Out-Null
        $sw.Stop()
        $baselineTimes += [math]::Round($sw.Elapsed.TotalSeconds, 2)
    }

    # With-hooks (agent started)
    Start-Service dlp-agent; Start-Sleep -Seconds 30
    # Warm-up (discarded)
    $word = New-Object -ComObject Word.Application; $word.Visible = $false
    $doc = $word.Documents.Open('C:\Protected\Test\t4_template.docx')
    $doc.Save(); $doc.Close(); $word.Quit()
    [System.Runtime.Interopservices.Marshal]::ReleaseComObject($word) | Out-Null

    # 3 hooked runs
    $hookedTimes = @()
    for ($i = 1; $i -le 3; $i++) {
        $sw = [System.Diagnostics.Stopwatch]::StartNew()
        $word = New-Object -ComObject Word.Application; $word.Visible = $false
        $doc = $word.Documents.Open('C:\Protected\Test\t4_template.docx')
        $doc.Save(); $doc.Close(); $word.Quit()
        [System.Runtime.Interopservices.Marshal]::ReleaseComObject($word) | Out-Null
        $sw.Stop()
        $hookedTimes += [math]::Round($sw.Elapsed.TotalSeconds, 2)
    }

    $baselineMedian = ($baselineTimes | Sort-Object)[[math]::Floor($baselineTimes.Count / 2)]
    $hookedMedian = ($hookedTimes | Sort-Object)[[math]::Floor($hookedTimes.Count / 2)]
    $overhead = if ($baselineMedian -eq 0) { 0 } else { [math]::Round((($hookedMedian - $baselineMedian) / $baselineMedian) * 100, 2) }
    $passed = $overhead -le 25
    ```

    4. Save the manual benchmark results to `C:\UAT\v0.10.0\crit04_word_com_fallback.json` with the same structure as the script's crit04_results.json (baseline_times, hooked_times, baseline_median, hooked_median, overhead_percent, passed, target_percent).
    5. If the manual benchmark shows significantly different overhead from the script's Word launch benchmark, use the manual COM automation results as the canonical I02 evidence. Document the discrepancy in the notes.

    If Word is not installed, mark I02 as N/A with justification and skip this task.
