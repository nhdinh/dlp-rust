        **Loader-Lock Safety Contract** (per review feedback P1 — Codex MEDIUM):

        `DllMain` runs under the Windows loader lock during `DLL_PROCESS_ATTACH`. The following operations are UNSAFE inside the loader lock and MUST NOT be called from `init()`:
        - `LoadLibrary` / `LoadLibraryEx` (may deadlock — loader lock is already held)
        - `CoInitializeEx` / `OleInitialize` (COM initialization may load DLLs)
        - `CreateThread` (may deadlock with loader lock)
        - `EnterCriticalSection` on a critical section not initialized in this DllMain
        - `InitializeCriticalSection` (safe, but EnterCriticalSection on it is not)
        - `malloc` / `HeapAlloc` (generally safe on Vista+, but avoid if possible)
        - `OutputDebugStringW` (safe on Vista+, but may load debug helper DLLs on XP)
        - Named-pipe connection / any IPC (may block indefinitely)
        - `VirtualProtect` (safe — does not load DLLs)

        The `init()` function MUST adhere to this contract:
        - `GetModuleHandleW(None)` — safe (returns already-loaded module)
        - `find_iat_entry` + `patch_iat` — safe (reads/writes memory, no DLL loading)
        - `resolve_proc` via `GetModuleHandleW` + `GetProcAddress` — safe for kernel32/ntdll (already loaded)
        - `OutputDebugStringW` — safe on Windows Vista+ (minimum supported OS)
        - `AtomicBool::swap` — safe (no syscalls)

        /// Maximum wide-character length for path extraction.
        const MAX_WIDE_CHARS: usize = 32_768;

        /// Converts a `PCWSTR` to a Rust `String`.
        ///
        /// Returns a truncated string if the input exceeds 32,768 characters.
        /// This prevents unbounded scanning on malformed pointers.
        pub(crate) unsafe fn pcwstr_to_string(ptr: PCWSTR) -> String {
            if ptr.is_null() {
                return String::new();
            }
            let mut len = 0usize;
            while len < MAX_WIDE_CHARS && *(ptr.0.offset(len as isize)) != 0 {
                len += 1;
            }
            let slice = std::slice::from_raw_parts(ptr.0, len);
            String::from_utf16_lossy(slice)
        }

        /// Sends raw bytes over the pipe and returns the raw response bytes.
        pub fn send_raw_request(
            pipe_name: &str,
            payload: &[u8],
            timeout_ms: u32,
        ) -> Result<Vec<u8>, PipeError> {
            let pipe = connect_pipe(pipe_name, timeout_ms)?;
            unsafe {
                let mode = PIPE_READMODE_MESSAGE;
                let _ = SetNamedPipeHandleState(pipe, Some(&mode), None, None);
            }
            if let Err(e) = write_frame(pipe, payload) {
                let _ = unsafe { CloseHandle(pipe) };
                return Err(e);
            }
            let frame = match read_frame(pipe, timeout_ms) {
                Ok(f) => f,
                Err(e) => {
                    let _ = unsafe { CloseHandle(pipe) };
                    return Err(e);
                }
            };
            let _ = unsafe { CloseHandle(pipe) };
            Ok(frame)
        }
