    9. Add module declaration to dlp-hook-dll/src/lib.rs: pub mod health_counters;

    - test_health_snapshot_computation: Verify cache_hit_rate is computed correctly
    - test_health_snapshot_resets_counters: Verify emit_health_snapshot resets 60s counters to 0
    - test_health_snapshot_zero_counters: Verify 0/0 case returns 0.0 hit rate

| Boundary | Description |
|----------|-------------|
| Hook DLL internal (trampoline -> hash_compute) | Trusted; buffer pointer comes from hooked API call |
| Hook DLL -> Agent pipe | Untrusted; health snapshots and diagnostic data are read-only from agent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58-05 | Denial of Service | Trampoline hash computation | mitigate | Inline for <64KB, thread pool for larger; 100MB cap; skipped flag on failure |
| T-58-06 | Information Disclosure | Diagnostic snapshot in ring buffer | mitigate | No PII beyond SID and path; 1-hour expiry; in-memory only |
| T-58-07 | Tampering | Health counter manipulation | accept | Counters are atomic and read-only from agent; no operator write path exists |
</threat_model>
