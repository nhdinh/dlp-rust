# Plan 58-01: Foundational Hook DLL Modules

## Objective

Create `diagnostic_snapshot.rs` and `content_hasher.rs` modules in the hook DLL with a versioned IPC envelope (`IpcPayloadV2`) to avoid bincode compatibility breaks, wall-clock timestamps for cross-process sorting, and non-blocking hash computation with saturation fallback.

## Background

The original plan appended new variants directly to `IpcPayloadV1`, which breaks bincode deserialization when old agents talk to new hook DLLs. The revised plan introduces `IpcPayloadV2` as a versioned envelope wrapping a nested enum, preserving backward compatibility. It also replaces QPC-only timestamps with `DateTime<Utc>` for wall-clock display and switches from `rayon::install` (blocking) to a bounded channel + timeout for hash computation.

## must_haves

- truths:
  - IpcPayloadV2 uses a versioned envelope pattern; bincode compatibility is preserved
  - DiagnosticSnapshot includes timestamp_utc for wall-clock display and severity derived from enforcement_mode
  - ContentHasher uses non-blocking submission with hash_skipped fallback on saturation
  - ENTRY_EXPIRY uses SystemTime, not raw QPC ticks

Create `crates/dlp-hook-dll/src/content_hasher.rs`:

- Use `sha2::Sha256` from the `sha2` crate (add to `Cargo.toml` if missing).
- Use a bounded crossbeam channel (`bounded(16)`) for hash job submission instead of `rayon::install`.
- Spawn a single background thread (via `std::thread::spawn`) that receives `(Vec<u8>, oneshot::Sender<String>)` jobs from the channel.
- Use `OnceLock` to lazily initialize the channel sender and background thread from trampoline context.
- Provide `fn compute_hash_async(buffer: Vec<u8>) -> (Option<String>, bool, Option<u64>)` that:
  - If buffer.len() > 100_000_000 (100MB), returns `(None, true, None)` (hash_skipped = true)
  - If channel is full (16 pending jobs), returns `(None, true, None)` (hash_skipped = true)
  - Otherwise sends job, waits up to 50ms on the oneshot receiver, returns `(Some(hex_hash), false, Some(elapsed_us))` on success or `(None, true, None)` on timeout
- Provide `fn compute_hash_sync(buffer: &[u8]) -> String` for small buffers (<= 64KB) that computes directly on the calling thread.
- Add `hex` crate dependency to `Cargo.toml` for hex encoding.
- Add unit tests:
  - `test_small_buffer_hash_sync`
  - `test_large_buffer_skipped`
  - `test_channel_full_fallback`
</action>
