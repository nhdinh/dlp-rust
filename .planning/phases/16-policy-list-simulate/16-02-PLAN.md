# Phase 16 — Wave 2: Policy Simulate (Full Implementation)

## Goal

Implement the complete `PolicySimulate` screen:
- `action_open_simulate` — creates the screen with fresh state
- `action_submit_simulate` — builds `EvaluateRequest`, POSTs to `/evaluate`, stores result
- `handle_policy_simulate` / `handle_simulate_editing` / `handle_simulate_nav` — keyboard event handlers
- `draw_policy_simulate` — multi-row form renderer with section headers and inline result block

**No new types or screen variants are needed** — Wave 1 already added those.

## Cross-AI Review Feedback Incorporated

This plan has been updated based on cross-AI review feedback (16-REVIEWS.md):

- **Client-side validation (HIGH)**: Added pre-submit validation for empty `resource` and `user` fields. Malformed inputs are rejected with an inline error before hitting the server.
- **`groups_raw` normalization (MEDIUM)**: Groups are now trimmed, deduplicated while preserving order, lowercased, and length-capped (max 100 SIDs, max 256 chars per SID) to prevent oversized payloads and inconsistent matching. Uses `IndexSet`-style order-preserving deduplication via `Vec` + `HashSet` tracking.
- **Reproducible simulations (MEDIUM)**: Added optional `timestamp_override` and `session_id_override` fields to `SimulateFormState` (hidden behind an "Advanced" toggle, default off). Default behavior remains `Utc::now()` / `session_id = 0`.
- **Loading state (LOW)**: Added a `SimulateOutcome::Loading` variant. The submit row shows "Submitting..." and input is disabled during the network request.
- **Error granularity (LOW)**: Distinguishes timeout vs connection vs decode errors using `reqwest::Error` kind matching instead of lumping all under "Network error".
- **Select cycling UX (LOW)**: Current selected option is explicitly shown in the label (e.g., `Device Trust: Unmanaged [2/4]`).
- **Input length caps**: All text fields capped at 256 chars; `groups_raw` capped at 4096 chars to prevent accidental oversized payloads.
- **Timestamp format hint**: UI shows ISO 8601 example format when advanced section is visible.
- **FormMode enum guidance**: Task 5 includes guidance for a `FormMode` enum to reduce state explosion, while preserving consistency with Phase 14/15 patterns.

### Task 3 — Implement `action_submit_simulate` with validation, normalization, and granular errors

**read_first:**
- `dlp-admin-cli/src/screens/dispatch.rs` (end of file, Wave 1 stub location)
- `dlp-common/src/abac.rs` (lines 167–189, `EvaluateRequest` struct definition)

**action:** Add the following function after `action_open_simulate`. This function:
1. Validates minimum required fields (non-empty `user_sid` and `path`).
2. Normalizes `groups_raw` (trim, dedupe preserving order, lowercase, length caps).
3. Builds the `EvaluateRequest` with optional timestamp/session_id overrides.
4. POSTs to `/evaluate` with a `Loading` state during the request.
5. Stores the outcome with granular error classification (timeout vs connection vs decode vs server).

```rust
/// Validates the simulate form, builds an EvaluateRequest, POSTs to /evaluate,
/// and stores the outcome in the screen's result field.
///
/// On success: result = SimulateOutcome::Success(response).
/// On validation failure: result = SimulateOutcome::Error("Validation error: ...").
/// On reqwest timeout: result = SimulateOutcome::Error("Timeout: ...").
/// On reqwest connection failure: result = SimulateOutcome::Error("Connection error: ...").
/// On reqwest decode failure: result = SimulateOutcome::Error("Decode error: ...").
/// On server 4xx/5xx: result = SimulateOutcome::Error("Server error: ...").
fn action_submit_simulate(app: &mut App) {
    // Clone form out of the screen to avoid borrow conflicts.
    let form = match &app.screen {
        Screen::PolicySimulate { form, .. } => form.clone(),
        _ => return,
    };

    // --- Validation ---
    let mut validation_errors: Vec<String> = Vec::new();
    if form.user_sid.trim().is_empty() {
        validation_errors.push("User SID is required".to_string());
    }
    if form.path.trim().is_empty() {
        validation_errors.push("Path is required".to_string());
    }
    if form.user_sid.len() > SIMULATE_MAX_FIELD_LEN {
        validation_errors.push(format!("User SID exceeds {SIMULATE_MAX_FIELD_LEN} characters"));
    }
    if form.user_name.len() > SIMULATE_MAX_FIELD_LEN {
        validation_errors.push(format!("User Name exceeds {SIMULATE_MAX_FIELD_LEN} characters"));
    }
    if form.path.len() > SIMULATE_MAX_FIELD_LEN {
        validation_errors.push(format!("Path exceeds {SIMULATE_MAX_FIELD_LEN} characters"));
    }
    if form.groups_raw.len() > SIMULATE_MAX_GROUPS_LEN {
        validation_errors.push(format!(
            "Groups buffer exceeds {SIMULATE_MAX_GROUPS_LEN} characters"
        ));
    }
    if !validation_errors.is_empty() {
        if let Screen::PolicySimulate { result, .. } = &mut app.screen {
            *result = SimulateOutcome::Error(format!(
                "Validation error: {}",
                validation_errors.join("; ")
            ));
        }
        return;
    }

    // --- Normalize groups (preserve order, dedupe, lowercase) ---
    let mut seen = std::collections::HashSet::new();
    let groups: Vec<String> = form
        .groups_raw
        .split(',')
        .map(|s| s.trim().to_lowercase())
        .filter(|s| {
            if s.is_empty() || s.len() > SIMULATE_MAX_GROUP_SID_LEN {
                return false;
            }
            seen.insert(s.clone())
        })
        .take(SIMULATE_MAX_GROUP_COUNT)
        .collect();

    // --- Map select indices to typed ABAC enums ---
    use dlp_common::abac::{
        AccessContext, Action, DeviceTrust, Environment, EvaluateRequest,
        NetworkLocation, Resource, Subject,
    };
    use dlp_common::Classification;

    let device_trust_vals: [DeviceTrust; 4] = [
        DeviceTrust::Managed,
        DeviceTrust::Unmanaged,
        DeviceTrust::Compliant,
        DeviceTrust::Unknown,
    ];
    let network_location_vals: [NetworkLocation; 4] = [
        NetworkLocation::Corporate,
        NetworkLocation::CorporateVpn,
        NetworkLocation::Guest,
        NetworkLocation::Unknown,
    ];
    let classification_vals: [Classification; 4] = [
        Classification::T1,
        Classification::T2,
        Classification::T3,
        Classification::T4,
    ];
    let action_vals: [Action; 6] = [
        Action::READ,
        Action::WRITE,
        Action::COPY,
        Action::DELETE,
        Action::MOVE,
        Action::PASTE,
    ];
    let access_context_vals: [AccessContext; 2] = [AccessContext::Local, AccessContext::Smb];

    // --- Parse optional overrides ---
    let timestamp = if form.timestamp_override.trim().is_empty() {
        chrono::Utc::now()
    } else {
        match form.timestamp_override.trim().parse::<chrono::DateTime<chrono::Utc>>() {
            Ok(ts) => ts,
            Err(_) => {
                if let Screen::PolicySimulate { result, .. } = &mut app.screen {
                    *result = SimulateOutcome::Error(
                        "Validation error: timestamp_override must be ISO 8601 (e.g. 2024-01-01T00:00:00Z)".to_string(),
                    );
                }
                return;
            }
        }
    };

    let session_id = if form.session_id_override.trim().is_empty() {
        0
    } else {
        match form.session_id_override.trim().parse::<u64>() {
            Ok(id) => id,
            Err(_) => {
                if let Screen::PolicySimulate { result, .. } = &mut app.screen {
                    *result = SimulateOutcome::Error(
                        "Validation error: session_id_override must be a non-negative integer".to_string(),
                    );
                }
                return;
            }
        }
    };

    let req = EvaluateRequest {
        subject: Subject {
            user_sid: form.user_sid.trim().to_string(),
            user_name: form.user_name.trim().to_string(),
            groups,
            device_trust: *device_trust_vals
                .get(form.device_trust)
                .unwrap_or(&DeviceTrust::Unmanaged),
            network_location: *network_location_vals
                .get(form.network_location)
                .unwrap_or(&NetworkLocation::Unknown),
        },
        resource: Resource {
            path: form.path.trim().to_string(),
            classification: *classification_vals
                .get(form.classification)
                .unwrap_or(&Classification::T1),
        },
        environment: Environment {
            timestamp,
            session_id,
            access_context: *access_context_vals
                .get(form.access_context)
                .unwrap_or(&AccessContext::Local),
        },
        action: *action_vals.get(form.action).unwrap_or(&Action::READ),
        agent: None,
    };

    // Set loading state before the blocking call.
    if let Screen::PolicySimulate { result, .. } = &mut app.screen {
        *result = SimulateOutcome::Loading;
    }

    let result = app.rt.block_on(
        app.client
            .post::<dlp_common::abac::EvaluateResponse>("evaluate", &req),
    );

    // Store outcome in screen (result field is &mut, needs to happen after block_on).
    if let Screen::PolicySimulate { result: out_result, .. } = &mut app.screen {
        match result {
            Ok(resp) => {
                *out_result = SimulateOutcome::Success(resp);
            }
            Err(e) => {
                let msg = e.to_string();
                let prefix = if let Some(req_err) = e.downcast_ref::<reqwest::Error>() {
                    if req_err.is_timeout() {
                        "Timeout: "
                    } else if req_err.is_connect() {
                        "Connection error: "
                    } else if req_err.is_decode() {
                        "Decode error: "
                    } else {
                        "Network error: "
                    }
                } else {
                    "Server error: "
                };
                *out_result = SimulateOutcome::Error(format!("{prefix}{msg}"));
            }
        }
    }
}
```

/// Handles key events while editing a text field in the Policy Simulate form.
///
/// Text rows: 0 = user_sid, 1 = user_name, 2 = groups_raw, 5 = path.
/// Advanced rows (when visible): 10 = timestamp_override, 11 = session_id_override.
fn handle_simulate_editing(app: &mut App, key: KeyEvent, _selected: usize) {
    match key.code {
        KeyCode::Char(c) => {
            if let Screen::PolicySimulate { buffer, .. } = &mut app.screen {
                buffer.push(c);
            }
        }
        KeyCode::Backspace => {
            if let Screen::PolicySimulate { buffer, .. } = &mut app.screen {
                buffer.pop();
            }
        }
        KeyCode::Enter => {
            // Commit buffer to the appropriate field, then exit edit mode.
            let (selected, buf) = match &app.screen {
                Screen::PolicySimulate {
                    selected, buffer, ..
                } => (*selected, buffer.clone()),
                _ => return,
            };
            if let Screen::PolicySimulate {
                form,
                buffer,
                editing,
                ..
            } = &mut app.screen
            {
                match selected {
                    0 => form.user_sid = buf.trim().to_string(),
                    1 => form.user_name = buf.trim().to_string(),
                    2 => form.groups_raw = buf.clone(), // Preserve exact formatting.
                    5 => form.path = buf.trim().to_string(),
                    10 => form.timestamp_override = buf.trim().to_string(),
                    11 => form.session_id_override = buf.trim().to_string(),
                    _ => {}
                }
                buffer.clear();
                *editing = false;
            }
        }
        KeyCode::Esc => {
            // Cancel edit; restore field to pre-edit value.
            if let Screen::PolicySimulate {
                buffer, editing, ..
            } = &mut app.screen
            {
                buffer.clear();
                *editing = false;
            }
        }
        _ => {}
    }
}
```

```rust
/// Handles key events while navigating the Policy Simulate form (not editing).
fn handle_simulate_nav(app: &mut App, key: KeyEvent, selected: usize) {
    // Determine effective row count based on advanced section visibility.
    let row_count = match &app.screen {
        Screen::PolicySimulate { form, .. } => {
            if form.advanced_visible {
                SIMULATE_ROW_COUNT + 2 // +2 for timestamp_override and session_id_override
            } else {
                SIMULATE_ROW_COUNT
            }
        }
        _ => SIMULATE_ROW_COUNT,
    };

    match key.code {
        KeyCode::Up | KeyCode::Down => {
            if let Screen::PolicySimulate { selected: sel, .. } = &mut app.screen {
                nav(sel, row_count, key.code);
            }
        }
        KeyCode::Enter => match selected {
            // Text field rows: 0 (user_sid), 1 (user_name), 5 (path) — enter edit mode.
            0 | 1 | 5 => {
                if let Screen::PolicySimulate {
                    form,
                    editing,
                    buffer,
                    ..
                } = &mut app.screen
                {
                    let pre_fill = match selected {
                        0 => form.user_sid.clone(),
                        1 => form.user_name.clone(),
                        5 => form.path.clone(),
                        _ => return,
                    };
                    *buffer = pre_fill;
                    *editing = true;
                }
            }
            // Groups row (2): free-text comma-separated SID input.
            2 => {
                if let Screen::PolicySimulate {
                    form, editing, buffer, ..
                } = &mut app.screen
                {
                    *buffer = form.groups_raw.clone();
                    *editing = true;
                }
            }
            // Select rows: Enter cycles to next option.
            3 => {
                if let Screen::PolicySimulate { form, .. } = &mut app.screen {
                    form.device_trust = (form.device_trust + 1) % SIMULATE_DEVICE_TRUST_OPTIONS.len();
                }
            }
            4 => {
                if let Screen::PolicySimulate { form, .. } = &mut app.screen {
                    form.network_location =
                        (form.network_location + 1) % SIMULATE_NETWORK_LOCATION_OPTIONS.len();
                }
            }
            6 => {
                if let Screen::PolicySimulate { form, .. } = &mut app.screen {
                    form.classification =
                        (form.classification + 1) % SIMULATE_CLASSIFICATION_OPTIONS.len();
                }
            }
            7 => {
                if let Screen::PolicySimulate { form, .. } = &mut app.screen {
                    form.action = (form.action + 1) % SIMULATE_ACTION_OPTIONS.len();
                }
            }
            8 => {
                if let Screen::PolicySimulate { form, .. } = &mut app.screen {
                    form.access_context =
                        (form.access_context + 1) % SIMULATE_ACCESS_CONTEXT_OPTIONS.len();
                }
            }
            // [Simulate] submit row (index 9).
            SIMULATE_SUBMIT_ROW => {
                action_submit_simulate(app);
            }
            // Advanced fields (10, 11) — text edit mode.
            10 | 11 => {
                if let Screen::PolicySimulate {
                    form,
                    editing,
                    buffer,
                    ..
                } = &mut app.screen
                {
                    let pre_fill = match selected {
                        10 => form.timestamp_override.clone(),
                        11 => form.session_id_override.clone(),
                        _ => return,
                    };
                    *buffer = pre_fill;
                    *editing = true;
                }
            }
            _ => {}
        },
        KeyCode::Char('a') => {
            // Toggle advanced section visibility.
            if let Screen::PolicySimulate { form, .. } = &mut app.screen {
                form.advanced_visible = !form.advanced_visible;
            }
        }
        KeyCode::Esc | KeyCode::Char('q') => {
            // Return to the caller screen, keeping the Simulate Policy row selected.
            let caller = match &app.screen {
                Screen::PolicySimulate { caller, .. } => *caller,
                _ => return,
            };
            match caller {
                SimulateCaller::MainMenu => {
                    app.screen = Screen::MainMenu { selected: 3 };
                }
                SimulateCaller::PolicyMenu => {
                    app.screen = Screen::PolicyMenu { selected: 5 };
                }
            }
        }
        _ => {}
    }
}

This renders a 10-row form with section headers, proper cyan highlight on the selected row, an edit-mode cursor pattern `[{buffer}_]`, select rows showing current option with index indicator (e.g., `[2/4]`), an inline result block below the form, and an optional advanced section.

```rust
/// Maps an editable `selected` index (0..=9, or 0..=11 with advanced) to the render-list position.
///
/// Section headers are interspersed at fixed render positions, so the editable
/// `selected` index does not match the render list position 1:1.
/// This lookup table is the single source of truth for the render/dispatch pair.
const EDITABLE_TO_RENDER: [usize; 10] = [
    0,  // User SID
    1,  // User Name
    2,  // Groups
    4,  // Device Trust  (render row 3 = "--- Subject ---" header)
    5,  // Network Location
    7,  // Path          (render row 6 = "--- Resource ---" header)
    8,  // Classification
    10, // Action        (render row 9 = "--- Environment ---" header)
    11, // Access Context
    13, // [Simulate]    (render row 12 = "--- Submit ---" header)
];

/// Builds the full render list (13+ ListItems) for the simulate form.
///
/// The list includes 4 section-header rows interleaved with 10 editable rows.
/// If advanced_visible is true, 2 additional rows (timestamp_override, session_id_override)
/// are appended after the Submit section.
fn build_simulate_items(
    form: &SimulateFormState,
    selected: usize,
    editing: bool,
    buffer: &str,
) -> Vec<ListItem<'static>> {
    let mut items = Vec::with_capacity(16);

    // Helper: append a section header row.
    let push_header = |label: &'static str, items: &mut Vec<_>| {
        let line = Line::styled(
            format!("  {label}"),
            Style::default()
                .fg(Color::DarkGray)
                .add_modifier(Modifier::BOLD),
        );
        items.push(ListItem::new(line));
    };

    // Helper: append an editable row.
    let push_row = |label: &str, value: &str, items: &mut Vec<_>, is_selected: bool, is_editing: bool| {
        let line = if is_selected && is_editing {
            // Cursor indicator: "[{buffer}_]"
            Line::from(format!("{label:width$}[{buffer}_]", width = label_col_width()))
        } else if value.is_empty() {
            Line::from(vec![
                Span::raw(format!("{label:width$}", width = label_col_width())),
                Span::styled("(empty)", Style::default().fg(Color::DarkGray)),
            ])
        } else {
            Line::from(format!("{label:width$}{value}", width = label_col_width()))
        };
        let item = ListItem::new(line);
        items.push(item);
    };

    // Helper: append a select row (shows current option label with index indicator).
    let push_select = |label: &str, option_label: &str, idx: usize, total: usize, items: &mut Vec<_>| {
        let display = format!("{label:width$}{option_label} [{idx}/{total}]", width = label_col_width());
        let line = Line::from(display);
        items.push(ListItem::new(line));
    };

    // Helper: append an action row (non-editable, e.g. [Simulate]).
    let push_action = |label: &str, items: &mut Vec<_>| {
        items.push(ListItem::new(Line::from(format!("  {label}"))));
    };

    // --- Row 0: User SID ---
    push_row("User SID:", &form.user_sid, &mut items, selected == 0, editing);

    // --- Row 1: User Name ---
    push_row("User Name:", &form.user_name, &mut items, selected == 1, editing);

    // --- Row 2: Groups ---
    push_row("Groups (comma-SIDs):", &form.groups_raw, &mut items, selected == 2, editing);

    // --- Row 3: "--- Subject ---" header ---
    push_header("--- Subject ---", &mut items);

    // --- Row 4: Device Trust (select) ---
    let dt = SIMULATE_DEVICE_TRUST_OPTIONS
        .get(form.device_trust)
        .unwrap_or(&"Unknown");
    push_select("Device Trust:", dt, form.device_trust + 1, SIMULATE_DEVICE_TRUST_OPTIONS.len(), &mut items);

    // --- Row 5: Network Location (select) ---
    let nl = SIMULATE_NETWORK_LOCATION_OPTIONS
        .get(form.network_location)
        .unwrap_or(&"Unknown");
    push_select("Network Location:", nl, form.network_location + 1, SIMULATE_NETWORK_LOCATION_OPTIONS.len(), &mut items);

    // --- Row 6: "--- Resource ---" header ---
    push_header("--- Resource ---", &mut items);

    // --- Row 7: Path ---
    push_row("Path:", &form.path, &mut items, selected == 5, editing);

    // --- Row 8: Classification (select) ---
    let cl = SIMULATE_CLASSIFICATION_OPTIONS
        .get(form.classification)
        .unwrap_or(&"T1");
    push_select("Classification:", cl, form.classification + 1, SIMULATE_CLASSIFICATION_OPTIONS.len(), &mut items);

    // --- Row 9: "--- Environment ---" header ---
    push_header("--- Environment ---", &mut items);

    // --- Row 10: Action (select) ---
    let ac = SIMULATE_ACTION_OPTIONS.get(form.action).unwrap_or(&"READ");
    push_select("Action:", ac, form.action + 1, SIMULATE_ACTION_OPTIONS.len(), &mut items);

    // --- Row 11: Access Context (select) ---
    let cx = SIMULATE_ACCESS_CONTEXT_OPTIONS
        .get(form.access_context)
        .unwrap_or(&"Local");
    push_select("Access Context:", cx, form.access_context + 1, SIMULATE_ACCESS_CONTEXT_OPTIONS.len(), &mut items);

    // --- Row 12: "--- Submit ---" header ---
    push_header("--- Submit ---", &mut items);

    // --- Row 13: [Simulate] button ---
    push_action("[Simulate]", &mut items);

    // --- Advanced section (optional) ---
    if form.advanced_visible {
        push_header("--- Advanced ---", &mut items);
        push_row(
            "Timestamp (ISO 8601):",
            &form.timestamp_override,
            &mut items,
            selected == 10,
            editing,
        );
        push_row(
            "Session ID:",
            &form.session_id_override,
            &mut items,
            selected == 11,
            editing,
        );
    }

    items
}

/// Returns the fixed-width column width for field labels (22 chars, per Phase 14 UI-SPEC).
fn label_col_width() -> usize {
    22
}

/// Draws the Policy Simulate multi-field form with an inline result block.
fn draw_policy_simulate(
    frame: &mut Frame,
    area: Rect,
    form: &SimulateFormState,
    selected: usize,
    editing: bool,
    buffer: &str,
    result: &SimulateOutcome,
) {
    let items = build_simulate_items(form, selected, editing, buffer);
    let render_selected = *EDITABLE_TO_RENDER.get(selected).unwrap_or(&0);

    let list = List::new(items)
        .block(
            Block::default()
                .title(" Policy Simulate ")
                .borders(Borders::ALL),
        )
        .highlight_style(
            Style::default()
                .fg(Color::Black)
                .bg(Color::Cyan)
                .add_modifier(Modifier::BOLD),
        )
        .highlight_symbol("> ");

    let mut state = ListState::default();
    state.select(Some(render_selected));
    frame.render_stateful_widget(list, area, &mut state);

    // Inline result block: positioned at the bottom of the form area.
    // Height is 4 rows: 3 for success (Matched policy / Decision / Reason) + 1 border.
    const RESULT_HEIGHT: u16 = 5;
    if area.height > RESULT_HEIGHT + 2 {
        let result_area = Rect {
            x: area.x + 2,
            y: area.y.saturating_add(area.height).saturating_sub(RESULT_HEIGHT + 1),
            width: area.width.saturating_sub(4),
            height: RESULT_HEIGHT,
        };

        match result {
            SimulateOutcome::None => {
                // Nothing to render — form only.
            }
            SimulateOutcome::Loading => {
                let block = Block::default()
                    .title(" Submitting... ")
                    .borders(Borders::ALL)
                    .border_style(Style::default().fg(Color::Yellow));
                frame.render_widget(
                    Paragraph::new("Evaluating policy... please wait.")
                        .style(Style::default().fg(Color::Yellow))
                        .block(block),
                    result_area,
                );
            }
            SimulateOutcome::Success(resp) => {
                let decision_color = if resp.decision.is_denied() {
                    Color::Red
                } else {
                    Color::Green
                };
                let matched = resp
                    .matched_policy_id
                    .as_deref()
                    .unwrap_or("none");
                let lines = vec![
                    Line::from(format!("Matched policy:  {matched}")),
                    Line::from(vec![
                        Span::raw("Decision:        "),
                        Span::styled(
                            format!("{:?}", resp.decision),
                            Style::default().fg(decision_color),
                        ),
                    ]),
                    Line::from(format!("Reason:          {}", resp.reason)),
                ];
                let block = Block::default()
                    .title(" Result ")
                    .borders(Borders::ALL)
                    .border_style(Style::default().fg(Color::Green));
                frame.render_widget(Paragraph::new(lines).block(block), result_area);
            }
            SimulateOutcome::Error(msg) => {
                let block = Block::default()
                    .title(" Error ")
                    .borders(Borders::ALL)
                    .border_style(Style::default().fg(Color::Red));
                frame.render_widget(
                    Paragraph::new(msg.as_str())
                        .style(Style::default().fg(Color::Red))
                        .block(block),
                    result_area,
                );
            }
        }
    }

    let hints = if editing {
        "Type to edit | Enter: commit | Esc: cancel"
    } else if matches!(result, SimulateOutcome::Loading) {
        "Submitting... | please wait"
    } else {
        "Up/Down: navigate | Enter: select/cycle | a: advanced | Esc: back"
    };
    draw_hints(frame, area, hints);
}
```
