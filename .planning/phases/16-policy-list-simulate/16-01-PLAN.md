# Phase 16 — Wave 1: Shared Types + Policy List Polish

## Goal

Deliver two tightly-coupled changes that unlock the full Phase 16 scope:

1. **Shared types** (required by both POLICY-01 and POLICY-06):
   - `SimulateCaller` enum
   - `SimulateOutcome` enum
   - `SimulateFormState` struct
   - `Screen::PolicySimulate` variant
   - `chrono = "0.4"` dependency
   - Wiring in `handle_event` and `draw_screen`

2. **POLICY-01 policy-list polish**:
   - Rewrite `draw_policy_list` columns to `Priority / Name / Action / Enabled`
   - Client-side sort by `priority` asc + `name` case-insensitive asc in `action_list_policies`
   - `Char('n')` branch in `handle_policy_list` → `Screen::PolicyCreate`
   - Update footer hints to `"n: new | e: edit | d: delete | Enter: view | Esc: back"`

## Cross-AI Review Feedback Incorporated

This plan has been updated based on cross-AI review feedback (16-REVIEWS.md):

- **Type extraction**: Simulate-related types moved to a dedicated `simulate.rs` module (was `app.rs`) to prevent file bloat.
- **Malformed priority visibility**: Malformed priorities are logged once per policy during the fetch/sort phase (not on every render) and visually marked as `"ERR"` in the Priority column.
- **Stable sort**: Uses `sort_by` with `then_with` for deterministic ordering. Documents that ties on priority+name are acceptable to reorder since policy IDs are not stable across refreshes.
- **Selection preservation**: After sort, selection index is reset to 0 (safe default) since policy IDs are not stable across list refreshes.
- **Stub UX**: The `draw_policy_simulate` stub renders a "Not implemented — Wave 2" message instead of a blank screen.

### Task 4 — Rewrite `draw_policy_list` columns, widths, hints, and malformed priority handling

```rust
/// Draws a scrollable policy table.
///
/// Malformed priority values are rendered as "ERR" in the Priority column.
/// Logging happens during fetch/sort (action_list_policies), not here,
/// to avoid log spam on every render.
fn draw_policy_list(
    frame: &mut Frame,
    area: Rect,
    policies: &[serde_json::Value],
    selected: usize,
) {
    let header = Row::new(vec!["Priority", "Name", "Action", "Enabled"])
        .style(Style::default().add_modifier(Modifier::BOLD))
        .bottom_margin(1);

    let rows: Vec<Row> = policies
        .iter()
        .map(|p| {
            let priority_str = match p["priority"]
                .as_u64()
                .and_then(|v| u32::try_from(v).ok())
            {
                Some(v) => v.to_string(),
                None => "ERR".to_string(),
            };
            let action = p["action"].as_str().unwrap_or("-");
            let enabled = if p["enabled"].as_bool().unwrap_or(false) {
                "Yes"
            } else {
                "No"
            };
            Row::new(vec![
                priority_str,
                p["name"].as_str().unwrap_or("-").to_string(),
                action.to_string(),
                enabled.to_string(),
            ])
        })
        .collect();

    let widths = [
        Constraint::Percentage(15), // Priority
        Constraint::Percentage(45), // Name
        Constraint::Percentage(20), // Action
        Constraint::Percentage(20), // Enabled
    ];

    let table = Table::new(rows, widths)
        .header(header)
        .block(
            Block::default()
                .title(format!(" Policies ({}) ", policies.len()))
                .borders(Borders::ALL),
        )
        .row_highlight_style(
            Style::default()
                .fg(Color::Black)
                .bg(Color::Cyan)
                .add_modifier(Modifier::BOLD),
        )
        .highlight_symbol("> ");

    let mut state = ratatui::widgets::TableState::default();
    state.select(Some(selected));
    frame.render_stateful_widget(table, area, &mut state);

    draw_hints(
        frame,
        area,
        "n: new | e: edit | d: delete | Enter: view | Esc: back",
    );
}
```

### Task 6 — Inject client-side sort in `action_list_policies` with stable comparison

**read_first:** `dlp-admin-cli/src/screens/dispatch.rs` (lines 458–475, `action_list_policies` function)

**action:** Replace the body of `action_list_policies` with the following. The `Ok(policies)` block changes to sort before assigning. Selection resets to 0 after sort since policy IDs are not stable across refreshes. Malformed priorities are logged once during fetch (not on every render) and sink to bottom via `u32::MAX`.

```rust
fn action_list_policies(app: &mut App) {
    match app
        .rt
        .block_on(app.client.get::<Vec<serde_json::Value>>("policies"))
    {
        Ok(policies) => {
            app.set_status(
                format!("Loaded {} policies", policies.len()),
                StatusKind::Success,
            );
            // Client-side sort: primary key = priority ascending (malformed = u32::MAX sinks to bottom);
            // secondary key = name case-insensitive ascending for deterministic tiebreak.
            // Uses to_ascii_lowercase for deterministic, locale-independent ordering.
            // Note: sort_by is not stable; ties may reorder across refreshes, which is
            // acceptable since policy IDs are not stable across list refreshes anyway.
            let mut sorted = policies;
            sorted.sort_by(|a, b| {
                let pa = a["priority"]
                    .as_u64()
                    .and_then(|v| u32::try_from(v).ok())
                    .unwrap_or(u32::MAX);
                let pb = b["priority"]
                    .as_u64()
                    .and_then(|v| u32::try_from(v).ok())
                    .unwrap_or(u32::MAX);
                pa.cmp(&pb).then_with(|| {
                    let na = a["name"].as_str().unwrap_or("").to_ascii_lowercase();
                    let nb = b["name"].as_str().unwrap_or("").to_ascii_lowercase();
                    na.cmp(&nb)
                })
            });
            // Log malformed priorities once during fetch, not on every render.
            for p in &sorted {
                if p["priority"].as_u64().and_then(|v| u32::try_from(v).ok()).is_none() {
                    let name = p["name"].as_str().unwrap_or("(unnamed)");
                    tracing::warn!(
                        policy_name = %name,
                        raw_priority = ?p["priority"],
                        "Malformed priority value in policy list; rendering as ERR"
                    );
                }
            }
            app.screen = Screen::PolicyList {
                policies: sorted,
                selected: 0,
            };
        }
        Err(e) => app.set_status(format!("Failed: {e}"), StatusKind::Error),
    }
}
```

- `grep -n "sorted.sort_by" dlp-admin-cli/src/screens/dispatch.rs` returns the sort block with primary key `pa.cmp(&pb)` and secondary `na.cmp(&nb)` using `.to_ascii_lowercase()`
- `grep -n "unwrap_or(u32::MAX)" dlp-admin-cli/src/screens/dispatch.rs` returns two occurrences (one for each priority extraction)
