    Add the following static counters to perf_telemetry.rs (outside the PerfTelemetry struct, as process-level counters):
    ```rust
    use std::sync::atomic::{AtomicU64, AtomicU8, Ordering};

    static PIPE_ROUND_TRIPS: AtomicU64 = AtomicU64::new(0);
    static CACHE_HITS_60S: AtomicU64 = AtomicU64::new(0);
    static CACHE_MISSES_60S: AtomicU64 = AtomicU64::new(0);
    static CURRENT_FAIL_STATE: AtomicU8 = AtomicU8::new(0); // 0=Healthy, 1=Degraded, 2=Isolated, 3=Resync
    static INJECTED_PIDS: AtomicU64 = AtomicU64::new(0);
    static PATCHED_MODULES: AtomicU64 = AtomicU64::new(0);
    ```

    Add public helper functions to increment these counters:
    ```rust
    pub fn record_pipe_round_trip() { PIPE_ROUND_TRIPS.fetch_add(1, Ordering::Relaxed); }
    pub fn record_cache_hit() { CACHE_HITS_60S.fetch_add(1, Ordering::Relaxed); }
    pub fn record_cache_miss() { CACHE_MISSES_60S.fetch_add(1, Ordering::Relaxed); }
    pub fn set_fail_state(state: u8) { CURRENT_FAIL_STATE.store(state, Ordering::Relaxed); }
    pub fn set_injected_pids(count: u64) { INJECTED_PIDS.store(count, Ordering::Relaxed); }
    pub fn set_patched_modules(count: u64) { PATCHED_MODULES.store(count, Ordering::Relaxed); }
    ```

    Add a function `emit_health_snapshot()` that:
    1. Reads and resets PIPE_ROUND_TRIPS, CACHE_HITS_60S, CACHE_MISSES_60S atomically.
    2. Computes cache_hit_rate_60s = hits / (hits + misses) or 0.0 if total is 0.
    3. Constructs a `dlp_common::hook_ipc::HookHealthSnapshot` with the current counter values.
    4. Returns the snapshot.

    ```rust
    pub fn emit_health_snapshot() -> dlp_common::hook_ipc::HookHealthSnapshot {
        let pipe_round_trips = PIPE_ROUND_TRIPS.swap(0, Ordering::Relaxed);
        let hits = CACHE_HITS_60S.swap(0, Ordering::Relaxed);
        let misses = CACHE_MISSES_60S.swap(0, Ordering::Relaxed);
        let total = hits + misses;
        let hit_rate = if total > 0 { (hits as f64) / (total as f64) } else { 0.0 };

        dlp_common::hook_ipc::HookHealthSnapshot {
            injected_pids: INJECTED_PIDS.load(Ordering::Relaxed),
            patched_modules: PATCHED_MODULES.load(Ordering::Relaxed),
            pipe_round_trips_60s: pipe_round_trips,
            cache_hit_rate_60s: hit_rate,
            current_fail_state: CURRENT_FAIL_STATE.load(Ordering::Relaxed),
            timestamp_secs: std::time::SystemTime::now()
                .duration_since(std::time::UNIX_EPOCH)
                .unwrap_or_default()
                .as_secs(),
        }
    }
    ```

    Add a separate static counter `HEALTH_EMIT_COUNTER: AtomicU64 = AtomicU64::new(0)` and a constant `HEALTH_EMIT_INTERVAL: u64 = 1000` (aligned with existing EMIT_INTERVAL). This counter must be incremented ONLY on actual pipe round-trips (cache misses), not inside `record_latency` which is called on every classification including ALLOW paths and cache hits.

    The correct increment point is in `classify_and_log_path` and `classify_and_log_handle` on cache miss (where a pipe call is made). After the pipe call returns (success or failure), increment `HEALTH_EMIT_COUNTER` and check if it is a multiple of `HEALTH_EMIT_INTERVAL`. If so, call `emit_health_snapshot()` and send it via `crate::pipe_client::send_health_snapshot` (to be added in Task 2).

    Modify `emit_state_transition_immediate` to also call `emit_health_snapshot` and send it via `crate::pipe_client::send_health_snapshot` (to be added in Task 2).

    Add a new public function `send_health_snapshot` to pipe_client.rs:
    ```rust
    pub fn send_health_snapshot(
        pipe_name: &str,
        snapshot: &dlp_common::hook_ipc::HookHealthSnapshot,
    ) -> Result<(), PipeError> {
        let envelope = dlp_common::hook_ipc::IpcEnvelope::V1(dlp_common::hook_ipc::IpcMessageV1 {
            payload: dlp_common::hook_ipc::IpcPayloadV1::HealthResponse(dlp_common::hook_ipc::HealthResponse {
                snapshot: snapshot.clone(),
            }),
        });
        let payload = match bincode::serialize(&envelope) {
            Ok(p) => p,
            Err(_) => return Err(PipeError::Malformed),
        };
        send_raw_oneway(pipe_name, &payload)
    }
    ```

    In perf_telemetry.rs, modify the pipe-round-trip path in classify_and_log_path and classify_and_log_handle to emit a health snapshot every 1000 pipe round-trips:
