### CR-01: Potential Use-After-Free in `get_current_user_sid` (sid.rs)

**Files modified:** `dlp-hook-dll/src/sid.rs`
**Commit:** efb3fb0
**Applied fix:** Added defense-in-depth comment clarifying the non-null pointer check before `CStr::from_ptr`. The existing code already had the null check; the fix adds an explicit safety comment to document the invariant.

### CR-02: QPC Expiry Calculation Uses Incorrect Ticks in `drain_snapshots` (diagnostic_ring.rs)

**Files modified:** `dlp-hook-dll/src/diagnostic_ring.rs`
**Commit:** 95c6bed
**Applied fix:**
- Replaced hard-coded `ENTRY_EXPIRY_QPC_TICKS = 36_000_000_000_000u64` with `ENTRY_EXPIRY_SECONDS = 3600`.
- Added `query_performance_frequency()` function to read actual QPC frequency at runtime.
- `drain_snapshots` now computes `one_hour_ticks = freq * 3600` dynamically.
- Switched `age` calculation from `saturating_sub` to `wrapping_sub` to handle QPC wrap-around safely (also addresses WR-03).
- Updated the expiry test to use the new runtime frequency calculation.

### WR-01: Mutex Poisoning Panics in `HealthAggregator` (health_aggregator.rs)

**Files modified:** `dlp-agent/src/health_aggregator.rs`
**Commit:** b61c09a
**Applied fix:** Replaced all 11 occurrences of `.expect("poisoned lock")` with `.unwrap_or_else(|e| { tracing::error!(...); e.into_inner() })` to recover from poisoned mutexes instead of crashing the agent process. Affected methods: `Debug::fmt`, `set_alert_router`, `ingest_snapshot`, `get_current_status`, `get_history`, `history_len`, and `emit_health_audit_event`.

### WR-02: Missing Error Handling in `send_health_snapshot` (pipe_client.rs)

**Files modified:** `dlp-hook-dll/src/pipe_client.rs`
**Commit:** 62cc3af
**Applied fix:** Added `tracing::warn!` logs when `bincode::serialize` fails in `send_hash_evidence` and `send_health_snapshot`, so serialization errors are not completely silent even when callers use `let _ =`. The functions already returned `Result<(), PipeError>`; the fix adds observability.

### WR-03: Integer Overflow Risk in `query_performance_counter` Wrapper (diagnostic_ring.rs)

**Files modified:** `dlp-hook-dll/src/diagnostic_ring.rs`
**Commit:** 95c6bed (fixed together with CR-02)
**Applied fix:** The `age` calculation in `drain_snapshots` now uses `wrapping_sub` instead of `saturating_sub`, preventing panic on QPC counter wrap-around.

### WR-04: Test Reliability Issue in `hook_ipc_integration.rs` (hook_ipc_integration.rs)

**Files modified:** `dlp-agent/tests/hook_ipc_integration.rs`
**Commit:** d5745f6
**Applied fix:**
- Added `shutdown_and_join` helper function that sets `request_shutdown()`, connects a dummy client to unblock `ConnectNamedPipe`, and joins the server thread with a short timeout.
- Replaced all `let _ = handle; dlp_agent::service::reset_shutdown_signal();` patterns across all integration tests with `shutdown_and_join(handle, pipe_name)`.
- This prevents pipe/thread exhaustion when serial tests run back-to-back.
