<objective>
Wire content SHA-256 hash computation into HookWriteFile and HookWriteFileEx deny branches so that every blocked write operation produces a forensic content hash. The hash is sent to the agent via a one-way HashEvidence IPC frame, stored in a TTL-governed HashCache, and attached to the AuditEvent. ALLOW paths and non-write DENY paths must not hash.

Purpose: DIFF-03 provides tamper-evident evidence of what content was blocked, satisfying forensic and compliance requirements.
Output: deny branches that compute SHA-256 with 100MB cap and pool-saturation fallback; agent-side HashCache and audit enrichment verified.
</objective>

  <files>dlp-hook-dll/src/hash_compute.rs</files>
  <action>
    Per D-07, the hash pool must skip computation when queue depth exceeds 4 pending hashes.

    Add a global AtomicU64 counter HASH_QUEUE_DEPTH that tracks pending offloaded hashes. Increment it before submitting to the pool, decrement in the pool closure after computation finishes (use a drop guard or explicit decrement). If the counter exceeds 4 at submission time, return (None, false, true) immediately (hash_skipped = true).

    For inline hashing (buffers < 64KB), do not check queue depth — inline hashing is synchronous and fast.

    Update compute_content_hash_offloaded signature to return (Option<String>, bool, bool) as before, but add the saturation check at the top:
    - If HASH_QUEUE_DEPTH.load(Relaxed) > 4, return (None, false, true).
    - Otherwise increment, submit to pool, and decrement when done.

    Ensure the decrement happens even if the pool panics (use a custom guard struct with Drop).
  </action>

    ```rust
        pipe_name: &str,
        frame: &dlp_common::hook_ipc::HashEvidenceFrame,
    ) -> Result<(), PipeError> {
        let envelope = dlp_common::hook_ipc::IpcEnvelope::V1(dlp_common::hook_ipc::IpcMessageV1 {
    ```

    ```rust
    use dashmap::DashMap;
    use std::sync::Arc;
    use std::time::{Duration, Instant};
    use dlp_common::hook_ipc::HashEvidenceFrame;

    pub type HashCache = Arc<DashMap<(u32, u64), (HashEvidenceFrame, Instant)>>;

    pub fn create_hash_cache() -> HashCache {
        Arc::new(DashMap::new())
    }

    pub fn spawn_hash_cache_cleanup_task(cache: HashCache) {
        std::thread::spawn(move || {
            loop {
                std::thread::sleep(Duration::from_secs(60));
                let now = Instant::now();
                let cutoff = Duration::from_secs(60);
                cache.retain(|_key, (_frame, inserted)| now.duration_since(*inserted) < cutoff);
            }
        });
    }
    ```
