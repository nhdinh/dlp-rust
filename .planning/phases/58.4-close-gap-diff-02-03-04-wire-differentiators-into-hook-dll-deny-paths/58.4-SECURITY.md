## Dependency Audit

The T-58.4-SC mitigation was implemented as a CI gate using `cargo-audit`:

- **Tool:** cargo-audit 0.21.2
- **Trigger:** every push/PR in `.github/workflows/build.yml`
- **Behavior:** fetches the RustSec advisory DB, strips unsupported `CVSS:4.0` lines (workaround for rustsec/cargo-audit#1200), runs `cargo audit --json --no-fetch`, and fails the build if any vulnerability is found.
