  <action>
    Extend `UsbDetector` in `dlp-agent/src/detection/usb.rs` with volume classification capabilities. Per D-01, D-05:

    1. Add `volume_class_map: RwLock<HashMap<char, VolumeClass>>` field to `UsbDetector` struct, initialized to empty HashMap in Default impl.

    2. Add `classify_drive(&self, letter: char) -> VolumeClass` method:
       - Call GetDriveTypeW on the drive root (format!("{}:\\", letter))
       - Map DRIVE_REMOTE (4) -> NetworkShare
       - Map DRIVE_CDROM (5) -> Optical (but per Pitfall 2, check WMI Model for "Virtual" or "Msft" first — if virtual indicator found, return Virtual even for DRIVE_CDROM)
       - Map DRIVE_REMOVABLE (2) -> call disambiguate_removable(letter)
       - Map DRIVE_FIXED (3) -> call disambiguate_fixed(letter)
       - Map DRIVE_RAMDISK (6) or unknown -> LocalNTFS fallback

    3. Add `disambiguate_removable(&self, letter: char) -> VolumeClass` private method:
       - Query WMI Win32_DiskDrive for the physical disk associated with this drive letter
       - Map drive letter to disk via Win32_LogicalDiskToPartition -> Win32_DiskDrive association (or query all disks and filter by DeviceID matching the letter)
       - If BusType/InterfaceType contains "SD" OR MediaType contains "SD" OR model contains "SD" or "MMC" -> SDCard
       - Otherwise -> USBRemovable
       - If WMI query fails, fallback: if model contains "SD" or "MMC" -> SDCard, else USBRemovable

    4. Add `disambiguate_fixed(&self, letter: char) -> VolumeClass` private method:
       - Query WMI Win32_DiskDrive for the disk associated with this letter
       - If Model contains "Virtual" or "Msft" or "File-backed Virtual" -> Virtual
       - Otherwise -> LocalNTFS
       - If WMI query fails, fallback to LocalNTFS

    5. Define a `WmiDiskDrive` struct with serde::Deserialize, #[serde(rename = "Win32_DiskDrive")], #[serde(rename_all = "PascalCase")], fields: DeviceID (String), interface_type (Option<String>), media_type (Option<String>), model (Option<String>), pnp_device_id (Option<String>).

    6. WMI query helper: `query_disk_for_letter(letter: char) -> Result<Option<WmiDiskDrive>, VolumeClassError>` that:
       - Creates WMIConnection::with_namespace_path(r"ROOT\CIMV2")
       - Queries all Win32_DiskDrive rows
       - Maps the drive letter to the correct disk (via Win32_LogicalDiskToPartition association or by matching DeviceID to the drive letter)
       - Returns the matching WmiDiskDrive or None if not found

    Error handling: WMI failures must not panic. Log via tracing::warn! and fall back to safe defaults (USBRemovable for removable, LocalNTFS for fixed).

    Do NOT query WMI on every classify_drive call in the hot path — this method is called from the agent's WM_DEVICECHANGE handler (not the hook DLL), so WMI latency is acceptable here.
  </action>
