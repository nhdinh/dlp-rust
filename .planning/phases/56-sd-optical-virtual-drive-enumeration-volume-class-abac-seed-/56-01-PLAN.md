         ```
         /// When a path cannot be classified (WMI failure, unknown drive letter, etc.),
         /// the classification returns `None`, NOT `LocalNTFS`. A `None` volume class

         ```

    2. Add `resolve_volume_class_from_path` helper function AFTER the VolumeClass enum. Per D-08 and D-09, addressing review concern "Agent = single source of truth":

       ```rust
       /// Extract drive letter or detect UNC prefix from a Windows path and return the corresponding VolumeClass.
       ///
       /// # Arguments
       ///
       /// * `path` - A Windows filesystem path (e.g., "C:\\file.txt", "\\\\server\\share\\file.txt")
       /// * `lookup` - A function that takes a drive letter (char) and returns Option<VolumeClass>.
       ///              This allows the caller to provide their own cache or query mechanism.
       ///              The agent's volume_class_map is the authoritative source.
       ///
       /// # Returns
       ///
       /// * `Some(VolumeClass::NetworkShare)` for UNC paths (starts with "\\\\")
       /// * `Some(class)` where class is returned by `lookup` for drive-letter paths
       /// * `None` for volume GUID paths ("\\\\?\\Volume{...}") when lookup fails — FAIL-CLOSED
       /// * `None` if no drive letter and not a recognized path format — FAIL-CLOSED
       pub fn resolve_volume_class_from_path<F>(path: &str, lookup: F) -> Option<VolumeClass>
       where
           F: FnOnce(char) -> Option<VolumeClass>,
       {
           // UNC path -> NetworkShare
           if path.starts_with("\\\\") {
               return Some(VolumeClass::NetworkShare);
           }
           // Drive letter path (e.g., "C:\\file.txt" or "C:/file.txt")
           let bytes = path.as_bytes();
           if bytes.len() >= 2 && bytes[0].is_ascii_alphabetic() && bytes[1] == b':' {
               let letter = bytes[0].to_ascii_uppercase() as char;
               return lookup(letter);
           }
           // Volume GUID path (\\?\Volume{...}) — FAIL-CLOSED: return None
           if path.starts_with("\\\\?\\Volume{") {
               return None;
           }
           None
       }
       ```

    Do NOT add sub-variants for Virtual (per D-02: single Virtual class).
    Do NOT put VolumeClass in a separate module — keep it in abac.rs for discoverability.
    Do NOT default unclassifiable paths to LocalNTFS — this is the key security fix from reviews.
