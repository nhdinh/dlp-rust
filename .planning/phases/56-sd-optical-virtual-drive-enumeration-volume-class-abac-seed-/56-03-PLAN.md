Implement hook DLL volume-class resolution at trampoline time using a thread-local cache (no WMI in hot path). Wire volume class into AbacContext before the pipe round-trip and shared-memory cache evaluation.

Purpose: The hook DLL must resolve volume class fast enough to stay within the 50 us p95 hot-path budget. WMI is too slow (~10-100ms), so a thread-local cache populated by the agent is required.
Output: volume_class_cache.rs module, trampoline integration for path-based and copy/move operations.
</objective>

  <action>
    Create `dlp-hook-dll/src/volume_class_cache.rs` as a new module. Per D-08 and Claude's Discretion:

    1. Define `VOLUME_CLASS_TTL: Duration = Duration::from_secs(30)` constant.

    2. Define thread-local cache:
       ```rust
       thread_local! {
           static VOLUME_CLASS_CACHE: RefCell<HashMap<char, (VolumeClass, Instant)>> =
               RefCell::new(HashMap::new());
       }
       ```

    3. Implement `pub fn resolve_volume_class(letter: char) -> VolumeClass`:
       - Check cache: if entry exists and Instant::elapsed() < TTL, return cached class
       - Cache miss/expired: call `query_volume_class_from_agent(letter)` (see below), insert into cache, return

    4. Implement `pub fn resolve_volume_class_from_path(path: &str) -> Option<VolumeClass>`:
       - If path starts with "\\" (UNC), return Some(VolumeClass::NetworkShare) immediately (per Pitfall 5)
       - Extract drive letter from path: check bytes[0].is_ascii_alphabetic() && bytes[1] == b':'
       - If drive letter found, convert to uppercase, call resolve_volume_class(letter), return Some(class)
       - For volume GUID paths (\\?\Volume{...}), attempt GetVolumePathNamesForVolumeNameW to get drive letter; if that fails, return Some(VolumeClass::LocalNTFS) as fallback
       - If no drive letter and not UNC, return None

    5. Implement `pub fn clear_cache()` to empty the thread-local HashMap (called on cache version invalidation or agent reconnect).

    6. Implement `fn query_volume_class_from_agent(letter: char) -> VolumeClass`:
       - First attempt: read from the shared-memory classification cache (Global\DlpClassificationCache) if it stores volume class data. If the shared-memory cache does NOT yet store volume classes (it only stores Classification), fall through.
       - Second attempt: send a lightweight HookMessage::VolumeClassQuery via the named pipe to the agent. The agent responds with the VolumeClass for that drive letter (agent reads from its volume_class_map).
       - If both fail (pipe unreachable), return VolumeClass::LocalNTFS as safe fallback.
       - NOTE: The pipe round-trip is slow (~1-5ms). This is why caching with 30s TTL is critical. The fallback to LocalNTFS is safe because T3/T4 fail-closed logic still applies.

    7. In `dlp-hook-dll/src/lib.rs`, add `pub mod volume_class_cache;` alongside existing modules.

    Do NOT use a global Mutex or RwLock — thread_local RefCell is required per D-08.
    Do NOT call WMI from this module — that would violate the hot-path budget.
