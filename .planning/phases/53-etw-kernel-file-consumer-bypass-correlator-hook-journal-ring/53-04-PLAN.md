<objective>
Implement the bypass correlator that matches ETW Kernel-File events against hook DLL journal entries within +/-5ms QPC tolerance. When no matching journal entry is found, the correlator constructs a BypassAlert with severity mapped by correlation reason and protected path status, batches alerts, and flushes them to the server via POST /audit/bypass.

Purpose: Turn hook-vs-ETW divergence into auditable bypass alerts that route through SIEM and the alert router.
Output: `bypass_correlator.rs` module with `BypassCorrelator` struct, `JournalReader` type, alert batching, and flush task.
</objective>

       - Spawn three tokio tasks:
         a. **Process event handler**: receives ProcessEvent from process_watcher
            - On process start: attempt to open journal with 5-second retry loop (spawn_blocking)
            - On process exit/heartbeat timeout: wait 5-second grace period, then remove journal from DashMap
         b. **ETW event handler**: receives EtwFileEvent from etw_kernel_file consumer
            - Check allowlist: if PID in allowlisted_pids and not expired, drop event
            - Check hardcoded emergency filter: drop if image path contains "System", "Registry", "smss.exe", "csrss.exe", "lsass.exe"

            - Map ETW event ID to op byte
            - Lookup journal for PID; if none, emit NoHookJournal alert
            - Search journal entries where `|entry.ts_qpc - event_ts_qpc| <= tolerance_qpc`
            - Match on `(path_hash == entry.path_hash AND op == entry.op)`
            - Match found, same op -> no alert
            - Match found, different op -> OpMismatch alert (warn severity)
            - No match -> NoHookJournal alert (crit if protected path, warn otherwise)
            - Add alert to batch
         c. **Batch flush task**: every 5 seconds or when batch reaches 100
            - Lock batch, drain to Vec
            - POST to `/audit/bypass` via server_client
            - On failure, log warning and re-add to batch (with max retry)

    10. Implement `BypassCorrelator::compute_image_sha256(image_path: &str) -> Option<String>`:

        - Store in cache and return
        - On failure (file not found, permission denied), return None
