<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent -> Server (POST /audit/bypass) | HTTPS + agent JWT; agent_id validated against claim |
| Admin -> Server (GET/POST /admin/bypass-alerts) | HTTPS + admin JWT; standard admin auth |
| Server -> SQLite | Local database; no network boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-53-17 | Spoofing | Agent injects fake bypass alerts for another agent | mitigate | POST /audit/bypass validates agent_id against JWT claim |
| T-53-18 | Denial of Service | Agent floods server with bypass alerts | mitigate | Batch size capped at 100; SQLite backpressure; alert router rate limiting |
| T-53-19 | Information Disclosure | Admin sees bypass alerts from other agents | accept | Admin role has global visibility by design; no tenant isolation in v0.10.0 |
| T-53-20 | Tampering | Admin acks alert they should not | accept | Ack is audit-logged; admin actions are traceable |
| T-53-21 | Elevation of Privilege | Non-admin accesses /admin/bypass-alerts | mitigate | Route is under protected_routes with JWT middleware |
</threat_model>
