<objective>
Implement the ETW Kernel-File consumer module that subscribes to Microsoft-Windows-Kernel-File events via ferrisetw 1.2.0, parses CREATE/WRITE/DELETE_PATH/OP_END events, converts NT device paths to DOS paths, and pushes them through a crossbeam channel for downstream correlation. Addresses review concerns CR-06 (gated return type), CR-07 (error! not warn!), WR-02 (separate enable flag), WR-09 (NT path normalization), and IN-03 (lost events wired to runtime alerting).

Purpose: Provide real-time kernel-level file operation telemetry that the bypass correlator (Plan 04) will compare against hook DLL journal entries.
Output: `etw_kernel_file.rs` module with `EtwKernelFileConsumer` struct, `EtwFileEvent` type, `FileOp` enum, `EtwConsumerState` enum, and full ProcessWatcher-mirroring architecture.
</objective>
