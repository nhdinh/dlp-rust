NOTE: The shared-memory layout structs (CacheHeader, PrefixEntry, HashEntry) must match the agent's definitions EXACTLY — use the same #[repr(C)] layout, same field order, same padding. The DLL and agent share the same memory layout but the DLL never writes.

    1. **Shared-memory layout structs** (mirror agent's definitions exactly):
       - `CacheHeader` with `version_word: AtomicU64` at offset 0, all offsets as `u64`
       - `PrefixEntry` with prefix_len, prefix[260], tier, ttl_secs
       - `HashEntry` with hash, tier, ttl_bits
       - All structs `#[repr(C)]` and read-only from DLL perspective

    2. **Global static state** (all read-only after init):
       - `static mut CACHE_HEADER: Option<*const CacheHeader> = None;`
       - `static mut CACHE_BASE: Option<*const u8> = None;`
       - `static CACHE_VERSION_SEEN_AT: AtomicU32 = AtomicU32::new(0);` — timestamp (wall-clock seconds since DLL load) when cache was last known valid
       - `static QPC_FREQUENCY: AtomicI64 = AtomicI64::new(0);` — cached QueryPerformanceCounter frequency

    3. **Initialization** (`init_mapping` function):
       - Call `OpenFileMappingW` with `FILE_MAP_READ` on `"Global\\DlpClassificationCache"`
       - Call `MapViewOfFile` to get read-only base pointer
       - Store in `CACHE_HEADER` and `CACHE_BASE`
       - Call `QueryPerformanceFrequency` once and cache in `QPC_FREQUENCY`
       - Return `true` on success, `false` on failure (non-fatal: cache is optimization)
       - SAFETY: This is called from DllMain after the self-allowlist gate. The mapping is read-only.

    4. **Cache lookup** (`lookup(path: &str) -> Option<Classification>`):
       - Read atomic version_word with Acquire ordering: `let word = (*header).version_word.load(Ordering::Acquire);`
       - Extract `version = word >> 1`, `buffer_index = (word & 1) as usize`
       - Compute `now_secs = CACHE_VERSION_SEEN_AT.load(Ordering::Relaxed)`
       - **Tier 1: Thread-local LRU** (fastest path):
         - Check thread-local LRU for exact path match
         - If hit, verify TTL: `now_secs - entry.seen_at < entry.ttl_secs`
         - If valid, return cached classification
       - **Tier 2: Root-prefix table** (second fastest):
         - Read prefix_count from header
         - Iterate prefix entries (sorted by length descending per D-02)
         - For each entry: check prefix match with `eq_ignore_ascii_case`
         - If match: verify TTL via `now_secs.saturating_sub(seen_at) < ttl_secs`
         - If valid: insert into thread-local LRU, return classification
       - **Tier 3: Per-file hash table** (third):
         - Compute FNV-1a 64-bit hash of path bytes
         - Compute hash table base address from header (hash_table_offset_0 or _1 based on buffer_index)
         - Open addressing with linear probing: check up to HASH_SLOTS entries
         - On match (entry.hash == computed_hash): verify TTL, return classification
         - On empty slot (entry.hash == 0): stop probing, return None
       - If all tiers miss: return None (fall through to pipe)

    5. **Thread-local LRU** (128 entries):
       - `thread_local! { static LRU: RefCell<Vec<(String, Classification, u32, u32)>> = RefCell::new(Vec::with_capacity(128)); }`
       - Each entry: (path, classification, ttl_secs, seen_at_secs)
       - `thread_local_lru_insert(path, classification, ttl_secs)`: push to front, truncate to 128
       - `thread_local_lru_lookup(path) -> Option<Classification>`: linear scan (128 entries = trivial)

    6. **FNV-1a hash** (copy from dlp-agent/src/cache.rs exactly):
       - `fn fnv1a_64(bytes: &[u8]) -> u64` with FNV-1a 64-bit constants

    7. **TTL staleness budgets** (per FAIL-03):
       - T4: 30s, T3: 60s, T2: 300s (5min), T1: 1800s (30min)
       - The `ttl_bits` field in shared memory encodes the tier-specific TTL
       - DLL computes `now_secs.saturating_sub(cache_version_seen_at) < ttl_secs`

    8. Add `mod classification_cache;` to dlp-hook-dll/src/lib.rs after existing module declarations.

    9. Unit tests (all using mock shared memory in test process address space):
       - `test_lookup_prefix_match`: Write prefix table to mock memory, verify lookup returns correct tier
       - `test_lookup_hash_match`: Write hash table entry, verify FNV-1a lookup returns correct tier
       - `test_lookup_ttl_expired`: Write entry with expired TTL, verify lookup returns None
       - `test_lookup_longest_prefix_wins`: Two overlapping prefixes, verify longer one wins
       - `test_lru_capacity`: Insert 129 entries, verify only 128 retained
       - `test_lru_hit`: Insert then lookup same path, verify hit
       - `test_version_word_read`: Verify atomic read extracts version and buffer correctly

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hook DLL -> Shared Memory | DLL reads only; Windows MMU enforces read-only mapping |
| Cache lookup -> Decision | Cache data drives ALLOW/DENY; stale data could cause wrong decision |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-10 | Tampering | DLL reads corrupted shared memory | mitigate | Atomic version word with Acquire ordering ensures DLL sees complete buffer; torn reads prevented by double-buffering |
| T-50-11 | Information Disclosure | Thread-local LRU contains classified paths | accept | LRU is per-thread within the same process; no cross-process leak |
| T-50-12 | Denial of Service | Cache lookup takes too long, blocking file I/O | mitigate | Lookup is O(1) for LRU, O(prefix_count) for prefix table, O(probe_depth) for hash table; all bounded; p95 target <50us |
| T-50-13 | Elevation of Privilege | Stale cache allows T3/T4 write after policy change | mitigate | TTL enforcement + atomic version flip + max staleness triggers ISOLATED state; DACL tripwire (Phase 52) is backstop |
</threat_model>
