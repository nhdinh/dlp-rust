## Review Feedback Addressed
- **Formalize ABI validation (HIGH):** Validate magic (0x4454_5001), layout_version (1), checksum, bounds (total_size, counts, offsets within mapping) on every lookup. Bad header -> treat as cache miss + emit telemetry.
- **Memory ordering (HIGH):** Acquire load on version_word; snapshot active buffer index; re-validate version after multi-field reads if necessary.
- **DllMain loader lock (HIGH):** Defer OpenFileMappingW + MapViewOfFile + background thread to first hook call via std::sync::OnceLock, NOT DllMain.
- **Cache-hit semantics (HIGH):** Document that cache stores classification HINT only. T3/T4 write on cache hit = fast-path DENY (skip pipe). T1/T2 = fast-path ALLOW. Cache miss = full ABAC evaluation via pipe. No ABAC bypass.
- **Path normalization (HIGH):** Normalize NT paths (\\?\, \\.\), DOS paths, UNC paths; strip trailing separators; case-fold; reject 8.3 short names (require canonical). Explicitly handle reparse points, symlinks, junctions, volume GUID paths, ADS streams — force pipe fallback for these cases.
- **LRU invalidation on version flip (MEDIUM):** Thread-local LRU stores cache_version per entry. On lookup, if LRU entry version != current global version, treat as miss.
- **Malformed-cache safe behavior (MEDIUM):** Bad magic/version/checksum/counts -> enter degraded mode (cache unavailable), fall through to pipe in HEALTHY/DEGRADED, use fail-mode in ISOLATED.
- **Validation cost (HIGH):** Split validation into full validation on map open/version change; cheap magic/version check per lookup.
