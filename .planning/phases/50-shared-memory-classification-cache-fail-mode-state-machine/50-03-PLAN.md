## Review Feedback Addressed
- **Formalize ABI validation (HIGH):** Validate magic (0x4454_5001), layout_version (1), checksum, bounds (total_size, counts, offsets within mapping) on every lookup. Bad header -> treat as cache miss + emit telemetry.
- **Memory ordering (HIGH):** Acquire load on version_word; snapshot active buffer index; re-validate version after multi-field reads if necessary.
- **DllMain loader lock (HIGH):** Defer OpenFileMappingW + MapViewOfFile + background thread to first hook call via std::sync::OnceLock, NOT DllMain.
- **Cache-hit semantics (HIGH):** Document that cache stores classification HINT only. T3/T4 write on cache hit = fast-path DENY (skip pipe). T1/T2 = fast-path ALLOW. Cache miss = full ABAC evaluation via pipe. No ABAC bypass.
- **LRU invalidation on version flip (MEDIUM):** Thread-local LRU stores cache_version per entry. On lookup, if LRU entry version != current global version, treat as miss.
- **Path normalization (MEDIUM):** Normalize NT paths (\\?\, \\.\), DOS paths, UNC paths; strip trailing separators; case-fold; reject 8.3 short names (require canonical). Document in code comments.
- **Malformed-cache safe behavior (MEDIUM):** Bad magic/version/checksum/counts -> enter degraded mode (cache unavailable), fall through to pipe in HEALTHY/DEGRADED, use fail-mode in ISOLATED.

  <files>dlp-hook-dll/src/classification_cache.rs</files>
  <action>
    Create `dlp-hook-dll/src/classification_cache.rs` with `CacheLookup` struct:

    `CacheLookup` fields:
    - header: *const CacheHeader (read-only mapping)
    - mapping_handle: HANDLE (from OpenFileMappingW)

    `CacheLookup::get() -> Option<&'static CacheLookup>`:
    - Uses `std::sync::OnceLock` for lazy init on first hook call (NOT DllMain).
    - Calls `OpenFileMappingW("Global\\DlpClassificationCache", FILE_MAP_READ)`.
    - Calls `MapViewOfFile` to get read-only pointer.
    - Validates magic (0x4454_5001), layout_version (1), checksum, and bounds.
    - If validation fails: stores None, returns None (cache unavailable for this process lifetime).
    - On success: stores Some(CacheLookup).

    `CacheLookup::lookup(path: &str, op: HookOp, now_secs: u64) -> Option<Classification>`:
    1. Read version_word with Ordering::Acquire.
    2. Extract version = word >> 1, buffer = word & 1.
    3. Validate header fields (magic, layout_version, checksum).
    4. If any validation fails, return None (treat as miss).
    5. Normalize path (see Task 2).
    6. Longest-prefix match (Task 3).
    7. If prefix miss, FNV-1a hash table lookup (Task 4).
    8. Check TTL: entry.ttl_secs vs (now_secs - header.created_at_epoch_secs).
    9. If expired, return None.
    10. Return classification.

    `CacheLookup::decide(classification: Classification, op: HookOp) -> Option<DenyReturn>`:
    - If T3/T4 + Write -> Some(DenyReturn::BoolFalse) (fast-path deny)
    - If T1/T2 -> None (fast-path allow)
    - If Read on any tier -> None (allow read; ABAC decides on pipe)
    - Cache miss -> None (fall through to pipe)

    Document: cache stores classification HINT only. ABAC evaluation occurs on pipe round-trip.
    Document: T3/T4 write fast-path deny is safe because classification is authoritative for tier.
  </action>

    - Doc comments explain cache-hint semantics
