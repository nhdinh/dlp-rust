## Review Feedback Addressed
- **DllMain loader lock (HIGH):** Background thread spawned on first hook call via std::sync::OnceLock, NOT DllMain. Use CreateEventW for shutdown signal.
- **Fail-mode correctness (HIGH):** DEGRADED uses cache + retries pipe every 10th call. ISOLATED uses cache-only, no pipe attempts. Clear separation documented.
- **RESYNC semantics (MEDIUM):** ISOLATED -> RESYNC requires BOTH successful pipe round-trip AND cache version > last_seen. RESYNC -> HEALTHY flushes LRU and resets counters.
- **In-flight guarantee (MEDIUM):** In-flight decisions during RESYNC complete using old cache. New decisions use new cache. No blocking, no latency spike. Version snapshot taken at lookup start.
- **TTL semantics (MEDIUM):** Wall-clock TTL using created_at_epoch_secs per buffer. Per-tier budgets: T4=30s, T3=60s, T2=5min, T1=30min.
- **Malformed cache safe behavior (MEDIUM):** Bad magic/version/checksum -> ISOLATED-safe mode: T3/T4 deny, T1/T2 allow (if policy permits fail-open).
</context>

    - shutdown_event: HANDLE (from CreateEventW)
    - thread_handle: Option<JoinHandle<()>>

    `start_background_thread(cache_header: *const CacheHeader, fail_state: Arc<FailModeState>)`:
    - Uses std::sync::OnceLock for lazy init on first hook call (NOT DllMain).
    - Creates shutdown_event via CreateEventW.
    - Spawns thread that loops:
      1. WaitForSingleObject(shutdown_event, 100) // 100ms timeout
      2. If signaled -> break loop
      3. If fail_state.current_state() == Isolated:
         a. Read version_word from cache_header with Ordering::Acquire
         b. Extract version = word >> 1
         c. If version > fail_state.cache_version_seen_at.load(Relaxed):
            - Call fail_state.record_pipe_success(version) to trigger ISOLATED->RESYNC
      4. If fail_state.current_state() == Resync:
         - Transition to Healthy (LRU flush happens in trampolines)

    `shutdown_background_thread()`:
    - SetEvent(shutdown_event) to signal thread exit
    - Join with 5-second timeout

    Document: thread only polls when in ISOLATED state to minimize CPU.
    Document: 100ms polling interval balances latency vs CPU (10 checks/second).
    Document: thread is per-process; multiple hooked processes each have their own thread.
  </action>

  </verify>

    7. If RESYNC:
       a. Flush LRU (clear all entries)
       b. Reset fail_state counters
       c. Transition to HEALTHY
       d. Retry from step 3
