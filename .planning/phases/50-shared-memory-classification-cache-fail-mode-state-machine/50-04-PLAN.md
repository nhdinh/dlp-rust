<objective>
Build the hook DLL's fail-mode state machine with deterministic HEALTHY -> DEGRADED -> ISOLATED -> RESYNC transitions, tier-gated asymmetric fail-closed/fail-open behavior, and a background thread for ISOLATED-state RESYNC detection.

Purpose: When the agent pipe is unreachable, the DLL must autonomously make correct decisions. T3/T4 paths must be denied (fail-closed); T1/T2 paths must be allowed (fail-open). The state machine ensures graceful degradation and automatic recovery.
Output: fail_mode.rs (state machine), background_thread.rs (RESYNC detection), trampoline integration.
</objective>

       - `state: AtomicU8` — current fail state
       - `consecutive_failures: AtomicU32` — pipe failure counter
       - `cache_version_last_seen: AtomicU64` — last known good cache version
       - `cache_version_seen_at: AtomicU32` — wall-clock seconds when cache was last valid

       - All fields use Ordering::Relaxed for counters, Ordering::SeqCst for state transitions

       - `static FAIL_MODE: FailModeState = FailModeState::new();`
       - This is the single source of truth for the entire DLL

    4. **Impl methods**:
       - `new() -> Self`: Initialize all atomics to zero, state = Healthy
       - `current_state() -> FailState`: Load state atomic, transmute u8 to FailState
       - `record_pipe_success(cache_version: u64) -> FailState`:
         - Reset consecutive_failures to 0
         - Update cache_version_last_seen to cache_version
         - Update cache_version_seen_at to current wall-clock seconds
         - If current state is Isolated OR Resync AND cache_version > cache_version_last_seen:
           - Set state to Healthy
           - Return Healthy
         - If current state is Degraded: set state to Healthy, return Healthy
         - Else: return current state
       - `record_pipe_failure() -> FailState`:
         - Increment consecutive_failures
         - Load current state
         - Match:
           - Healthy + failures >= 3: set state to Degraded, return Degraded
           - Degraded + failures >= 10: set state to Isolated, return Isolated
           - Degraded: increment degraded_call_count; if count % 10 == 0, return DegradedRetry (special signal to retry pipe)
           - Isolated: return Isolated (no change)
           - Resync: return Resync (no change)
       - `check_cache_stale(now_secs: u32, max_ttl_secs: u32) -> bool`:
         - Compute `elapsed = now_secs.saturating_sub(cache_version_seen_at)`
         - Return `elapsed > max_ttl_secs`
       - `should_attempt_pipe() -> bool`:
         - Healthy: true
         - Degraded: true (but only every 10th call — caller checks degraded_call_count)
         - Isolated: false
         - Resync: true

    5. **Asymmetric decision** (`asymmetric_decision`):

         ```
         loop {
             let wait = WaitForSingleObject(shutdown_event, 100); // 100ms timeout

             if fail_mode::current_state() == FailState::Isolated {

                     let version = word >> 1;
         ```

       ```
       fn classify_and_log_path(
           path: &str,
           action: &str,
           fn_name: &str,
           deny_return: DenyReturn,
       ) -> Option<DenyReturn> {
           // Deferred background thread spawn (avoids DllMain deadlock).
           if !BG_THREAD_SPAWNED.swap(true, Ordering::SeqCst) {
               crate::background_thread::spawn_background_thread();
           }

           let path_hash = crate::hash_path(path);
           let start_qpc = unsafe { query_performance_counter() };
           let is_write = is_write_action(action);
           let current_state = crate::fail_mode::current_state();

           // 1. Check cache first (fast path).
           let cache_result = crate::classification_cache::lookup(path);
           
           match cache_result {
               Some(classification) => {
                   let latency_qpc = unsafe { query_performance_counter() } - start_qpc;
                   // Cache hit — decide based on classification + action.
                   if classification.is_sensitive() && is_write {
                       let msg = format!("[dlp-hook] DENY(cache) {} hash={:016x} latency={}us\0", ...);
                       crate::debug_log(&msg);
                       return Some(deny_return);
                   }
                   let msg = format!("[dlp-hook] ALLOW(cache) {} hash={:016x} latency={}us\0", ...);
                   crate::debug_log(&msg);
                   return None;
               }
               None => {
                   // Cache miss — behavior depends on fail-mode state.
                   match current_state {
                       FailState::Isolated => {
                           // ISOLATED: no pipe attempts. Use asymmetric decision.
                           let decision = crate::fail_mode::asymmetric_decision(None, is_write);
                           let msg = format!("[dlp-hook] DENY(isolated) {} hash={:016x}\0", ...);
                           crate::debug_log(&msg);
                           return decision;
                       }
                       FailState::Degraded => {
                           // DEGRADED: retry pipe every 10th call.
                           if !crate::fail_mode::should_attempt_pipe() {
                               // Use cache-only decision (will be asymmetric since cache miss).
                               return crate::fail_mode::asymmetric_decision(None, is_write);
                           }
                           // Fall through to pipe attempt.
                       }
                       _ => {} // HEALTHY or RESYNC: fall through to pipe.
                   }
               }
           }

           // 2. Pipe round-trip (HEALTHY, RESYNC, or DEGRADED retry).
           let pipe_result = crate::classify_path(path, action, crate::DEFAULT_PIPE_NAME);
           
           match pipe_result {
               Ok(decision) => {
                   // Record success and update cache version.
                   let new_state = crate::fail_mode::record_pipe_success(/* cache_version from response */);
                   if new_state == FailState::Healthy && current_state != FailState::Healthy {
                       let msg = "[dlp-hook] fail-mode: recovered to HEALTHY\0";
                       crate::debug_log(msg);
                   }
                   
                   match decision {
                       Decision::ALLOW | Decision::AllowWithLog => {
                           let msg = format!("[dlp-hook] ALLOW {} hash={:016x}\0", ...);
                           crate::debug_log(&msg);
                           None
                       }
                       d if d.is_denied() => {
                           let msg = format!("[dlp-hook] DENY {} hash={:016x}\0", ...);
                           crate::debug_log(&msg);
                           Some(deny_return)
                       }
                       _ => Some(deny_return),
                   }
               }
               Err(pipe_error) => {
                   // Record failure and transition state.
                   let new_state = crate::fail_mode::record_pipe_failure();
                   if new_state != current_state {
                       let msg = format!("[dlp-hook] fail-mode: {:?} -> {:?}\0", current_state, new_state);
                       crate::debug_log(&msg);
                   }
                   
                   // Use asymmetric decision based on new state.
                   crate::fail_mode::asymmetric_decision(None, is_write)
               }
           }
       }
       ```
