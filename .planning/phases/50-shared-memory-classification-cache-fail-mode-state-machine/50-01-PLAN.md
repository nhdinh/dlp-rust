Extend the IPC protocol between hook DLL and agent to support cache versioning, cache hint warming, and operation-type discrimination with a versioned envelope and hardened bincode compatibility.

Purpose: Enable the agent to detect stale DLLs (via cache_version), warm the DLL's LRU on pipe round-trips (via cache_hint), and distinguish read vs write operations for tier-gated fast-path decisions. Ensure bincode evolution is safe with golden fixtures and explicit downgrade behavior.
Output: Extended HookRequest/HookResponse types with versioned IpcEnvelope, backward-compatible bincode serialization, and golden fixture tests.
</objective>
