<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hook DLL -> Agent pipe | Untrusted process sends HookRequest; agent must validate |
| Agent -> Hook DLL response | Agent sends cache_hint; DLL trusts agent (SYSTEM privilege) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-01 | Tampering | HookRequest cache_version field | mitigate | Field is advisory only; agent verifies against shared-memory version word, not DLL claim |
| T-50-02 | Information Disclosure | cache_hint reveals classification tier | accept | Cache hint only sent to the same process that requested classification; no cross-process leak |
| T-50-03 | Denial of Service | Malformed bincode with extra fields | mitigate | serde `default` attribute handles missing fields gracefully; extra fields are ignored by bincode 1.x |
| T-50-04 | Elevation of Privilege | Old DLL sends request without cache_version | accept | Agent treats missing cache_version as 0 (stale), triggers proactive CacheDelta push — this is the desired behavior |
</threat_model>
