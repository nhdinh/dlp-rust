## Trust Boundaries

| Boundary | Description |
|------------|-------------|
| Agent (SYSTEM) -> Shared Memory | Agent writes; all other processes read-only |
| Shared Memory -> Hook DLLs | DLLs map read-only; Windows enforces at MMU level |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-04 | Tampering | Malicious process writes to shared memory | mitigate | FILE_MAP_READ only for DLLs; SYSTEM-only write ACL |
| T-50-05 | Information Disclosure | Classification metadata leaked via AU read | mitigate | Security descriptor: BA read only (not AU); classification is tier-only (T1-T4) |
| T-50-06 | Denial of Service | Cache overflow causes agent crash | mitigate | Priority truncation on overflow; graceful fallback to pipe-only |
| T-50-07 | Elevation of Privilege | Namespace squatting on Global\DlpClassificationCache | mitigate | Agent creates mapping before hooks load; verify owner on open |
| T-50-26 | Tampering | Corrupt cache header causes agent crash | mitigate | Bounds-check all offsets/counts; validate magic/checksum; fuzz tests for malformed headers |
| T-50-27 | Information Disclosure | Reserved header fields leak memory | mitigate | Reserved fields zeroed on initialization; not read by DLL |
</threat_model>
