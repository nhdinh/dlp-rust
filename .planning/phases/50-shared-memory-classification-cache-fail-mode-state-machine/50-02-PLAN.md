<objective>
Build the agent-side shared-memory classification cache owner: create the 2 MiB `Global\DlpClassificationCache` mapping, implement double-buffered layout with atomic version flip, and wire a policy-change subscriber that rebuilds the cache and flips the version atomically.

Purpose: The agent owns the only writeable handle to the shared memory. Every hooked process maps it read-only. This plan creates the foundation that all DLL cache lookups depend on.
Output: classification_cache.rs (cache owner), cache_pusher.rs (policy subscriber), service.rs integration.

       - `test_hash_write_read`: Stage hash entries, rebuild, read back and verify FNV-1a hash matches

  <action>
    Create dlp-agent/src/cache_pusher.rs that subscribes to policy_store changes and triggers cache rebuilds:

    1. **CachePusher struct**:
       - `cache: Arc<parking_lot::Mutex<ClassificationCache>>` — shared cache reference
       - `shutdown: Arc<AtomicBool>` — shutdown signal
       - `last_policy_hash: AtomicU64` — hash of last seen policy state

    2. **Core loop** (`run` method):
       - Poll every 30 seconds (same cadence as engine_client config poll)
       - Compute hash of current policy_store state (serialize relevant policy data, hash with FNV-1a)
       - If hash changed: trigger rebuild
       - Check shutdown signal between iterations

    3. **Rebuild with debounce** (per D-16 and RESEARCH.md open question #3):
       - On first change detection: set `pending_rebuild = true`, record `pending_at = Instant::now()`
       - On subsequent change detection while pending: reset `pending_at`
       - When `pending_rebuild && Instant::now() - pending_at >= 500ms`: execute rebuild
       - This batches rapid policy changes into a single rebuild

    4. **Rebuild sequence**:
       - Lock cache mutex
       - Read current policy state: all T3/T4 protected paths, explicit per-file classifications
       - Sort prefix entries by length descending (longest-prefix-wins per D-02)
       - Write to INACTIVE buffer (buffer index = 1 - current_active_buffer)
       - Atomic flip via `cache.flip_version()`
       - Log at info level: "Cache rebuilt: N prefixes, M hashes, version=V"
       - Unlock mutex

    5. **Startup pre-population**:
       - On CachePusher creation, immediately read protected paths from config and pre-populate cache
       - This ensures the cache is warm before any DLL connects

    6. Add `pub mod cache_pusher;` to dlp-agent/src/lib.rs.

    7. Unit tests:
       - `test_rebuild_triggers_on_hash_change`: Simulate policy change, verify rebuild fires
       - `test_debounce_batches_changes`: Two rapid changes within 200ms result in single rebuild
       - `test_no_rebuild_when_unchanged`: Same policy hash does not trigger rebuild
  </action>

    <automated>cargo test -p dlp-agent cache_pusher::tests</automated>
  </verify>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent (SYSTEM) -> Shared Memory | Agent writes; all other processes read-only |
| Shared Memory -> Hook DLL | DLL maps read-only; Windows MMU enforces |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-05 | Tampering | Malicious process writes to shared memory | mitigate | Security descriptor restricts write to SYSTEM; DLL maps FILE_MAP_READ only |
| T-50-06 | Information Disclosure | Shared memory readable by all processes | accept | Cache contains classification tiers (1-4), not sensitive content; design assumes all users can know classification |
| T-50-07 | Denial of Service | Agent crash leaves stale shared memory | accept | Stale mapping is read-only and harmless; new agent creates new mapping on restart |
| T-50-08 | Spoofing | Process creates fake Global\DlpClassificationCache | mitigate | Global\ namespace requires SeCreateGlobalPrivilege (SYSTEM only); non-SYSTEM creation fails |
| T-50-09 | Elevation of Privilege | Double-buffer flip without fence causes torn reads | mitigate | fence(Release) before atomic store; DLL reads with Acquire ordering |
</threat_model>
