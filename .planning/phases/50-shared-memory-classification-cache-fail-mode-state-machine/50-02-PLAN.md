    - magic: u64 = 0x4454_5001 ("DLP" + version 1)
    - layout_version: u32 = 1
    - total_size: u64 = 2 * 1024 * 1024
    - prefix_table_offset: u64
    - prefix_count: u64
    - hash_table_offset_0: u64

    - allowlist_offset: u64
    - allowlist_count: u64
    - created_at_epoch_secs: u64 (wall-clock seconds when buffer was built)
    - checksum: u64 (simple XOR checksum of header fields)
    - _pad to 128 bytes total
    
    `PrefixEntry` (#[repr(C)]):
    - prefix_len: u16
    - prefix: [u8; 260] (MAX_PATH in UTF-8)

    - hash: u64 (FNV-1a)

    Implement `ClassificationCache` struct with methods:
    
    `new() -> Result<Self, CacheError>`:
    - CreateFileMappingW("Global\DlpClassificationCache", 2 MiB, PAGE_READWRITE)
    - Security descriptor: D:(A;;GA;;;SY)(A;;GR;;;BA) via ConvertStringSecurityDescriptorToSecurityDescriptorW
    - Initialize header with magic, layout_version, version_word = 1 (version=0, buffer=0)
    - MapViewOfFile for read-write access
    
    `rebuild(entries: Vec<(CacheKey, Classification, u32)>) -> Result<u64, CacheError>`:
    - Read current version_word, determine inactive buffer
    - Build prefix table (sorted by prefix_len descending) and hash table in inactive buffer
    - Set created_at_epoch_secs to current wall-clock seconds
    - Compute checksum
    - fence(Ordering::Release) then atomic store version_word with new version + buffer flip
    
    `prepopulate_t3_t4_roots(roots: Vec<PathBuf>)`:
    - Insert T3/T4 protected path roots into cache at startup
    
    `overflow_behavior()`:
    - If entries exceed capacity: sort by tier (T4, T3, T2, T1), truncate lower tiers
    - Emit tracing::warn! with counts
    - Emit siem.cache_overflow telemetry event
    
    Use parking_lot::RwLock for rebuild synchronization (not hot path).
    Use tracing::error!/warn!/info! for logging.
  </action>
