## Review Feedback Addressed
- **Bincode compatibility (HIGH):** Use versioned IPC envelope with protocol_version field. All new fields have #[serde(default)]. Compatibility tests verify old/new round-trips.
- **CacheDelta inconsistency (HIGH):** No HookMessage::CacheDelta variant. Cache updates are via SHM atomic flip only. Agent does not send cache deltas through pipe.
- **Benchmark gates (MEDIUM):** Micro benchmark (p50/p95/p99 cache-hit latency with QPC) and macro benchmark (cargo build overhead) are separate test targets.
- **ABAC bypass (HIGH):** Cache stores classification hint only. Agent IPC handler still performs full ABAC evaluation on pipe round-trip. Cache hit = fast-path tier-gated decision; cache miss = full ABAC.
</context>

  <files>dlp-agent/src/hook_ipc.rs</files>
  <action>
    Modify `dlp-agent/src/hook_ipc.rs` to handle extended HookRequest:

    `handle_hook_request(req: HookRequest) -> Result<HookResponse, Error>`:
    1. Read current cache_version from ClassificationCache::current_version().
    2. If req.cache_version < current_version:
       - tracing::info!("stale DLL detected: req.version={}, current={}", ...)
       - The DLL will detect version mismatch on next cache lookup and refresh.
    3. Perform full ABAC evaluation (existing logic):
       - Look up path classification from policy_store.
       - Evaluate ABAC rules against subject/resource/action/environment.
       - Determine Decision (ALLOW / DENY / AllowWithLog).
    4. Build cache_hint:
       - If path is classified (has a tier), create CacheHint { path, tier, ttl_secs }.
       - ttl_secs based on tier: T4=30, T3=60, T2=300, T1=1800.
       - If unclassified, cache_hint = None.
    5. Return HookResponse {
         decision,
         reason,
         cache_hint,
         cache_version: current_version,
       }.

    Document: cache_version in request lets agent detect stale DLLs (for telemetry/audit only).
    Document: cache_hint in response warms DLL's thread-local LRU.
    Document: ABAC evaluation ALWAYS occurs on pipe round-trip — cache hit only skips pipe for tier-gated fast path.
  </action>
  <verify>
    <automated>cargo test -p dlp-agent hook_ipc::tests::cache_version_handling --lib</automated>
  </verify>
  <done>
    - handle_hook_request reads current cache_version from ClassificationCache
    - Detects stale DLLs when req.cache_version < current_version
    - Performs full ABAC evaluation (no bypass)
    - Returns cache_hint with tier and ttl_secs
    - Returns current cache_version in HookResponse
    - Tests verify stale detection and cache_hint generation
  </done>
