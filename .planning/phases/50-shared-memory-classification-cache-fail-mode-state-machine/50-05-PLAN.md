## Review Feedback Addressed
- **Security descriptor (HIGH):** Allowlist does not bypass enforcement — it bypasses cache lookup and pipe for known-trusted paths. Classification is still T1 (Public) for allowlisted paths. No security downgrade.
- **Allowlist bypass risk (MEDIUM):** Build-tool matching uses FULL PATH (not basename-only). Prevents `C:\Users\attacker\cargo.exe` from matching. Hardcoded paths require trusted parent directories (System32, Program Files, etc.).
- **Telemetry cost (MEDIUM):** Histogram uses thread-local pre-allocated bucket array (no allocation). Emission every 1000 calls reduces pipe traffic. QPC measurement is two register reads (~20ns).
- **Path normalization (MEDIUM):** Allowlist matching uses same normalize_path function as cache lookup (consistent handling of NT paths, case-folding, trailing separators).
</context>
