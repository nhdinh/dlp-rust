| Hook DLL -> Windows kernel | NtSuspendThread, VirtualProtect cross into kernel |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-05 | Tampering | retour trampoline generation | mitigate | retour is [ASSUMED] legitimate after human checkpoint; crate has CI coverage for Windows targets |
| T-51-06 | Denial of Service | detour.enable() fails on already-patched stub | mitigate | Per-stub state machine tracks state; never call enable() on Patched stub |
| T-51-07 | Elevation of Privilege | Race between EDR detection and patch | accept | Window is microseconds; EDR patches at load time, not continuously |
