       ```rust
       // dlp-hook-dll/tests/ntdll_chaos_test.rs
       // Phase 51 Chaos Test: Validate ntdll patcher under concurrent load.
       //
       // This test:
       // 1. Creates an NtdllPatcher (enabled=true)
       // 2. Spawns 1000 threads that repeatedly call NtCreateFile on a temp file
       // 3. While threads are running, performs 100 patch/unpatch cycles
       // 4. Verifies no crashes, no deadlocks, and trampolines work correctly
       //
       // WARNING: This test modifies ntdll in-memory. Run in isolation.

       use std::sync::{Arc, atomic::{AtomicUsize, Ordering}};
       use std::thread;
       use std::time::{Duration, Instant};

       #[test]
       #[ignore = "run manually: cargo test -p dlp-hook-dll --test ntdll_chaos_test -- --ignored --nocapture"]
       fn ntdll_chaos_test() {
           // ... test body ...
       }
       ```

    3. Test body implementation:
       a. Create `NtdllPatcher::new(true)`.
       b. Create a temp file path for NtCreateFile calls.
       c. Create `AtomicUsize` counters: `syscalls_ok`, `syscalls_denied`, `crashes`.
       d. Spawn 1000 threads. Each thread loops for the test duration (30 seconds):
          - Call `NtCreateFile` on the temp file with `FILE_READ_ATTRIBUTES` access (minimal, no actual I/O impact).
          - If return is `STATUS_SUCCESS`, increment `syscalls_ok`.
          - If return is `STATUS_ACCESS_DENIED`, increment `syscalls_denied` (hook is working).
          - Catch any panics with `std::panic::catch_unwind`.
       e. In the main thread, perform 100 patch/unpatch cycles:
          - `patcher.patch_all_stubs()`
          - Sleep 100ms
          - `patcher.unpatch_all_stubs()`
          - Sleep 100ms
       f. After 30 seconds, signal threads to stop (via `AtomicBool`).
       g. Join all threads.
       h. Assertions:
          - `crashes.load(Ordering::SeqCst) == 0` — no thread crashed
          - `syscalls_ok.load(Ordering::SeqCst) > 0` — syscalls were working
          - `syscalls_denied.load(Ordering::SeqCst) >= 0` — may be zero if no deny policy
          - Test completed within 60 seconds (no deadlock)

    4. Add helper functions:

| T-51-22 | Tampering | Concurrent patch/unpatch from multiple threads | mitigate | Mutex around NtdllPatcher; only one patcher operation at a time |
