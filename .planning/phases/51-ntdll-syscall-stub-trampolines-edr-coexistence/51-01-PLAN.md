```rust
fn is_edr_hooked(stub_addr: *const u8) -> bool {
    let known_edr_modules = ["csagent.dll", "csfalcon.dll", "SentinelAgent.dll"];
    if !any_known_edr_module_loaded(&known_edr_modules) {
        return false;
    }
    let first_byte = unsafe { *stub_addr };
    if first_byte != 0xE9 {
        return false;
    }
    let rel32 = unsafe { let offset_ptr = stub_addr.add(1) as *const i32; *offset_ptr };
    let target = stub_addr.wrapping_add(5).wrapping_add(rel32 as usize);
    is_address_in_edr_module_range(target as *const c_void)
}
```

From 51-RESEARCH.md Pattern 2 (Thread Suspend):
```rust
unsafe fn atomic_patch_stub(stub_addr: *mut u8, jmp_bytes: &[u8; 5]) -> Result<(), PatchError> {
    let current_tid = GetCurrentThreadId();
    let threads = enumerate_process_threads(GetCurrentProcessId())?;
    for thread in &threads { if thread.tid != current_tid { let _ = NtSuspendThread(thread.handle, None); } }
    for thread in &threads {
        if thread.tid == current_tid { continue; }
        let rip = get_thread_rip(thread.handle)?;
        if rip >= stub_addr as usize && rip < (stub_addr as usize + 5) {
            resume_all_threads(&threads, current_tid);
            return Err(PatchError::RipInStubRange);
        }
    }
    // ... atomic write ...
    resume_all_threads(&threads, current_tid);
    Ok(())
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hook DLL internal -> Windows kernel APIs | NtQuerySystemInformation, NtSuspendThread cross into kernel; inputs must be validated |
| EDR detection -> stub byte inspection | Reading ntdll .text bytes is safe (RX, always resident) but must not trigger EDR heuristics |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-01 | Tampering | edr_detector.rs module enumeration | mitigate | EnumProcessModules is MS-provided API; results are kernel-authoritative |
| T-51-02 | Denial of Service | thread_suspender.rs suspend protocol | mitigate | Drop guard ensures resume even on panic; timeout not needed as suspend is synchronous |
| T-51-03 | Information Disclosure | Module enumeration exposes loaded DLLs | accept | Module list is already visible to any process via standard APIs; no PII exposed |
