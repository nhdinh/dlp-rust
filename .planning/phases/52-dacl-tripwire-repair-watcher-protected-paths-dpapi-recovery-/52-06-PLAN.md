### Windows path validation (from 52-RESEARCH.md)
Use `GetFullPathNameW` for canonicalization. Reject paths that:
- Start with `\\` (UNC)
- Start with `\\?\` (extended-length)
- Start with `\\?\Volume{` (volume GUID)
- Are reparse points (junctions, symlinks) — check via `GetFileAttributesW` for `FILE_ATTRIBUTE_REPARSE_POINT`
- Use 8.3 short names — check for `~` in path segments

    2. **Path validation helper using Windows API** (addresses review concern HIGH):
       ```rust
       fn validate_protected_path(path: &str) -> Result<(), AppError> {
           // Use GetFullPathNameW for canonicalization
           let wide_path: Vec<u16> = path.encode_utf16().chain(std::iter::once(0)).collect();
           let mut buffer = vec![0u16; 512];
           let len = unsafe { GetFullPathNameW(PCWSTR(wide_path.as_ptr()), buffer.len() as u32, PWSTR(buffer.as_mut_ptr()), None) };
           if len == 0 {
               return Err(AppError::BadRequest("path is invalid".to_string()));
           }
           let canonical = String::from_utf16_lossy(&buffer[..len as usize]);
           
           // Reject UNC paths
           if canonical.starts_with("\\\\") {
               return Err(AppError::BadRequest("UNC paths are not supported".to_string()));
           }
           // Reject extended-length paths
           if canonical.starts_with("\\\\?\\") {
               return Err(AppError::BadRequest("extended-length paths are not supported".to_string()));
           }
           // Reject volume GUID paths
           if canonical.starts_with("\\\\?\\Volume{") {
               return Err(AppError::BadRequest("volume GUID paths are not supported".to_string()));
           }
           // Must be absolute drive path
           if !(canonical.len() >= 3 && canonical.as_bytes()[1] == b':' && canonical.as_bytes()[2] == b'\\') {
               return Err(AppError::BadRequest("path must be an absolute NTFS path (e.g., C:\\Data)".to_string()));
           }
           // Reject 8.3 short names
           if canonical.contains('~') {
               return Err(AppError::BadRequest("8.3 short names are not supported".to_string()));
           }
           
           Ok(())
       }
       ```
       Note: This validation runs server-side. The agent also validates paths before applying ACLs (Plan 52-01).
