       ```rust
       if let Some(ref staging) = self.staging {
           match staging.is_staged(&event.path.to_string_lossy()) {
               Ok(true) => {
                   // Staged operation — suppress tamper alert.
                   // If the row is a removal and applied_at is NULL, apply the removal now.
                   if let Ok(Some(row)) = staging.get_row(&event.path.to_string_lossy()) {
                       if row.operation == "remove" && row.applied_at.is_none() {
                           if let Err(e) = crate::dacl_tripwire::remove_tripwire_from_path(&event.path) {
                               tracing::warn!(path = %event.path.display(), error = %e, "failed to remove tripwire for staged removal");
                           } else {
                               if let Err(e) = staging.mark_applied(&event.path.to_string_lossy()) {
                                   tracing::warn!(path = %event.path.display(), error = %e, "failed to mark staged removal as applied");
                               }
                           }
                       }
                   }
                   continue; // Suppress tamper alert
               }
               Ok(false) => { /* Not staged — proceed to repair and alert */ }
               Err(e) => {
                   tracing::warn!(error = %e, "staging check failed — proceeding with tamper alert");
               }
           }
       }
       ```

       ```rust
                   staged_at: r.get(2)?,
       ```

    1. **Removal application task** in `service.rs`:

       - Takes `Arc<DaclStaging>` and `Arc<DaclWatcher>`
       - Runs on a 30-second interval (aligned with config poll cadence)
       - Reads staging rows with `operation = 'remove'` and `applied_at IS NULL`
       - For each row:
         - Calls `crate::dacl_tripwire::remove_tripwire_from_path(path)`
         - On success: calls `staging.mark_applied(path)`, unregisters path from DaclWatcher
         - On failure: logs error with `tracing::warn!`, retries on next interval
       - Respects shutdown signal

       ```rust
       pub fn spawn_removal_application_task(
           staging: Arc<crate::dacl_staging::DaclStaging>,
           watcher: Arc<crate::dacl_repair_watcher::DaclWatcher>,
           interval_secs: u64,
           mut shutdown_rx: tokio::sync::watch::Receiver<bool>,
       ) -> tokio::task::JoinHandle<()> {
           tokio::spawn(async move {
               let mut interval = tokio::time::interval(Duration::from_secs(interval_secs));
               interval.tick().await;
               loop {
                   tokio::select! {
                       _ = interval.tick() => {
                           match staging.list_all() {
                               Ok(rows) => {
                                   for row in rows {
                                       if row.operation == "remove" && row.applied_at.is_none() {
                                           let path = std::path::PathBuf::from(&row.path);
                                           match crate::dacl_tripwire::remove_tripwire_from_path(&path) {
                                               Ok(_) => {
                                                   if let Err(e) = staging.mark_applied(&row.path) {
                                                       tracing::warn!(path = %row.path, error = %e, "failed to mark removal as applied");
                                                   }
                                                   if let Err(e) = watcher.unregister(&path) {
                                                       tracing::warn!(path = %row.path, error = %e, "failed to unregister watcher for removed path");
                                                   }
                                               }
                                               Err(e) => {
                                                   tracing::warn!(path = %row.path, error = %e, "failed to remove tripwire — will retry");
                                               }
                                           }
                                       }
                                   }
                               }
                               Err(e) => tracing::warn!(error = %e, "failed to list staging rows for removal application"),
                           }
                       }
                       _ = shutdown_rx.changed() => {
                           tracing::info!("removal application task shutting down");
                           return;
                       }
                   }
               }
           })
       }
       ```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-16b | Tampering | Race between staging and watcher | mitigate | Staging check happens BEFORE tamper alert. mark_applied is called after ACL removal succeeds. |
| T-52-17b | Denial of Service | Staging table grows unbounded | mitigate | 5-minute TTL GC removes applied rows. Unapplied rows persist until operator resolves. |
| T-52-18b | Elevation of Privilege | Malicious server sends removal for non-protected path | mitigate | Agent only removes paths that were previously in its protected_paths config. Unknown paths are ignored. |
| T-52-19b | Information Disclosure | Staging table reveals operator actions | accept | Staging table is local SQLite under SYSTEM protection. Contains paths and operations, no secrets. |
