<objective>
Implement the DACL repair watcher that detects out-of-band ACL tampering on protected paths and restores canonical ACE order. Uses ReadDirectoryChangesW(FILE_NOTIFY_CHANGE_SECURITY) with a 60-second polling backstop and debounced repair.

Purpose: Ensure the NTFS DACL tripwire remains effective even when operators or adversaries modify ACLs outside the DLP system.
Output: `dacl_repair_watcher.rs` module with DaclWatcher struct, per-path watcher threads, crossbeam channel, debounced tokio repair task, and polling backstop with full subtree coverage.

Addresses review concerns:
- HIGH: Watcher/subtree coverage gaps — polling backstop walks full tree
- MEDIUM: No debounce/throttling on watcher repair — 500ms-2s debounce added
- MEDIUM: Audit event schema/routing validated in this plan (not deferred)
</objective>

    4. **`DaclWatcher` struct** following WfpManager pattern:
       ```rust
       pub struct DaclWatcher {
           watchers: parking_lot::Mutex<HashMap<PathBuf, WatcherHandle>>,
           snapshots: parking_lot::Mutex<HashMap<PathBuf, crate::dacl_tripwire::CanonicalAclSnapshot>>,
           event_tx: crossbeam_channel::Sender<SecurityEvent>,
           event_rx: crossbeam_channel::Receiver<SecurityEvent>,
           dlp_admin_sid: parking_lot::RwLock<Option<String>>,
       }
       ```

    5. **`impl DaclWatcher`**:
       - `pub fn new() -> Self` — creates bounded crossbeam channel (capacity 1024), empty maps
       - `pub fn register(&self, path: &Path, snapshot: CanonicalAclSnapshot) -> Result<(), DaclWatcherError>` — spawns dedicated OS thread for `ReadDirectoryChangesW(FILE_NOTIFY_CHANGE_SECURITY)` on the path with `bWatchSubtree = true`, stores WatcherHandle in map, stores snapshot
       - `pub fn unregister(&self, path: &Path) -> Result<(), DaclWatcherError>` — signals shutdown flag, joins thread, removes from maps
       - `pub fn unregister_all(&self)` — iterates all watchers calling unregister
       - `pub fn update_snapshot(&self, path: &Path, snapshot: CanonicalAclSnapshot)` — replaces snapshot for a path
       - `pub fn start_repair_task(&self, shutdown_rx: tokio::sync::watch::Receiver<bool>) -> tokio::task::JoinHandle<()>` — spawns tokio task that reads from event_rx with **500ms-2s debounce**: accumulates events in a HashMap<PathBuf, SecurityEvent>, on each event resets a timer for that path, when timer expires calls repair_acl. This batches rapid changes and prevents event storms.
       - `pub fn start_poll_backstop(&self, interval_secs: u64, shutdown_rx: tokio::sync::watch::Receiver<bool>) -> tokio::task::JoinHandle<()>` — spawns tokio task with `tokio::time::interval` that scans all registered paths. For each path: **walk the full subtree** (same walkdir pattern as apply_tripwire_recursive, up to 10K files), reads current ACL via `GetFileSecurityW + ConvertSecurityDescriptorToStringSecurityDescriptorW`, compares against stored snapshot SDDL. On mismatch, triggers repair. This catches descendant ACL changes that `ReadDirectoryChangesW` may miss.

    6. **`run_security_watcher_thread`** — the blocking OS thread function:
       - Opens directory with `CreateFileW(FILE_LIST_DIRECTORY, FILE_SHARE_READ | FILE_SHARE_DELETE, FILE_FLAG_BACKUP_SEMANTICS)`
       - Loops calling `ReadDirectoryChangesW` with `FILE_NOTIFY_CHANGE_SECURITY` and `bWatchSubtree = true`
       - On `ERROR_NOTIFY_ENUM_DIR` (1022), logs warning and sends SecurityEvent to trigger full subtree scan
       - On shutdown flag set, breaks loop and closes handle
       - Sends `SecurityEvent` through crossbeam channel on any security change

    7. **`repair_acl(path: &Path, snapshot: &CanonicalAclSnapshot, dlp_admin_sid: Option<&str>)`**:
       - Calls `crate::dacl_tripwire::apply_tripwire_to_path(path, dlp_admin_sid)` to restore canonical ACL
       - On success, logs info
       - On failure, logs error and emits `DaclTamperDetected` audit event via `crate::audit_emitter::emit`
       - Event includes: path, timestamp, EventType::DaclTamperDetected, agent_id
       - `triggers_alert()` returns true for this event type

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Watcher thread -> tokio repair task | crossbeam channel is in-process; no external trust boundary |
| Polling backstop -> NTFS kernel | Backstop reads ACLs via GetFileSecurityW; kernel is trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-08 | Denial of Service | ReadDirectoryChangesW buffer overflow | mitigate | On ERROR_NOTIFY_ENUM_DIR (1022), trigger immediate full subtree scan. 60s backstop catches missed events. |
| T-52-09 | Tampering | Attacker pauses watcher thread | accept | Thread runs as SYSTEM; pausing requires SYSTEM privilege. If attacker has SYSTEM, they can bypass all defenses. |
| T-52-10 | Information Disclosure | SDDL snapshots in memory | accept | Snapshots contain SIDs and access masks, no secrets. Memory is SYSTEM-protected. |
| T-52-11 | Denial of Service | Polling backstop CPU exhaustion | mitigate | Interval is fixed at 60s. Scan reads ACLs only (no file content). Number of protected paths is operator-controlled. |
| T-52-12 | Denial of Service | Event storm from rapid ACL changes | mitigate | 500ms-2s debounce batches rapid changes into single repair. Bounded channel (1024) with drop-oldest backpressure. |
| T-52-13 | Tampering | npm/pip/cargo installs | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] |
</threat_model>
