# Phase 38.2 Plan 38.2-GAP-02: Fix Boot-Drive Case-Sensitive Comparison Summary

**Boot drive letter normalization with belt-and-suspenders case-insensitive comparison across dlp-common and dlp-agent**

## Performance

- **Duration:** 2 min (actual code change); ~116 min including full workspace build/verify
- **Started:** 2026-05-06T09:39:01+0700
- **Completed:** 2026-05-06T11:35:01+0700
- **Tasks:** 3
- **Files modified:** 2

## Accomplishments

- Fixed `get_boot_drive_letter_windows` in `dlp-common` to uppercase the drive letter before returning, ensuring `'c'` from lowercase registry paths becomes `'C'`.
- Added defensive case-insensitive comparison in `dlp-agent/src/detection/disk.rs` that uppercases both the disk's drive letter and the boot letter before comparison.
- Added `test_boot_drive_letter_is_uppercased` in dlp-common to verify the uppercase guarantee on Windows.
- Added `test_is_boot_disk_true_when_letters_differ_in_case` in dlp-agent to verify case-mismatched letters still correctly identify the boot disk.

## Task Commits

Each task was committed atomically:

1. **Task 1: Uppercase boot drive letter in get_boot_drive_letter_windows** - `ba4b08d` (feat)
2. **Task 2: Case-insensitive boot disk comparison in agent enumeration** - `93ae17e` (feat)

## Files Created/Modified

- `dlp-common/src/disk.rs` - `get_boot_drive_letter_windows` now applies `.to_ascii_uppercase()` to the extracted drive letter; added `test_boot_drive_letter_is_uppercased`
- `dlp-agent/src/detection/disk.rs` - Boot disk comparison in `spawn_disk_enumeration_task` now uppercases both sides; added `test_is_boot_disk_true_when_letters_differ_in_case`

## Decisions Made

- **Uppercase both sides of comparison** (deviation from plan): The plan originally specified only uppercasing the disk's drive letter (`disk.drive_letter.map(|l| l.to_ascii_uppercase()) == Some(boot_letter)`). During test verification, this proved insufficient when `boot_letter` itself could be lowercase. Changed to uppercase both sides for true case-insensitivity.
- **Test private function directly**: `get_boot_drive_letter_windows` is private and `#[cfg(windows)]`, but the test module in the same file has access to private items, allowing direct testing without exposing the function publicly.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Agent-side comparison only uppercased one side**
- **Found during:** Task 2 (writing test_is_boot_disk_true_when_letters_differ_in_case)
- **Issue:** The plan specified `disk.drive_letter.map(|l| l.to_ascii_uppercase()) == Some(boot_letter)` which fails when boot_letter is lowercase ('c') and disk letter is uppercase ('C')
- **Fix:** Changed to uppercase both sides: `disk.drive_letter.map(|l| l.to_ascii_uppercase()) == Some(boot_letter.to_ascii_uppercase())`
- **Files modified:** `dlp-agent/src/detection/disk.rs`
- **Verification:** `test_is_boot_disk_true_when_letters_differ_in_case` passes with all case combinations
- **Committed in:** `93ae17e` (Task 2 commit)
