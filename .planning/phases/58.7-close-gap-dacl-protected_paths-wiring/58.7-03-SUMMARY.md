# Phase 58.7 Plan 03: Runtime reactive protected_paths wiring

**BypassCorrelator protected_paths is now dynamically updatable via RwLock, and DaclWatcherManager fully handles Shutdown and Reinit so server-pushed protected_paths changes apply the tripwire, register watchers, rebuild the classification cache, and update the correlator without an agent service restart.**

## Accomplishments

- Replaced `BypassCorrelator.protected_paths` with `parking_lot::RwLock<Vec<String>>` and added a public `set_protected_paths(&self, Vec<String>)` method.
- Documented the concurrency choice (rare-write / frequent-read) and a p99 < 10us latency acceptance criterion in a module-level comment.
- Changed `BypassCorrelator::run` to take `self: Arc<Self>` so the same correlator instance can be shared with the DACL manager.
- Reordered `run_loop_init` to construct the `Arc<BypassCorrelator>` before spawning the DACL manager.
- Implemented full `DaclWatcherManager::run` command handling:
  - `Shutdown` shuts down the current bundle and exits.
  - `Reinit` shuts down the old bundle, reads the latest `protected_paths` and `global_mode`, rebuilds the watcher bundle, repopulates T3/T4 cache roots, and updates the correlator path list.
- Added `reinit_dacl_bundle` helper to centralise the fresh-config rebuild path.
- Added unit tests for manager shutdown, reinit, and the end-to-end added-path behavior.
- Restored the `DaclWatcherBundle` struct definition (with `empty()` and consuming `shutdown(mut self)`) that had been accidentally removed during an earlier duplicate cleanup.

## Decisions Made

- **RwLock over arc-swap:** `parking_lot::RwLock<Vec<String>>` was chosen because writes happen only on policy sync and arc-swap would add a new dependency. The ignored latency test documents the p99 < 10us acceptance criterion, and migration to `arc-swap` is the documented contingency if profiling shows reader contention.
- **Correlator constructed before manager:** `run_loop_init` now builds `Arc<BypassCorrelator>` before `spawn_dacl_watcher_manager` so the manager can call `set_protected_paths` during `Reinit` without restarting the correlator task.
- **Fresh config snapshot on every Reinit:** `reinit_dacl_bundle` reads `protected_paths` and `enforcement.global_mode` from the shared `Arc<Mutex<AgentConfig>>` inside the command handler, preventing stale global_mode from being applied.
