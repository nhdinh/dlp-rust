<objective>
Make the protected-path configuration reactive at runtime: enable dynamic updates to the bypass correlator path list and implement full `Shutdown`/`Reinit` command handling in the DACL manager so a server-pushed `protected_paths` change applies the tripwire, registers new watchers, and rebuilds the classification cache without an agent service restart.

Purpose: Without runtime reinit behavior, UAT scenario F01 ("wait for policy sync") fails because the Deny ACE only appears after service restart, breaking the promised zero-restart configuration experience. The `Reinit` command is also the mechanism that makes additions immediate: when `apply_payload_to_config` diffs a new protected path into the config, the config-poll loop emits `Reinit`, which must apply the tripwire and register the watcher for that addition.

Output: Dynamic protected-path update in `BypassCorrelator` with a documented concurrency choice and latency acceptance criterion, and full command handling in `dlp-agent/src/service.rs` `spawn_dacl_watcher_manager`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server config push -> Agent | HTTP/JSON carries the authoritative protected_paths list |
| Agent internal -> DaclWatcherManager | Command channel crosses from config poll task to watcher lifecycle task |
| DaclWatcherManager -> NTFS | Reinit applies/removes Deny ACEs on disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58.7-08 | Elevation of Privilege | Reinit path uses stale global_mode | mitigate | The manager rebuilds a fresh `AgentConfig` snapshot from `with_config` on every `Reinit`, including current `enforcement.global_mode`. |
| T-58.7-09 | Information Disclosure | Reinit logs new path values | mitigate | Log only field names and counts; never log full protected path values in manager or init_dacl_watcher messages. |
| T-58.7-10 | Denial of Service | Rapid protected_paths changes exhaust threads/handles | mitigate | Config poll interval bounds change rate; `try_send` drops duplicate Reinit commands if the manager is still processing the previous one. |
| T-58.7-11 | Denial of Service | BypassCorrelator reader contention | accept | `parking_lot::RwLock` chosen for rare-write / frequent-read pattern; latency acceptance test verifies p99 below 10us. Migrate to `arc-swap` if profiling shows contention. |
| T-58.7-SC | Tampering | npm/pip/cargo installs | accept | No new external packages are required; all dependencies are already declared and locked in Cargo.lock. |
</threat_model>
