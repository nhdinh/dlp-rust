<objective>
Make the protected-path configuration reactive at runtime: when the server pushes a change to `protected_paths`, the agent shuts down the existing DACL watcher, applies the tripwire to the new path set, registers new `ReadDirectoryChangesW` watchers, and rebuilds the classification cache roots. This closes the operational gap where an operator had to restart the agent service for protected-path changes to take effect.

Purpose: Without runtime reinit, UAT scenario F01 ("wait for policy sync") fails because the Deny ACE only appears after service restart, breaking the promised zero-restart configuration experience.

Output: A `DaclWatcherManager` actor in `dlp-agent/src/service.rs`, dynamic protected-path update in `BypassCorrelator`, and tests proving the reinit path.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server config push -> Agent | HTTP/JSON carries the authoritative protected_paths list |
| Agent internal -> DaclWatcherManager | Command channel crosses from config poll task to watcher lifecycle task |
| DaclWatcherManager -> NTFS | Reinit applies/removes Deny ACEs on disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58.7-06 | Denial of Service | DaclWatcherManager reinit loop | mitigate | `try_send` is used from config_poll_loop so a stuck manager cannot block config polling; shutdown awaits handles with bounded service shutdown timeout. |
| T-58.7-07 | Tampering | Old watcher left running after reinit | mitigate | `DaclWatcherBundle::shutdown` signals and awaits removal, gc, repair, and poll tasks before the manager replaces the bundle; `unregister_all` is invoked via shutdown. |
| T-58.7-08 | Elevation of Privilege | Reinit path uses stale global_mode | mitigate | The manager rebuilds a fresh `AgentConfig` snapshot from `with_config` on every `Reinit`, including current `enforcement.global_mode`. |
| T-58.7-09 | Information Disclosure | Reinit logs new path values | mitigate | Log only field names and counts; never log full protected path values in manager or init_dacl_watcher messages. |
| T-58.7-10 | Denial of Service | Rapid protected_paths changes exhaust threads/handles | mitigate | Config poll interval bounds change rate; `try_send` drops duplicate Reinit commands if the manager is still processing the previous one. |
| T-58.7-SC | Tampering | npm/pip/cargo installs | accept | No new external packages are required; all dependencies are already declared and locked in Cargo.lock. |
</threat_model>
