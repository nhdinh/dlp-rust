# Phase 58.7: Close gap — DACL protected_paths wiring — Verification Report

**Phase Goal:** Close the agent-side wiring gap identified in the v0.10.0 milestone audit: all consumers of the protected-path list must read from the server-pushed `AgentConfig.protected_paths` field instead of `AgentConfig.monitored_paths`. Fix the path-normalization inconsistency between the staging table and the watcher so legitimate removals do not trigger spurious tamper alerts, validate server-pushed paths to reject traversal attempts, and migrate existing staging rows so in-flight removals are not orphaned by the new canonical key format.
