<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin TUI -> server API | JWT-authenticated CRUD on allowlist entries |
| Server -> agent config | HTTP/JSON config push every 30s |
| Agent config -> allowlist matcher | In-memory TOML deserialization |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-16 | Tampering | Malicious allowlist entry | mitigate | JWT auth on admin API; category CHECK constraint in SQLite; invalid category rejected by handler |
| T-49-17 | Information Disclosure | Allowlist entries in agent config TOML | accept | Allowlist entries are operational config (paths and cert subjects), not secrets. TOML file is in ProgramData with restricted ACLs. |
| T-49-18 | Denial of Service | Large allowlist in config payload | mitigate | No explicit size limit in this phase; if needed, add a guard in Plan 05. Vec deserialization is bounded by HTTP body size limits. |
| T-49-19 | Elevation of Privilege | Operator adds self-process exclusion | mitigate | Self-process exclusion is automatic (by PID and image path) regardless of allowlist entries. Operator cannot remove self-protection. |
</threat_model>
