# 49-04 — Config Wiring + Admin TUI: Allowlist Hot-Reload + Operator UI

## Objective

Wire the server-side allowlist into the agent config sync pipeline and build the admin TUI screen for operators to CRUD allowlist entries. Includes config versioning for cheap change detection and a manual "refresh now" trigger.

## Background (from Reviews)

Cross-AI review identified these MEDIUM-priority gaps:
1. **30s polling too slow for operational response**: Emergency allowlist updates may take up to 30s. Fix: add manual "refresh now" trigger from TUI + config versioning for cheap change detection.
2. **No atomic swap of allowlist**: Race between update and injection decisions. Fix: versioned config with atomic replace in agent.
3. **No validation feedback loop**: Invalid glob patterns from server not caught. Fix: validate on server before distribution, log invalid entries in agent.
4. **No caching/versioning of config payloads**: Agent re-downloads full config every 30s. Fix: version header allows 304-style skip.

All concerns are addressed in this revised plan.

- Agent atomically replaces allowlist on version change (no partial update)

- Invalid entry logging: agent logs warn! for entries it cannot parse

### Task 5: Create admin TUI allowlist screen

**Files:** dlp-admin-cli/src/screens/allowlist.rs (new), dlp-admin-cli/src/screens/mod.rs (modify)

**Action:**
Create `allowlist.rs` following the `usb_enforcement.rs` pattern:

```rust
//! Admin TUI allowlist configuration screen.
//!
//! Navigable list of allowlist entries with add/edit/disable actions.

use ratatui::{
    layout::{Constraint, Direction, Layout, Rect},
    style::{Color, Modifier, Style},
    text::{Line, Span},
    widgets::{Block, Borders, Clear, List, ListItem, Paragraph, Wrap},
    Frame,
};
use crossterm::event::{KeyCode, KeyEvent};

/// Screen state for allowlist management.
pub struct AllowlistScreen {
    pub entries: Vec<AllowlistEntryUi>,
    pub selected: usize,
    pub mode: AllowlistMode,
    pub edit_buffer: String,
    pub edit_field: usize,
    pub error_message: Option<String>,
    pub refresh_pending: bool,
}

#[derive(Debug, Clone)]
pub struct AllowlistEntryUi {
    pub id: String,
    pub match_type: String,
    pub value: String,
    pub description: String,
    pub category: String,
    pub priority: i64,
    pub enabled: bool,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AllowlistMode {
    List,
    Add,
    Edit,
    ConfirmDisable,
    ConfirmDelete,
}

impl AllowlistScreen {
    pub fn new() -> Self {
        Self {
            entries: Vec::new(),
            selected: 0,
            mode: AllowlistMode::List,
            edit_buffer: String::new(),
            edit_field: 0,
            error_message: None,
            refresh_pending: false,
        }
    }

    pub fn handle_key(&mut self, key: KeyEvent, client: &mut crate::client::AdminClient,
    ) -> Option<crate::app::ScreenTransition> {
        match self.mode {
            AllowlistMode::List => self.handle_list_mode(key, client),
            AllowlistMode::Add | AllowlistMode::Edit => self.handle_edit_mode(key, client),
            AllowlistMode::ConfirmDisable | AllowlistMode::ConfirmDelete => {
                self.handle_confirm_mode(key, client)
            }
        }
    }

    fn handle_list_mode(
        &mut self,
        key: KeyEvent,
        _client: &mut crate::client::AdminClient,
    ) -> Option<crate::app::ScreenTransition> {
        match key.code {
            KeyCode::Up => {
                if self.selected > 0 {
                    self.selected -= 1;
                }
            }
            KeyCode::Down => {
                if self.selected + 1 < self.entries.len() {
                    self.selected += 1;
                }
            }
            KeyCode::Char('a') => {
                self.mode = AllowlistMode::Add;
                self.edit_buffer.clear();
                self.edit_field = 0;
            }
            KeyCode::Char('e') => {
                if !self.entries.is_empty() {
                    self.mode = AllowlistMode::Edit;
                    self.edit_buffer = self.entries[self.selected].value.clone();
                    self.edit_field = 0;
                }
            }
            KeyCode::Char('d') => {
                if !self.entries.is_empty() {
                    self.mode = AllowlistMode::ConfirmDisable;
                }
            }
            KeyCode::Char('x') => {
                if !self.entries.is_empty() {
                    self.mode = AllowlistMode::ConfirmDelete;
                }
            }
            KeyCode::F(5) => {
                // Manual refresh trigger.
                self.refresh_pending = true;
            }
            KeyCode::Esc => {
                return Some(crate::app::ScreenTransition::Pop);
            }
            _ => {}
        }
        None
    }

    fn handle_edit_mode(
        &mut self,
        key: KeyEvent,
        client: &mut crate::client::AdminClient,
    ) -> Option<crate::app::ScreenTransition> {
        // TODO: implement full edit form with match_type picker, value input, etc.
        match key.code {
            KeyCode::Enter => {
                // Submit edit/add
                self.mode = AllowlistMode::List;
                self.refresh_pending = true;
            }
            KeyCode::Esc => {
                self.mode = AllowlistMode::List;
            }
            _ => {
                // Append to edit_buffer
            }
        }
        None
    }

    fn handle_confirm_mode(
        &mut self,
        key: KeyEvent,
        client: &mut crate::client::AdminClient,
    ) -> Option<crate::app::ScreenTransition> {
        match key.code {
            KeyCode::Char('y') => {
                // Confirm disable/delete
                self.mode = AllowlistMode::List;
                self.refresh_pending = true;
            }
            KeyCode::Char('n') | KeyCode::Esc => {
                self.mode = AllowlistMode::List;
            }
            _ => {}
        }
        None
    }
}

pub fn draw_allowlist_screen(
    frame: &mut Frame,
    screen: &AllowlistScreen,
    area: Rect,
) {
    let block = Block::default()
        .title("Allowlist Configuration (F5=Refresh, a=Add, e=Edit, d=Disable, x=Delete, Esc=Back)")
        .borders(Borders::ALL);

    let items: Vec<ListItem> = screen
        .entries
        .iter()
        .enumerate()
        .map(|(i, entry)| {
            let style = if i == screen.selected {
                Style::default().fg(Color::Black).bg(Color::White)
            } else if !entry.enabled {
                Style::default().fg(Color::DarkGray)
            } else {
                Style::default()
            };
            let status = if entry.enabled { "[+]" } else { "[-]" };
            ListItem::new(format!(
                "{} {} | {} | {} | {}",
                status, entry.match_type, entry.value, entry.category, entry.description
            ))
            .style(style)
        })
        .collect();

    let list = List::new(items).block(block);
    frame.render_widget(list, area);
}
```

Add `pub mod allowlist;` to `screens/mod.rs`.

**Verify:** `cargo check -p dlp-admin-cli` compiles.

**Acceptance criteria:**
- `AllowlistScreen` has List, Add, Edit, ConfirmDisable, ConfirmDelete modes
- F5 triggers refresh
- a/e/d/x keys map to add/edit/disable/delete
- Disabled entries shown in dark gray
