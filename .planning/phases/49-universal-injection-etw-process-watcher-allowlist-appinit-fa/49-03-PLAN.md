3. `start_injection_task` function — the main entry point:
   ```rust
   pub fn start_injection_task(
       rx: crossbeam_channel::Receiver<ProcessEvent>,
       injector: HookInjector,
       registry: Arc<ProcessRegistry>,
       allowlist_matcher: AllowlistMatcher,
       siem_tx: Option<mpsc::Sender<dlp_common::AuditEvent>>,
   ) -> tokio::task::JoinHandle<()>
   ```
   This spawns a tokio task that loops on `rx.recv()` and processes each `ProcessEvent`:

   a. If `event.event_type == ProcessEventType::Stop`:
      - Call `registry.record_exited(event.pid)`
      - `continue`

   b. If `event.event_type == ProcessEventType::Start`:
      - If `registry.should_skip(event.pid)` → `trace!(pid, "injection skipped — already in registry")`, `continue`
      - Call `registry.record_discovered(event.pid)`
      - Run `allowlist_matcher.check(event.pid, &event.image_path)`:
        - If `Skipped(reason)` → `registry.record_skipped(event.pid, reason)`, `trace!(pid, reason = ?reason, "allowlist skip")`, `continue`
      - If allowed, attempt injection:
        - `match injector.inject(event.pid)`:
          - `Ok(())` → `registry.record_injected(event.pid, arch)` where arch is from `HookInjector::target_architecture(event.pid)` (unwrap as "x64" on error)
          - `Err(HookError::AccessDenied { pid })` → log `warn!(pid, "injection access denied — expected for PPL/protected processes")`, `registry.record_skipped(event.pid, AllowlistReason::Ppl)` (treat as PPL since we missed it)
          - `Err(HookError::RemoteThreadFailed { pid, detail }) | Err(HookError::RemoteAllocFailed { pid, detail }) | Err(HookError::RemoteWriteFailed { pid, detail })` → log `error!(pid, error = %detail, "injection failed unexpectedly")`, emit `siem.injection_failure` audit event if `siem_tx` is Some, then retry once after 50ms (`tokio::time::sleep(Duration::from_millis(50)).await`), then attempt injection again. If second attempt also fails, record as failed.
          - `Err(HookError::InjectionFailed { pid, exit_code })` → same as above but with exit_code
          - `Err(HookError::ArchitectureMismatch { .. }) | Err(HookError::DllNotFound { .. }) | Err(HookError::PathTooLong { .. })` → log `error!`, these are configuration errors, no retry

   c. The task runs until the channel is disconnected (sender dropped), then exits cleanly.
