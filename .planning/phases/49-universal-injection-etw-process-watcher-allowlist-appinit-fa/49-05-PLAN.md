# 49-05 — Telemetry + Installer + Tests: Coverage Metrics + AppInit Setup + Validation

## Objective

Complete Phase 49 with telemetry aggregation (including latency SLA metrics), installer AppInit_DLLs registry setup with backup/restore, and comprehensive tests. This is Wave 3 — depends on all prior plans.

## Background (from Reviews)

Cross-AI review identified these HIGH/MEDIUM-priority gaps:
1. **Coverage percent excludes timing dimension**: 500ms SLA is not measured. Fix: add latency SLA metric (% injected within 500ms).
2. **Telemetry denominator is ambiguous**: `injected / (injected + skipped_non_ppl + failed)` excludes some skipped categories and may overstate coverage. Fix: separate eligibility, intentional skip, failed, timed out, and hello-confirmed counts.
3. **Failed state cleanup every 60s erases diagnostics**: Removing failed states too quickly hurts troubleshooting. Fix: retain failed entries with capped history (max 1000 entries) instead of full cleanup.
4. **No integration tests simulating high process churn**: Need stress test harness.
5. **AppInit registry modification is high-risk**: No validation of DLL load success post-install. Fix: add post-install verification step.
6. **No per-category breakdown**: Operators need visibility into PPL vs AV vs system-critical skips.

All concerns are addressed in this revised plan.

```rust
//! Telemetry aggregation for universal injection coverage and latency metrics.

use crate::process_registry::ProcessCounts;
use std::time::{Duration, Instant};

/// Aggregated telemetry snapshot emitted per minute.
#[derive(Debug, Clone, PartialEq)]
pub struct InjectionTelemetry {
    pub timestamp: String,
    /// Total PIDs observed (eligible for injection).
    pub eligible_pids: u64,
    /// Successfully injected AND received hello.
    pub injected_hello: u64,
    /// Injected but no hello received yet (may be pending or failed silently).
    pub injected_no_hello: u64,
    /// Skipped by category.
    pub skipped_self: u64,
    pub skipped_avedr: u64,
    pub skipped_system: u64,
    pub skipped_ppl: u64,
    pub skipped_wow64: u64,
    pub skipped_operator: u64,
    pub skipped_failed: u64,
    /// Failed injection attempts (retained).
    pub failed_count: u64,
    /// Timed out injection attempts.
    pub timed_out_count: u64,
    /// Latency percentiles (ms).
    pub latency_p50: f64,
    pub latency_p95: f64,
    pub latency_p99: f64,
    /// Percentage of injections under 500ms.
    pub pct_under_500ms: f64,
    /// Coverage percentage.
    pub coverage_percent: f64,
}

impl InjectionTelemetry {
    /// Build telemetry from process counts + latency histogram.
    pub fn from_counts_and_latency(
        counts: &ProcessCounts,
        latency: &crate::universal_injector::LatencyHistogram,
    ) -> Self {
        let eligible = counts.injected_hello
            + counts.injected_no_hello
            + counts.skipped_self
            + counts.skipped_avedr
            + counts.skipped_system
            + counts.skipped_ppl
            + counts.skipped_wow64
            + counts.skipped_operator
            + counts.skipped_failed;

        let coverage = if eligible > 0 {
            (counts.injected_hello as f64 / eligible as f64) * 100.0
        } else {
            100.0
        };

        let (p50, p95, p99) = latency.percentiles();
        let pct_500 = latency.pct_under_500ms();

        Self {
            timestamp: chrono::Utc::now().to_rfc3339(),
            eligible_pids: eligible,
            injected_hello: counts.injected_hello,
            injected_no_hello: counts.injected_no_hello,
            skipped_self: counts.skipped_self,
            skipped_avedr: counts.skipped_avedr,
            skipped_system: counts.skipped_system,
            skipped_ppl: counts.skipped_ppl,
            skipped_wow64: counts.skipped_wow64,
            skipped_operator: counts.skipped_operator,
            skipped_failed: counts.skipped_failed,
            failed_count: counts.skipped_failed,
            timed_out_count: 0, // tracked separately in injector
            latency_p50: p50,
            latency_p95: p95,
            latency_p99: p99,
            pct_under_500ms: pct_500,
            coverage_percent: coverage,
        }
    }

    /// Convert to SIEM audit event JSON.
    pub fn to_siem_event(&self) -> serde_json::Value {
        serde_json::json!({
            "event_type": "siem.injection_telemetry",
            "timestamp": self.timestamp,
            "eligible_pids": self.eligible_pids,
            "injected_hello": self.injected_hello,
            "injected_no_hello": self.injected_no_hello,
            "skipped": {
                "self": self.skipped_self,
                "avedr": self.skipped_avedr,
                "system_critical": self.skipped_system,
                "ppl": self.skipped_ppl,
                "wow64": self.skipped_wow64,
                "operator_defined": self.skipped_operator,
                "failed": self.skipped_failed,
            },
            "latency_ms": {
                "p50": self.latency_p50,
                "p95": self.latency_p95,
                "p99": self.latency_p99,
            },
            "pct_under_500ms": self.pct_under_500ms,
            "coverage_percent": self.coverage_percent,
        })
    }
}
```

Add `pub mod telemetry;` to `lib.rs`.

### Task 3: Implement failed-state retention with cap (1000 entries)

**Files:** dlp-agent/src/process_registry.rs (modify)

**Action:**
Modify `ProcessRegistry` to cap total entries at 1000, with LRU eviction for `Exited` and `Skipped(Failed)` entries:

```rust
const MAX_REGISTRY_SIZE: usize = 1000;

impl ProcessRegistry {
    /// Insert with LRU eviction if over cap.
    pub fn insert_with_eviction(&self,
        key: ProcessKey,
        state: ProcessState,
    ) {
        // If at cap, remove oldest Exited or Failed entries.
        if self.states.len() >= MAX_REGISTRY_SIZE {
            let to_evict: Vec<ProcessKey> = self
                .states
                .iter()
                .filter(|entry| {
                    matches!(entry.value(), ProcessState::Exited)
                        || matches!(entry.value(), ProcessState::Skipped(SkipReason::Failed(_)))
                })
                .take(self.states.len() - MAX_REGISTRY_SIZE + 1)
                .map(|entry| *entry.key())
                .collect();
            for k in to_evict {
                self.states.remove(&k);
            }
        }
        self.states.insert(key, state);
    }
}
```

Update `record_injected`, `record_skipped`, `record_exited` to use `insert_with_eviction`.

**Verify:** `cargo test -p dlp-agent registry_eviction` passes.

**Acceptance criteria:**

```powershell
# AppInit_DLLs setup
$appinitKey = "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows"
$backupKey = "HKLM:\SOFTWARE\DLP\Backup\AppInit_DLLs"

# Read current values for backup
$currentDlls = (Get-ItemProperty -Path $appinitKey -Name "AppInit_DLLs" -ErrorAction SilentlyContinue).AppInit_DLLs
$currentLoad = (Get-ItemProperty -Path $appinitKey -Name "LoadAppInit_DLLs" -ErrorAction SilentlyContinue).LoadAppInit_DLLs
$currentSigned = (Get-ItemProperty -Path $appinitKey -Name "RequireSignedAppInit_DLLs" -ErrorAction SilentlyContinue).RequireSignedAppInit_DLLs

# Create backup
New-Item -Path $backupKey -Force | Out-Null
Set-ItemProperty -Path $backupKey -Name "AppInit_DLLs" -Value $currentDlls
Set-ItemProperty -Path $backupKey -Name "LoadAppInit_DLLs" -Value $currentLoad
Set-ItemProperty -Path $backupKey -Name "RequireSignedAppInit_DLLs" -Value $currentSigned

# Set new values
$dlpDllPath = "C:\Program Files\DLP\dlp_hook_dll.dll"
Set-ItemProperty -Path $appinitKey -Name "AppInit_DLLs" -Value $dlpDllPath
Set-ItemProperty -Path $appinitKey -Name "LoadAppInit_DLLs" -Value 1
Set-ItemProperty -Path $appinitKey -Name "RequireSignedAppInit_DLLs" -Value 1

Write-Host "AppInit_DLLs configured. Backup saved to $backupKey"
```

Add uninstall restore:
```powershell
# Restore from backup

    Set-ItemProperty -Path $appinitKey -Name "LoadAppInit_DLLs" -Value $backup.LoadAppInit_DLLs
    Set-ItemProperty -Path $appinitKey -Name "RequireSignedAppInit_DLLs" -Value $backup.RequireSignedAppInit_DLLs
```

```rust
mod integration_tests {

    use std::sync::Arc;

    #[tokio::test]
    async fn test_simulated_etw_stream() {
        let registry = Arc::new(ProcessRegistry::new());
        let matcher = Arc::new(AllowlistMatcher::new(vec![], "C:\\dlp\\dlp-agent.exe".into(), 1234));

            let event = ProcessEvent {

                image_path: format!("C:\\Program Files\\App{}\\app.exe", i),

        assert_eq!(counts.discovered, 0); // all should be claimed
        assert!(counts.injected_hello + counts.injected_no_hello + counts.skipped_failed > 0);
    }
}
```

```rust
#[cfg(test)]
mod stress_tests {
    use super::*;

    #[tokio::test]
    async fn test_high_churn_1000_processes() {
        let registry = Arc::new(ProcessRegistry::new());
        let matcher = Arc::new(AllowlistMatcher::new(vec![], "C:\\dlp\\dlp-agent.exe".into(), 1234));
        let injector = Arc::new(HookInjector::new("C:\\dlp\\dlp_hook_dll.dll", None));
        let universal = UniversalInjector::new(registry, matcher, injector);

        let start = Instant::now();
        for i in 0..1000 {
            let event = ProcessEvent {
                pid: 2000 + (i % 500), // simulate PID reuse
                image_path: format!("C:\\Temp\\app{}.exe", i),
                parent_pid: 1,
                creation_time: i as u64,
                source: EventSource::Etw,
                event_timestamp: Instant::now(),
            };
            universal.handle_event(event, &tokio::sync::mpsc::channel(1).0).await;
        }
        let elapsed = start.elapsed();

        let counts = universal.registry.counts();
        let total = counts.injected_hello
            + counts.injected_no_hello
            + counts.skipped_self
            + counts.skipped_avedr
            + counts.skipped_system
            + counts.skipped_ppl
            + counts.skipped_wow64
            + counts.skipped_operator
            + counts.skipped_failed;

        assert_eq!(total, 1000, "all 1000 events should be accounted for");
        assert!(elapsed < Duration::from_secs(10), "should process 1000 events in <10s");
    }
}
```
