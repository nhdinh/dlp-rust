   - `check(&self, pid: u32, image_path: &str) -> AllowlistMatchResult` — the main entry point that runs checks in this exact order:
     a. If `pid == self_pid` → return `Skipped(AllowlistReason::SelfProcess)`
     b. If `pid == 0 || pid == 4` → return `Skipped(AllowlistReason::SystemCritical)`
     c. If image_path basename matches any of: `csrss.exe`, `smss.exe`, `wininit.exe`, `services.exe`, `lsass.exe`, `fontdrvhost.exe`, `dwm.exe` (case-insensitive) → return `Skipped(AllowlistReason::SystemCritical)`
     d. If `image_path` starts with `self_image_path` (self binary directory) → return `Skipped(AllowlistReason::SelfProcess)`
     e. For each `entry` in `self.entries`:
        - If `entry.path` is Some and matches `image_path` (exact or glob via `glob::Pattern::matches`): return `Skipped(reason_from_category(entry.category))`
        - If `entry.cert_subject` is Some: call `extract_cert_subject(image_path)` and if the returned string contains the `cert_subject` as substring (case-insensitive), return `Skipped(reason_from_category(entry.category))`
     f. Check PPL at injection time: call `is_protected_process_light(pid)` — if true, return `Skipped(AllowlistReason::Ppl)`
     g. All checks passed → return `Allowed`

6. Helper `reason_from_category(cat: AllowlistCategory) -> AllowlistReason`:
   - `SelfProcess -> AllowlistReason::SelfProcess`
   - `Avedr -> AllowlistReason::Avedr`
   - `SystemCritical -> AllowlistReason::SystemCritical`
   - `OperatorDefined -> AllowlistReason::OperatorDefined`

7. `extract_cert_subject(image_path: &str) -> String` — reuses the 4-step WinCrypt pattern from `detection/app_identity.rs` but extracts the FULL cert subject string (not just CN). Use `CertGetNameStringW` with `CERT_NAME_ATTR_TYPE` and `"2.5.4.3"` (CN) OR use the existing `CERT_NAME_SIMPLE_DISPLAY_TYPE` and document that it returns the display name (typically CN). <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ETW callback -> tokio task | ETW callback runs on kernel-managed thread; must not block |
| Agent -> target process | Injection crosses process boundary; requires PROCESS_ALL_ACCESS |
| Allowlist config -> injection decision | Malformed allowlist could permit injection into AV/EDR |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-01 | Denial of Service | `allowlist.rs` check() | mitigate | System-critical process exclusion (csrss, smss, lsass, etc.) per BLOCK-06; self-PID exclusion prevents agent self-injection loop |
| T-49-02 | Tampering | `appinit.rs` registry read | accept | Agent reads-only; installer manages writes. Secure Boot disables AppInit anyway. No runtime modification. |
| T-49-03 | Information Disclosure | `extract_cert_subject()` | mitigate | Returns empty string on failure; no cert data logged. Only subject string (not key material) is extracted. |
| T-49-04 | Elevation of Privilege | PPL detection bypass | mitigate | PPL checked at injection time (D-19), not cached. `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` fails safely to `false`. |
| T-49-05 | Denial of Service | `ProcessRegistry` DashMap | mitigate | Lock-free concurrent map prevents blocking between ETW callback and injection task. No Mutex/RwLock on hot path. |
</threat_model>
