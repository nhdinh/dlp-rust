## Key Decisions

1. **Genesis hash**: `hex(sha256("DLP-AUDIT-CHAIN-v1-GENESIS"))` — deterministic, same everywhere
2. **Canonical JSON**: excludes hash fields before hashing (avoids circular dependency)
3. **Per-agent chains**: server verifies prev_hash against last stored chain_hash per agent_id
4. **Backward compat**: events without hash fields accepted without verification, stored as NULL
5. **Tamper alert**: synthetic `AuditEvent` with `EventType::ChainBreakDetected`, `Decision::DenyWithAlert`
