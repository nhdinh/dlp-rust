       ```rust
       /// Reads the last line of `path` and attempts to parse it as an AuditEvent.
       /// Returns the event's `chain_hash` if present, otherwise None.
       fn recover_last_hash_from_log(path: &Path) -> Option<String> {
           use std::io::{BufRead, BufReader};
           let file = std::fs::File::open(path).ok()?;
           let reader = BufReader::new(file);
           reader
               .lines()
               .filter_map(|line| line.ok())
               .filter_map(|line| serde_json::from_str::<dlp_common::AuditEvent>(&line).ok())
               .filter_map(|event| event.chain_hash)
               .last()
       }
       ```

    2. Modify `AuditEmitter::open()` to attempt recovery after opening the file:
       ```rust
       let last_chain_hash = if log_path.exists() {
           recover_last_hash_from_log(&log_path).unwrap_or_else(dlp_common::audit::genesis_hash)
       } else {
           dlp_common::audit::genesis_hash()
       };
       Ok(Self {
           writer: Mutex::new(BufWriter::new(file)),
           log_path,
           max_bytes,
           events_since_check: Mutex::new(0),
           last_chain_hash: Mutex::new(last_chain_hash),
       })
       ```

    3. Consider a more efficient tail-read implementation if the JSONL file is large. If the file size is > 1 MiB, seek to near-end and read the last complete line instead of streaming all lines.
