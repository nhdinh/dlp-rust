Verify the SHA-256 hash chain on the server side as events are ingested. For each event with a `chain_hash`, recompute the expected hash, check event integrity, compare `prev_hash` against the last stored chain hash for the same agent, and trigger a tamper alert via `alert_router.send_alert()` when any check fails. Maintain backward compatibility by skipping verification for legacy events without hash fields.
</objective>

# Key interfaces

From dlp-server/src/audit_store.rs (existing pattern):
- `ingest_events` validates events, clones for relay/alert, then spawns blocking DB insert
- `store_events_sync` is a synchronous helper for admin handlers
- `alert_events` are filtered from `relay_events` by `Decision::DenyWithAlert`
- `state.alert` (AlertRouter) is used for real-time alerts

- `AuditEventRow` includes `prev_hash` and `chain_hash` fields
- `AuditEventRepository::get_last_chain_hash(pool, agent_id)` returns the latest chain_hash per agent
- `AuditEventRepository::insert_batch` writes rows to the DB

From dlp-common/src/audit.rs (already completed):
- `pub fn genesis_hash() -> String`
- `pub fn compute_chain_hash(prev_hash: &str, event: &AuditEvent) -> Result<String, serde_json::Error>`
- `EventType::ChainBreakDetected` routes to SIEM and triggers_alert

    1. After the app-identity validation loop and before `let count = events.len();`, add a chain verification pass that requires mutable access or produces a side-effect flag. Since `events` is `Json<Vec<AuditEvent>>` (moved), iterate by reference:
       ```rust
       let mut chain_breaks = Vec::new();
       for event in &events {
           if let Some(ref chain_hash) = event.chain_hash {
               let prev_hash = event.prev_hash.as_deref().unwrap_or_else(|| dlp_common::audit::genesis_hash());
               match dlp_common::audit::compute_chain_hash(prev_hash, event) {
                   Ok(expected) => {
                       if expected != *chain_hash {
                           chain_breaks.push((event.agent_id.clone(), event.correlation_id.clone(), "integrity_mismatch".to_string()));
                       } else {
                           // Verify continuity against last stored hash
                           match AuditEventRepository::get_last_chain_hash(&pool, &event.agent_id) {
                               Ok(Some(last_hash)) => {
                                   if prev_hash != last_hash {
                                       chain_breaks.push((event.agent_id.clone(), event.correlation_id.clone(), "continuity_break".to_string()));
                                   }
                               }
                               Ok(None) => {
                                   // No prior hash: prev_hash must be genesis
                                   if prev_hash != dlp_common::audit::genesis_hash() {
                                       chain_breaks.push((event.agent_id.clone(), event.correlation_id.clone(), "missing_genesis".to_string()));
                                   }
                               }
                               Err(e) => {
                                   tracing::error!(error = %e, agent_id = %event.agent_id, "failed to query last chain hash");
                               }
                           }
                       }
                   }
                   Err(e) => {
                       tracing::error!(error = %e, agent_id = %event.agent_id, "failed to compute chain hash");
                   }
               }
           }
       }
       ```
       NOTE: The `pool` is borrowed from `state.pool` later. Move the pool clone earlier so it is available here:
       ```rust
       let pool = Arc::clone(&state.pool);
       ```
       before the verification loop.

    2. Pass `chain_breaks` into the spawn_blocking closure by cloning it:
       ```rust
       let chain_breaks_for_block = chain_breaks.clone();
       ```

    3. After the spawn_blocking returns and before SIEM relay, trigger tamper alerts if any chain breaks occurred:
       ```rust
       if !chain_breaks.is_empty() {
           let alert_router = Arc::clone(&state.alert);
           tokio::spawn(async move {
               for (agent_id, correlation_id, reason) in chain_breaks {
                   let synthetic = dlp_common::AuditEvent::new(
                       dlp_common::EventType::ChainBreakDetected,
                       "S-1-5-18".to_string(),
                       "SYSTEM".to_string(),
                       "audit_chain_break".to_string(),
                       dlp_common::Classification::T4,
                       dlp_common::Action::WRITE,
                       dlp_common::Decision::DenyWithAlert,
                       agent_id.clone(),
                       0,
                   )
                   .with_correlation_id(correlation_id.clone());
                   if let Err(e) = alert_router.send_alert(&synthetic).await {
                       tracing::error!(error = %e, agent_id = %agent_id, "failed to send chain break alert");
                   }
                   tracing::error!(agent_id = %agent_id, correlation_id = %correlation_id.as_deref().unwrap_or("none"), reason = %reason, "audit chain break detected");
               }
           });
       }
       ```

    4. Ensure `AuditEvent::with_correlation_id` exists; if not, set `correlation_id` directly after construction using the existing builder pattern or field mutation.

    5. Add `use dlp_common::{Action, Classification, Decision};` if not already in scope.
