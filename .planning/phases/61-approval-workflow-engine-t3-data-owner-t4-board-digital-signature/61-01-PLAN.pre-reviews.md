<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| signing_key -> token | The Ed25519 private key never leaves the server process |
| API -> DB | SQL queries parameterized; no string interpolation |
| token -> agent | Token is signed; agent verifies with public key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-61-01 | Spoofing | `ApprovalTokenService::sign_token` | mitigate | Ed25519 cryptographic signatures; token includes expiry (`exp`) claim |
| T-61-02 | Tampering | `verify_token` | mitigate | Signature verification rejects tampered tokens; `jsonwebtoken` library validates standard claims |
| T-61-03 | Information Disclosure | `DLP_APPROVAL_PRIVATE_KEY` env var | mitigate | Key loaded once at startup into memory; env var can be unset after first boot |
| T-61-04 | Elevation of Privilege | Board signature verification | mitigate | T4 grants require valid Ed25519 signature against stored pubkey; no signature = 400 error |
| T-61-05 | Denial of Service | Keypair generation | accept | One-time operation at startup; negligible impact |
</threat_model>
