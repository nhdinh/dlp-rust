<objective>
Build the admin HTTP API for approval lifecycle management: create, list, grant, reject, revoke. Add agent-facing approval request endpoint. T4 grants require Board digital signature verification. All state changes emit audit events and alerts. Server pushes tokens to agents on grant.

Purpose: Provides the REST interface consumed by the admin TUI (Plan 04) and the agent (Plan 03). This is the control plane for the approval workflow.
Output: `dlp-server/src/approval_api.rs` with handlers; `/admin/approvals` routes wired in `admin_api.rs`; `/agent/approval-request` endpoint; approval audit event types in `dlp-common`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin TUI -> API | JWT-authenticated; only dlp-admin can grant/reject/revoke |
| API -> DB | SQL parameterized; no string interpolation |
| Board signature -> T4 grant | Cryptographic verification against stored pubkey |
| Agent -> API | Agent credentials authenticate approval requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-61-06 | Spoofing | `grant_approval` approver_sid | mitigate | Extracted from validated JWT claims; cannot be forged by client |
| T-61-07 | Tampering | T4 signature bypass | mitigate | Server verifies Ed25519 signature against stored board pubkey; missing/invalid = 400 |
| T-61-08 | Elevation of Privilege | Non-admin grants approval | mitigate | Route is under JWT auth layer; only dlp-admin token valid |
| T-61-09 | Repudiation | Missing audit on grant | mitigate | Every state change emits AuditEvent to siem_connector; append-only audit_events table |
| T-61-10 | Information Disclosure | Token in audit event | accept | Token is a signed JWT; no private key material exposed |
| T-61-11 | TOCTOU | Concurrent grant | mitigate | `WHERE status = 'pending'` with rows_affected check; 409 on conflict |
| T-61-12 | Elevation of Privilege | Board key swap | mitigate | `PUT /admin/board-public-key` restricted to dlp-admin with audit event |
| T-61-13 | Denial of Service | Invalid valid_until | mitigate | Rejected if valid_until <= now; prevents already-expired grants |
</threat_model>
