<objective>
Build the admin HTTP API for approval lifecycle management: create, list (with pagination), grant, reject, revoke. Add agent-facing approval request endpoint and startup sync endpoint. T4 grants require Board digital signature verification. All state changes emit audit events and alerts. Server pushes tokens to agents on grant and supports agent startup sync.

Purpose: Provides the REST interface consumed by the admin TUI (Plan 04) and the agent (Plan 03). This is the control plane for the approval workflow.
Output: `dlp-server/src/approval_api.rs` with handlers; `/admin/approvals` routes wired in `admin_api.rs`; `/agent/approval-request` and `/agent/approvals/active` endpoints; approval audit event types in `dlp-common`.
