       let dec_key = DecodingKey::from_ed_der(&verifying_key.to_bytes());

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-61-01 | Spoofing | `ApprovalTokenService::sign_token` | mitigate | Ed25519 cryptographic signatures; token includes expiry (`exp`) claim and issuer (`iss`) |
| T-61-02 | Tampering | `verify_token` | mitigate | Signature verification rejects tampered tokens; `jsonwebtoken` library validates standard claims including `iss` |
| T-61-03 | Information Disclosure | Encrypted signing key storage | mitigate | Key encrypted with Phase 47 Envelope (PBKDF2 + DPAPI + AES-256-GCM); loaded once at startup into memory |
| T-61-04 | Elevation of Privilege | Board signature verification | mitigate | T4 grants require valid Ed25519 signature against stored pubkey; no signature = 400 error |
| T-61-05 | Denial of Service | Keypair generation | accept | One-time operation at startup; negligible impact |
| T-61-06 | Repudiation | T4 signature replay | mitigate | Canonical message includes `jti` (approval ID); signature cannot be replayed across different approvals |
