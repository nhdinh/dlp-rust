</read_first>

<action>
1. In `dlp-common/src/abac.rs`, add `DragDrop` to the `Action` enum:
```rust
/// Supported ABAC actions for policy evaluation.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "SCREAMING_SNAKE_CASE")]
pub enum Action {
    READ,
    WRITE,
    COPY,
    DELETE,

    /// Drag-and-drop operation (Phase 40).
    DRAG_DROP,
}
```

Ensure the variant serializes as `"DRAG_DROP"`.
