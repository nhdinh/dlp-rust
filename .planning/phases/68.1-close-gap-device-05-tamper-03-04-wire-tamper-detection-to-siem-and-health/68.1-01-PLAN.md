## Objective

Close the server-side gaps for DEVICE-05 and TAMPER-03 by:
1. Extending the `POST /audit/events` response to report chain-break detection back to the requesting agent (per D-01).
2. Routing synthetic `ChainBreakDetected` events to both SIEM relay and syslog queue, not just `alert_router` (per D-03).

## Scope Boundary

- In scope: `ingest_events` response body, `send_audit_events` return type, synthetic event relay wiring.
- Out of scope: Agent-side reaction to tamper flag (Plan 02), ABAC health wiring (Plan 02), TUI screen (Plan 03).

## Threat Model

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-68.1-01 | Tampering | ingest_events response | mitigate | JSON response with additive fields; older agents ignore via #[serde(default)] |
| T-68.1-02 | Information Disclosure | IngestEventsResponse | mitigate | Only returns agent's own tamper status; no cross-agent leakage |
| T-68.1-03 | Denial of Service | syslog_events extend | mitigate | Synthetic events are appended to existing Vec; no additional allocations beyond clone |
| T-68.1-04 | Spoofing | tamper_detected_for_agent | mitigate | Server is authoritative; agent only reacts to server's response |
