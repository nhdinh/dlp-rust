## Objective

Close the TAMPER-04 gap by adding an admin TUI Audit Integrity screen that consumes the existing `GET /admin/audit/integrity` endpoint and displays per-agent chain status, break counts, and integrity summary. The screen follows the established `BypassAlertList` pattern for consistency.

## Scope Boundary

- In scope: New TUI screen module, client method, screen variant, dispatch handler, render function, system menu entry, tests.
- Out of scope: Server-side endpoint changes (already exists in `audit_store.rs`), new API routes, new data types.
