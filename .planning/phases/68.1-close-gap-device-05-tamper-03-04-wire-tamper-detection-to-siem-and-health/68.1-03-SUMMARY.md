# Plan 68.1-03 Summary

## Phase

68.1-close-gap-device-05-tamper-03-04-wire-tamper-detection-to-siem-and-health

## Plan

03

## Objective

Close the TAMPER-04 gap by adding an admin TUI Audit Integrity screen that consumes the existing `GET /admin/audit/integrity` endpoint and displays per-agent chain status, break counts, and integrity summary. The screen follows the established `BypassAlertList` pattern for consistency.

## Tasks Completed

### Task 1: Create audit_integrity.rs screen module with constants

- Created `dlp-admin-cli/src/screens/audit_integrity.rs` with:
  - `AUDIT_INTEGRITY_LIST_HINTS` — footer hint string with key bindings: `[f] Filter Agent  [r] Refresh  [Enter] Detail  [PgUp/PgDn] Page  [Esc] Back`
  - `AUDIT_INTEGRITY_LIST_EMPTY` — "No audit integrity data found."
  - `AUDIT_INTEGRITY_DETAIL_HINTS` — "[Enter/Esc] Back to list"
- Added `#[cfg(test)]` module with 3 tests verifying all constants.
- Added `pub mod audit_integrity;` to `dlp-admin-cli/src/screens/mod.rs`.

### Task 2: Add Screen variant, filter enum, and SystemMenu entry

- Added `AuditIntegrityList` variant to `Screen` enum with 7 fields: `agents`, `selected`, `filter`, `page`, `page_size`, `total`, `integrity_ok`.
- Added `AuditIntegrityDetail` variant to `Screen` enum with field `agent`.
- Added `AuditIntegrityFilter` enum with `All` and `PerAgent(String)` variants, implementing `next()`, `agent_id()`, and `label()`.
- Updated `handle_system_menu` in `dispatch.rs`: expanded nav from 14 to 15 items, added index 14 mapping to `action_load_audit_integrity(app, AuditIntegrityFilter::All, 0)`.
- Added `Screen::AuditIntegrityList` and `Screen::AuditIntegrityDetail` match arms in top-level `handle_event`.
- Updated `system_menu_item_count_and_order` test to 15 items.
- Fixed `handle_system_menu_has_14_items` test (renamed to `handle_system_menu_has_15_items`).

### Task 3: Add client method and render function

- Added `EngineClient::list_audit_integrity(agent_id: Option<&str>)` in `client.rs`:
  - Builds URL `admin/audit/integrity` with optional `?agent_id=` query param.
  - Returns `Result<serde_json::Value>`.
- Added 2 unit tests: `test_list_audit_integrity_method_exists`, `test_list_audit_integrity_with_agent_id`.
- Added `draw_audit_integrity_list` in `render.rs`:
  - Top banner with integrity status (green "OK" or red "BROKEN" with BOLD).
  - Table headers: Agent ID | Events | Verified | Breaks | Last Hash (truncated to 16 chars).
  - Selected row highlighting, footer hints, page indicator.
- Added `draw_audit_integrity_detail` in `render.rs`:
  - Detail popup with agent_id, event_count, verified_count, break_count, last_chain_hash, and chain_breaks list.
- Wired both Screen variants into the `draw` function match.
- Added 4 render unit tests: empty list, agent row rendering, detail with all fields, detail with no breaks.

### Task 4: Add dispatch handlers for AuditIntegrityList and AuditIntegrityDetail

- Added `handle_audit_integrity_list` in `dispatch.rs`:
  - Up/Down navigation, `f` filter cycling, `r` refresh, PgUp/PgDn pagination, Enter opens detail, Esc returns to SystemMenu (selected=14).
- Added `handle_audit_integrity_detail` in `dispatch.rs`:
  - Enter/Esc returns to list with `AuditIntegrityFilter::All`.
- Added `action_load_audit_integrity` in `dispatch.rs`:
  - Calls `client.list_audit_integrity()`, parses response into `Screen::AuditIntegrityList`.
- Added 3 unit tests:
  - `handle_audit_integrity_list_esc_goes_to_system_menu`
  - `handle_audit_integrity_list_enter_opens_detail`
  - `handle_audit_integrity_list_page_down_loads_next_page`

## Decisions

1. `AuditIntegrityFilter` uses `PerAgent(String)` for agent-specific filtering. The `next()` cycle goes `All -> PerAgent("") -> All`. When `PerAgent` has an empty string, `agent_id()` returns `None`, effectively showing all agents.
2. The detail view returns to the list with `AuditIntegrityFilter::All` (not preserving the previous filter), matching the `BypassAlertDetail` pattern.
3. SystemMenu index 14 is "Audit Integrity", positioned after "Syslog Config" (index 12) and "Back to Main Menu" (index 13). This keeps the new screen in the System submenu alongside other monitoring/audit features.
