<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client->API | Untrusted HTTP client sends PolicyPayload JSON; serde default shields missing mode field |
| DB->PolicyStore | DB row mode string parsed into PolicyMode; malformed values are skipped (fail-safe) |
| PolicyStore->evaluate | Read-lock held during evaluation; mode switch is O(1) enum dispatch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Tampering | PolicyPayload JSON without mode | mitigate | `#[serde(default)]` on PolicyPayload.mode ensures missing field defaults to ALL (POLICY-12) |
| T-18-02 | Denial of Service | Migration re-run on every startup | mitigate | `run_alter` swallows only "duplicate column name" errors; all other errors bubble up |
| T-18-03 | Information Disclosure | Malformed mode in DB row logged | accept | Warn log contains policy_id only; no sensitive data exposed |
| T-18-04 | Elevation of Privilege | Empty-conditions ALL policy matches unconditionally | accept | Documented behavior per D-13; matches v0.4.0 semantics |
| T-18-05 | Tampering | npm/pip/cargo installs | mitigate | No new dependencies in this phase; slopcheck not triggered |
</threat_model>
