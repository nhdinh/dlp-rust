- Integration test compilation failed because #[cfg(test)] gating does not apply when a crate is used as a dev-dependency. - CreateFileMappingW with Global\ prefix requires administrator privileges. Solved by changing test cache name to Local\ prefix.
- Pre-existing hook_journal test (test_error_already_exists_opens_existing) is flaky when run in full suite but passes in isolation. Not related to our changes.
