## Existing Implementation (from source files)

### dlp-agent/src/classification_cache.rs (agent writer)
- `ClassificationCache::new()` creates `Global\DlpClassificationCache` (2 MiB, PAGE_READWRITE, SDDL-protected).
- `rebuild(entries)` performs sequence-lock: odd version_word during write, even version_word after Release fence.
- `prepopulate_t3_t4_roots(roots)` builds initial prefix entries.
- `CacheHeader` has `version_word: AtomicU64` at offset 0, `magic: u64` at offset 8, `created_at_epoch_secs: u64` at offset 72.
- Version encoding: high 63 bits = version number, low bit = active buffer. Odd = writer in progress.

### dlp-hook-dll/src/classification_cache.rs (hook DLL reader)
- `CacheLookup::get()` lazy-init via `OpenFileMappingW` + `MapViewOfFile` (FILE_MAP_READ).
- `lookup(path, op, now_secs)` reads version_word with Acquire, checks odd bit for writer-in-progress, performs full validation on version change.
- `CacheHeader` struct mirrors agent-side layout byte-for-byte.
- `LruCache` thread-local with 128 entries, version invalidation.
- `lru::clear_all()` flushes all entries for RESYNC.

### dlp-hook-dll/src/fail_mode.rs (state machine)
- `FailModeState` with atomic state (u8), failures (u32), successes (u32), cache_version_seen_at (u64).
- Thresholds: 3 failures Healthy->Degraded, 10 failures Degraded->Isolated.
- Hysteresis: 3 successes Degraded->Healthy, 5 successes Isolated/Resync->Healthy.
- `record_pipe_success(version)` checks `cache_version > last_seen` for ISOLATED->RESYNC.
- `record_pipe_failure()` transitions RESYNC->ISOLATED on any failure.
- `decide_isolated(classification, op)` asymmetric: T3/T4 write deny, T1/T2 allow, unknown write deny.
- `is_cache_stale(cache_version, header_version, header_created_at, now_secs)` uses T4=30s budget.

### dlp-hook-dll/src/background_thread.rs (RESYNC detector)
- `start_background_thread(cache_header, fail_state, verify_fn)` spawns thread with 100ms WaitForSingleObject loop.
- In ISOLATED: reads version_word with Acquire, skips odd versions, calls `record_pipe_success(version)` if version > last_seen.
- In RESYNC: relies on trampoline pipe successes for hysteresis; background thread only detects fresh versions.
- `THREAD_STARTED: AtomicBool` prevents double-start; `shutdown_background_thread()` signals exit.

            header: *const CacheHeader,

            Some(lookup)
