# Phase 38.3 Patterns

## Pattern: AGENT-UNKNOWN Sentinel Substitution

When an audit event is constructed and `source_application` or `destination_application` would be `None`, substitute the AGENT-UNKNOWN sentinel instead. The sentinel is an `AppIdentity` with all fields set to `"AGENT-UNKNOWN"` / `Unknown` tiers.

```rust
const AGENT_UNKNOWN_APP: AppIdentity = AppIdentity {
    image_path: "AGENT-UNKNOWN".to_string(),
    publisher: "AGENT-UNKNOWN".to_string(),
    trust_tier: AppTrustTier::Unknown,
    signature_state: SignatureState::Unknown,
};
```

## Pattern: Metric Counter Flush

In-memory `AtomicUsize` counters per path. Flush to audit log every 50 occurrences or on shutdown.

## Pattern: File Interception AppIdentity Resolution

For BLOCK events only: `get_application_metadata(pid)` -> `WinVerifyTrust` -> full `AppIdentity`.
For ACCESS events: skip WinVerifyTrust overhead, use `application_path` only.
