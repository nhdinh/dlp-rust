### Gaps Resolved

1. **Clippy `missing_const_for_thread_local`** in `dlp-agent/src/hook_ipc.rs:356`
   - Fixed by replacing `std::cell::Cell::new(None)` with `const { std::cell::Cell::new(None) }`.

2. **Integration test PID mismatch for `UnhookAck` validation**
   - `unhook_polling_protocol_roundtrip` and `unhook_polling_protocol_failed_ack` in `dlp-agent/tests/hook_ipc_integration.rs` used fixed PID `1234`, but the test-only `named_pipe_client_pid` override is gated behind `#[cfg(test)]` and inaccessible to integration tests (which link against the non-test lib build).
   - Fixed by making the test-only `named_pipe_client_pid` fall back to the real named-pipe client PID when no override is set, and updating the integration tests to use `std::process::id()` for registry seeding, `PollControl`, and `UnhookAck`.

3. **Missing audit context in failed-ack integration test**
   - `unhook_polling_protocol_failed_ack` did not attach an `EmitContext` to the test server, so the expected `UnhookFailure` audit event was never emitted.
   - Fixed by chaining `.with_audit_ctx(dlp_agent::audit_emitter::EmitContext::default())` on `HookIpcServer`.
