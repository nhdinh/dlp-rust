<objective>
Close UAT Test 7 blocker: after the dlp-agent service is stopped, injected processes still have dlp_hook_dll.dll loaded because the cooperative unhook dispatch was scheduled too late in `run_loop_shutdown` and the 35-second `SHUTDOWN_TIMEOUT` expired before `request_unhook_from_injected` could complete. Move unhook dispatch to the very beginning of shutdown, protect the unhook budget from other teardown steps, keep the hook IPC server alive during the unhook window, and add automated tests for the ordering and budget protection.

Purpose: Give every injected process the full shutdown budget to poll, receive `UnhookCommand`, and self-unload before the agent process terminates.
Output: Updated agent shutdown path, resilient IPC accept loop, and passing dlp-agent tests.
</objective>

  <action>
    Move the Phase 58.5 cooperative-unhook block to the very beginning of `run_loop_shutdown`, immediately after `shutdown_start` is recorded and before any other subsystem teardown (drag-drop hook uninstall, file monitor stop, event loop drop, heartbeat stop, config/registry/origins polls, disk enumeration, encryption check, device watcher, DACL tasks, WFP unregister, sync watcher, print enforcer, UI kill, or audit flush).

    Extract the budget computation into a pure helper `fn compute_unhook_budget(shutdown_timeout: Duration, configured: Duration, cleanup_reserve: Duration) -> Duration` in `dlp-agent/src/service.rs`. Use a `CLEANUP_RESERVE` of 5 seconds so the remaining teardown steps cannot push the service past `SHUTDOWN_TIMEOUT` even if unhook consumes the full budget.
