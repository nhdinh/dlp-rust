# Phase 58.5 Plan 03: Agent-Side Unhook Orchestration Summary

**Agent-side cooperative unhook orchestration with registry-validated PollControl/UnhookAck routing, bounded shutdown wait, and watchdog evidence reconciliation.**

## Performance

- **Duration:** 95 min
- **Started:** 2026-06-30T11:51:00Z
- **Completed:** 2026-06-30T14:26:00Z
- **Tasks:** 3
- **Files modified:** 7

## Accomplishments
- Added `ProcessRegistry::iter_injected` and `ProcessRegistry::record_unhooked` for PID-reuse-safe unhook state management.
- Threaded the process registry through `HookIpcServer` and implemented validated `PollControl` and success-gated `UnhookAck` routing.
- Added `emit_unhook_audit` helper supporting `AgentShutdownUnhook`, `UnhookFailure`, and `WatchdogSelfUnload` events.
- Integrated a bounded 5-second unhook wait into `run_loop_shutdown` using the global `UNHOOK_ALL_REQUESTED` flag.
- Reconciled watchdog self-unload evidence from `C:\ProgramData\DLP\WatchdogSelfUnload` on agent startup, with matched and untracked audit events.
- Restored the per-thread audit test capture sink with `audit_test_lock` and token propagation for reliable multi-threaded test assertions.

## Decisions Made
- Kept `UNHOOK_WAIT_BUDGET` at 5 seconds to preserve the remaining 5 seconds of the existing 10-second `SHUTDOWN_TIMEOUT` budget.
- Returned a `Vec` snapshot from `iter_injected` to avoid holding the `DashMap` across await points.
- Propagated the per-thread audit capture token into the mock server thread so multi-threaded `UnhookAck` tests could observe emitted events deterministically.
- Retained unmatched watchdog evidence files for bounded retry and emitted an `untracked` `WatchdogSelfUnload` audit event instead of silently dropping them.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Restored partially-applied audit test capture sink**
- **Found during:** Task 2 (audit helper and test capture)
- **Issue:** `emit()` and `emit_audit()` referenced a removed `TEST_CAPTURE_ENABLED` atomic and pushed raw `AuditEvent` values into a sink that now stores `(u64, AuditEvent)` tuples, causing compilation errors.
- **Fix:** Replaced the atomic check with `CURRENT_CAPTURE_TOKEN.with()`, added `enable_test_capture()`, `set_current_capture_token()`, `drain_test_events()`, and `audit_test_lock()` returning an `AuditTestGuard` that drains stale events on drop. Updated both emission paths to push `(token, event.clone())`.
- **Files modified:** `dlp-agent/src/audit_emitter.rs`, `dlp-agent/src/bypass_correlator.rs`
- **Verification:** `cargo test -p dlp-agent` passes; audit tests capture events reliably.
- **Committed in:** `b1a4ebe` (Task 3 commit)

**2. [Rule 1 - Bug] Fixed multi-threaded audit capture for UnhookAck failure test**
- **Found during:** Task 1 (UnhookAck routing tests)
- **Issue:** `unhook_ack_failure_routing_test` captured 0 events because the mock server thread emitted audits under a different capture token than the test thread.
- **Fix:** Generated a capture token in the test thread and propagated it to the server thread via `set_current_capture_token(token)` before calling `server.run_with_ready(...)`.
- **Files modified:** `dlp-agent/src/hook_ipc.rs`
- **Verification:** `unhook_ack_failure_routing_test` passes and captures the expected `UnhookFailure` event.
- **Committed in:** `b1a4ebe` (Task 3 commit)

**3. [Rule 1 - Bug] Fixed global atomic test flake in PollControl tests**
- **Found during:** Task 2 (PollControl routing tests)
- **Issue:** `poll_control_no_op_when_not_requested` failed intermittently when run concurrently with other tests that toggled the global `UNHOOK_ALL_REQUESTED` atomic.
- **Fix:** Added `#[serial_test::serial]` to the test so it runs in isolation.
- **Files modified:** `dlp-agent/src/hook_ipc.rs`
- **Verification:** PollControl tests pass reliably under `cargo test -p dlp-agent`.
- **Committed in:** `b1a4ebe` (Task 3 commit)

**4. [Rule 3 - Blocking] Restructured service initialization to provide registry to HookIpcServerConfig**
- **Found during:** Task 3 (service integration)
- **Issue:** `HookIpcServerConfig` needed the process registry created by `init_universal_injection`, but the original code tried to mutate an immutable config struct after construction.
- **Fix:** Reordered `run_loop_init` to build `HookIpcServerConfig` after `init_universal_injection` returns the registry, so the registry could be passed directly via `with_registry`. Added `#[allow(unused_variables)]` to the destructuring of `init_universal_injection` return values that were no longer all needed in the new order.
- **Files modified:** `dlp-agent/src/service.rs`
- **Verification:** `cargo clippy -p dlp-agent -- -D warnings` clean; `cargo test -p dlp-agent` passes.
- **Committed in:** `b1a4ebe` (Task 3 commit)
