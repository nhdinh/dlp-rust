<objective>
Implement cooperative self-unhook inside the hook DLL: integrate ntdll detour disable and real shared-memory unmapping into `UnhookAll()`, add active-call guards so unload waits for in-flight trampolines, replace unsound `OnceLock` reset with lock-protected `Option<Mapping>` globals, add a shutdown pass-through flag used by trampolines, capture the DLL HINSTANCE in `DllMain` for correct self-unload, and add a unified control-poll/watchdog thread that starts from a safe post-attach/init path, receives `UnhookCommand` from the agent during graceful shutdown, and self-unloads only after distinguishing transient pipe errors from true agent death.

Purpose: This is the in-process side of the unhook protocol. It ensures that when the agent is stopped or killed, every injected process can restore original IAT/ntdll stubs and release shared memory without crashing. Addresses Cycle 2 review concerns: control thread must start for every successful injection, unload safety requires active-call drains, OnceLock reset is unsound, and watchdog timeout must tolerate transient errors.
Output: Extended hook DLL with complete, review-safe self-unhook capability and unit tests verifying UnhookAll state transitions and unload safety.
</objective>
