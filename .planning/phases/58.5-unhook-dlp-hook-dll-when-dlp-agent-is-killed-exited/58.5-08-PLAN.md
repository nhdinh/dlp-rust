<objective>
Close the remaining UAT Test 7 blocker diagnosed in `.planning/debug/dll-remains-after-agent-kill.md`: even after the 58.5-07 shutdown-ordering fix, injected processes can still have `dlp_hook_dll.dll` loaded because (1) control-thread start was best-effort, (2) idle injected processes never lazily start a control thread, and (3) startup/backstop sweeps may double-load the DLL. The prior attempt to repair elevated reference counts from inside the DLL is unsafe, so this plan prevents reference-count inflation at the source and keeps the self-unload path atomic.

Purpose: Guarantee that every process recorded as `Injected` has a live control-poll thread before the agent requests unhook, prevent reference-count inflation from repeated injections, replace the unsafe in-DLL FreeLibrary loop with the safe atomic unload path, and keep the shutdown reconciliation pass within the unhook budget.

    - Create a remote thread at that address, wait up to 10 seconds, and verify the exit code is `0`.
