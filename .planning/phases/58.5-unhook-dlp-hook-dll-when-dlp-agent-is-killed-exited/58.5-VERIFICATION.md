# Phase 58.5: Unhook dlp_hook_dll.dll when dlp-agent is killed/exited — Verification Report

**Phase Goal:** Ensure the DLP agent cleanly unhooks `dlp_hook_dll.dll` from all injected processes when the agent service is killed, exits, or restarts, restoring original IAT/ntdll trampolines and releasing shared-memory resources without crashing host processes.

**Status:** passed

**Re-verification:** No — initial verification

## Goal Achievement

### Observable Truths

| # | Truth | Status | Evidence |
|---|-------|--------|----------|
| 1 | On agent graceful shutdown, every process injected with `dlp_hook_dll.dll` receives an unhook command and the DLL is unloaded or trampolines are restored to original bytes. | VERIFIED | `run_loop_shutdown` calls `request_unhook_from_injected`, which sets `UNHOOK_ALL_REQUESTED` and waits for acks; `HookIpcServer::handle_connection` replies to validated `PollControl` with `UnhookCommand`; `dlp-hook-dll` `StartDlpControlThread` is called immediately after `LoadLibraryW` so idle processes poll; `handle_unhook_command` calls `UnhookAll` to restore IAT and disable ntdll stubs; integration tests `unhook_polling_protocol_roundtrip` and `idle_injected_process_sends_poll_control_with_creation_time` exercise the full polling protocol with real DLL injection; UAT Test 7 recorded pass for live Windows DLL unload. |
| 2 | On agent crash or unexpected termination, a watchdog mechanism detects agent absence and triggers self-unload in hooked processes within a bounded timeout. | VERIFIED | `dlp-hook-dll/src/control_thread.rs` implements a control-poll loop with `MAX_FAILURES=3` and `WATCHDOG_TIMEOUT_MS=30_000`; on consecutive poll failures it persists watchdog evidence to `C:\ProgramData\DLP\WatchdogSelfUnload` and calls `self_unload`; agent startup `reconcile_watchdog_evidence` reconciles the evidence; unit tests `control_poll_thread_triggers_after_grace_and_failures` and integration test `watchdog_evidence_reconciliation_roundtrip` pass. |
| 3 | No host process crashes or hangs during unhook; original file I/O behavior is fully restored. | VERIFIED | `UnhookAll` sets `SHUTTING_DOWN`, drains active calls with a 5-second bounded timeout, restores IAT entries, calls `unpatch_all_stubs`, and unmaps shared memory; trampolines pass through to original APIs when `is_shutting_down()` is true; unit tests `unhook_all_drains_active_calls`, `shutting_down_passes_through_create_file_w`, `shutting_down_passes_through_nt_create_file`, and `unhook_all_infallible_per_stub` pass. |
| 4 | Shared-memory sections (`Global\\DlpClassificationCache`, per-process journal sections) are closed and released. | VERIFIED | `UnhookAll` calls `classification_cache::unmap_cache()` and `hook_journal::unmap_journal()`; both modules use `Mutex<Option<Mapping>>` ownership with `Drop` impls that call `UnmapViewOfFile` and `CloseHandle`; unit tests `unhook_all_unmaps_shared_memory`, `test_unmap_journal_releases_handle_and_view`, and `test_unmap_cache_releases_handle_and_view` pass. |
| 5 | Audit events are emitted for unhook lifecycle (`agent_shutdown_unhook`, `watchdog_self_unload`, `unhook_failure`). | VERIFIED | `dlp-common/src/audit.rs` defines `EventType::AgentShutdownUnhook`, `WatchdogSelfUnload`, and `UnhookFailure` with correct `routed_to_siem()` and `triggers_alert()` semantics; `dlp-agent/src/audit_emitter.rs` provides `emit_unhook_audit`; `request_unhook_from_injected` emits `AgentShutdownUnhook` and `UnhookFailure`; `reconcile_watchdog_evidence` emits `WatchdogSelfUnload`; unit tests `test_emit_unhook_audit_*` and `test_reconcile_watchdog_evidence_*` pass. |
