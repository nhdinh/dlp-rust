<task type="auto">
  <name>Task 1: Promote PHASE_58_5_TEST_LOCK to a crate-wide test-only static and add reset helpers</name>
  <files>dlp-hook-dll/src/lib.rs, dlp-hook-dll/src/hash_compute.rs, dlp-hook-dll/src/perf_telemetry.rs, dlp-hook-dll/src/pipe_client.rs, dlp-hook-dll/src/control_thread.rs</files>
  <action>
    Move `PHASE_58_5_TEST_LOCK` out of the `#[cfg(test)] mod tests` block in `dlp-hook-dll/src/lib.rs` to a top-level `#[cfg(test)] pub(crate) static` so every module's tests can import it directly.

    Add `#[cfg(test)] pub(crate)` reset helpers for each process-global static that tests mutate:
    - `reset_hash_queue_depth()` already exists in `hash_compute.rs`; make it `pub(crate)` and ensure it zeroes `HASH_QUEUE_DEPTH`.
    - In `perf_telemetry.rs`, add `reset_perf_counters()` that zeroes `PIPE_ROUND_TRIPS`, `CACHE_HITS_60S`, `CACHE_MISSES_60S`, `CURRENT_FAIL_STATE`, `INJECTED_PIDS`, `PATCHED_MODULES`, and `HEALTH_EMIT_COUNTER`.
    - In `pipe_client.rs`, add `reset_pipe_client_mocks()` that clears `MOCK_POLL_CONTROL` and `MOCK_UNHOOK_ACK_SINK`.
    - In `control_thread.rs`, ensure `reset_watchdog_test_state()` is `pub(crate)` and resets all watchdog/consecutive-failure state.
    - In `lib.rs`, add or expose `reset_hook_globals()` that resets `SHUTTING_DOWN`, `ACTIVE_CALLS`, `INITIALISED`, `DLL_INSTANCE`, and clears `NTDLL_PATCHER` if already set.

    Keep every helper behind `#[cfg(test)]` so release builds are unaffected.
  </action>
  <verify>
    <automated>cargo check -p dlp-hook-dll --tests</automated>
  </verify>
  <done>All reset helpers compile under `#[cfg(test)]` and are importable from any dlp-hook-dll test module.</done>

    - `lib.rs`: ensure all Phase 58.5 tests already using the lock continue to do so and call the new centralized reset helper.
