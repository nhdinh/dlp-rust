# Phase 58.5 Plan 01: Shared Unhook IPC and Audit Types Summary

**Added cooperative unhook protocol payloads (UnhookCommand, UnhookAck, PollControl, ControlResponse) and three SIEM-routed audit event types (AgentShutdownUnhook, WatchdogSelfUnload, UnhookFailure) to dlp-common.**

## Accomplishments

- Extended `IpcPayloadV1` with four new bincode-round-trippable variants for the agent-hosted polling unhook protocol.
- Added `UnhookReason`, `UnhookCommand`, `UnhookAck`, `PollControl`, and `ControlResponse` structs/enums with doc comments.
- Extended `EventType` with `AgentShutdownUnhook`, `WatchdogSelfUnload`, and `UnhookFailure`.
- Updated `routed_to_siem()` and `triggers_alert()` with correct semantics.
- Added 13 new unit tests covering bincode round-trip, discriminant index stability, SIEM routing, alert semantics, and JSON serde round-trip.
- Verified `cargo test -p dlp-common`, `cargo clippy -p dlp-common -- -D warnings`, and `cargo fmt --check -p dlp-common` all pass.

## Decisions Made

- Followed the plan exactly: appended new `IpcPayloadV1` variants after `HashEvidence` and added a regression test to lock existing discriminant indexes.
- `creation_time` was included in `PollControl` and `UnhookAck` per the plan's review concern to preserve the registry's PID-reuse-safe composite key.
- `UnhookFailure` triggers a real-time alert; the other two new event types do not, matching the plan's security semantics.

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed discriminant index regression test offset**
- **Found during:** Task 1 (existing_variant_indexes_unchanged test)
- **Issue:** The initial test asserted the first 4 bytes of the serialized envelope were the payload discriminant, but `IpcEnvelope::V1` itself serializes a u32 discriminant first, so the payload discriminant starts at byte 4.
- **Fix:** Updated the test to compare `&req_bytes[4..8]` and `&resp_bytes[4..8]` and clarified the comment.
- **Files modified:** `dlp-common/src/hook_ipc.rs`
- **Verification:** `cargo test -p dlp-common existing_variant_indexes_unchanged -- --nocapture` passes.
