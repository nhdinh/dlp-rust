<objective>
Implement the agent-side unhook orchestration using the polling protocol: on graceful shutdown, set a global `UNHOOK_ALL_REQUESTED` flag so the hook IPC server replies to incoming `PollControl` frames with `UnhookCommand`; route returning `UnhookAck` frames to update the `ProcessRegistry`; emit `AgentShutdownUnhook` and `UnhookFailure` audit events; and keep the total wait within the existing service shutdown budget.

Purpose: This is the agent-side orchestration of the cooperative unhook protocol. Because the agent hosts the named-pipe server and the hook DLL is the client, the agent cannot directly send commands to each injected process. The polling model reuses the existing pipe and lets every injected DLL discover the shutdown signal on its next poll.
Output: Extended agent service with registry accessors, PollControl/UnhookAck routing, audit wiring, and passing unit tests.
</objective>

    Addresses review concerns: shutdown timing must fit within the existing 10s budget, and audit events must be emitted.

    In `dlp-agent/src/service.rs`:
    - Define constants near `SHUTDOWN_TIMEOUT`:
      - `const UNHOOK_WAIT_BUDGET: Duration = Duration::from_secs(5);` — reserve 5s for DLLs to poll and ack
      - `const UNHOOK_POLL_INTERVAL: Duration = Duration::from_millis(100);` — how often to check registry during the wait
    - Add an async helper `async fn wait_for_unhook_acks(registry: &Arc<ProcessRegistry>, budget: Duration)` that:
      - Records the initial `iter_injected()` count
      - Loops, sleeping `UNHOOK_POLL_INTERVAL`, until `iter_injected()` is empty or the budget expires
      - Returns the remaining injected count
    - In `run_loop_shutdown`, insert the following block just before the "Phase 58: Stop hook IPC server" block (around line 3758):
      ```rust
      // Phase 58.5: Request cooperative unhook from all injected processes.
      if let Some(ref registry) = ctx.process_registry {
          let injected_before = registry.iter_injected().len();
          if injected_before > 0 {
              crate::password_stop::debug_log("run_loop: requesting unhook from injected processes");
              crate::audit_emitter::emit_unhook_audit(
                  &ctx.audit_ctx,
                  dlp_common::EventType::AgentShutdownUnhook,
                  std::process::id(),
                  true,
                  Some(format!("injected_count={}", injected_before)),
              );
              UNHOOK_ALL_REQUESTED.store(true, Ordering::Release);
              let remaining = wait_for_unhook_acks(registry, UNHOOK_WAIT_BUDGET).await;
              for (key, _) in registry.iter_injected() {
                  crate::audit_emitter::emit_unhook_audit(
                      &ctx.audit_ctx,
                      dlp_common::EventType::UnhookFailure,
                      key.pid,
                      false,
                      Some(format!("creation_time={}", key.creation_time)),
                  );
              }
              info!(remaining, "unhook wait complete");
          }
      }
      ```
    - After the hook IPC server is stopped, set `UNHOOK_ALL_REQUESTED.store(false, Ordering::Release)` so a future service restart starts clean.

    Add unit tests in `service.rs` `#[cfg(test)]` module:
    - `test_run_loop_shutdown_requests_unhook` — construct a minimal RunLoopContext with a registry containing one Injected entry and a mock audit capture sink, call run_loop_shutdown (or a test-exposed helper), assert UNHOOK_ALL_REQUESTED becomes true and AgentShutdownUnhook is emitted
    - `test_unhook_wait_emits_failure_for_remaining` — seed registry with an Injected entry that never acks, call wait_for_unhook_acks with a short budget, assert UnhookFailure is emitted for the remaining key

    Note: `run_loop_shutdown` is async and touches many subsystems; for unit tests, expose a test-only helper `async fn request_unhook_from_injected(registry: &Arc<ProcessRegistry>, audit_ctx: &EmitContext)` that contains only the unhook-orchestration logic.
