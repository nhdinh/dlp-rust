# Plan 39-02: UWP AUMID Resolution in dlp-user-ui

## Objective

Extend the existing app identity resolution pipeline in `dlp-user-ui` to detect UWP processes and resolve their AUMID using `GetApplicationUserModelId`.

## Background

The current pipeline in `dlp-user-ui/src/detection/app_identity.rs`:
1. `GetWindowThreadProcessId(hwnd)` → PID
2. `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` → handle
3. `QueryFullProcessImageNameW(handle)` → image path
4. `run_wintrust(image_path)` → publisher + signature_state

For UWP apps, the image path points to a proxy executable under `C:\Program Files\WindowsApps\`. The true identity is the AUMID. We detect UWP by the `WindowsApps` path prefix, then call `GetApplicationUserModelId` on the same process handle.

Add a new function `resolve_uwp_identity(process_handle: HANDLE, image_path: &str) -> Option<(String, String)>` after `build_app_identity_from_path`:

```rust
/// Detect UWP app by image path and resolve AUMID + PackageFamilyName.
/// Returns (aumid, package_family_name) if UWP, None otherwise.
fn resolve_uwp_identity(process_handle: HANDLE, image_path: &str) -> Option<(String, String)> {
    // Detection heuristic: path under WindowsApps
    if !image_path.to_lowercase().contains("\\windowsapps\\") {
        return None;
    }

    // SAFETY: GetApplicationUserModelId takes a valid process handle.
    // First call gets buffer size; second call fills the buffer.
    unsafe {
        let mut len: u32 = 0;
        let hr = GetApplicationUserModelId(process_handle, &mut len, PWSTR::null());
        if hr != windows::Win32::Foundation::ERROR_INSUFFICIENT_BUFFER.to_hresult() {
            return None;
        }

        let mut buf = vec![0u16; len as usize];
        let hr = GetApplicationUserModelId(process_handle, &mut len, PWSTR(buf.as_mut_ptr()));
        if hr.is_err() {
            return None;
        }

        let aumid = String::from_utf16_lossy(&buf[..len as usize - 1]);
        // PackageFamilyName is everything before '!'
        let pfn = aumid.split('!').next().unwrap_or(&aumid).to_string();
        Some((aumid, pfn))
    }
}
```
