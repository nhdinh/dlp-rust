# Plan 40-02: App Identity Resolution in dlp-agent

## Objective

Port the app identity resolution pipeline from `dlp-user-ui` to `dlp-agent` so drag-and-drop (and future file interception) can resolve source application identity.

## Background

`dlp-user-ui/src/detection/app_identity.rs` has a complete pipeline:
1. `GetWindowThreadProcessId(hwnd)` → PID
2. `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` → handle
3. `QueryFullProcessImageNameW(handle)` → image path
4. `WinVerifyTrust(image_path)` → publisher + signature_state
5. For UWP: `GetApplicationUserModelId(handle)` → aumid

The dlp-agent currently only has `get_application_metadata(pid)` in `audit_emitter.rs` which returns just the image path. We need a full `resolve_app_identity(hwnd)` equivalent.
