# Plan 40-03: DragDropEnforcer Core

## Objective

Implement the `DragDropEnforcer` module that intercepts drag-and-drop operations via a global message hook, extracts the source application identity, and evaluates whether the drop should be allowed.

## Background

The approach uses `SetWindowsHookEx` with `WH_GETMESSAGE` to intercept `WM_DROPFILES` messages. When a file drop is detected:
1. Extract the destination window handle from the message
2. Get the source window handle from the drag operation context
3. Resolve both applications' identities
4. Evaluate ABAC policy
5. Block if denied (by consuming the message), allow if permitted
