## Prerequisites Checklist

### Required for UAT Completion (MUST have all)

- [x] `dlp-server` running and reachable from the test endpoint
- [x] `dlp-agent` running and connected to the server
- [x] `DLP_ADMIN_JWT` environment variable set to a valid admin token
- [x] T4 policy configured and active (at least one T4-classified path with a DENY rule)
- [x] Protected Path configured (at least one T3 or T4 root registered in Protected Paths)
- [x] Real printer installed and visible to Windows (test page prints successfully)
- [ ] Physical USB removable drive (mass storage, any size)
- [x] EDR allowlist propagated (DLP binaries are excluded from AV/EDR quarantine)

### Required Only for Optional Tests (OK to skip if hardware unavailable)

- [ ] Cloud sync clients installed (OneDrive, Google Drive, Dropbox, or Box)
- [ ] Physical SD card and card reader
- [ ] Optical drive (CD/DVD/Blu-ray) with writable media
- [ ] Virtual drive mounted (VHD, VHDX, ISO via Explorer, or Daemon Tools)

Items in the "Required Only for Optional Tests" section are only needed if you
intend to run the corresponding optional test group. UAT can be considered
complete without them.

## Actual Column Format Guide

Use the following conventions when filling in the "Actual" column:

- For PASS results: describe the observed behaviour in one sentence (e.g.,
  "Upload blocked with `ERROR_ACCESS_DENIED` and audit event ID 1234 emitted").
- For FAIL results: include the exact error message, HRESULT, or NTSTATUS code,
  plus any relevant log excerpts.
- For SKIP results: state the reason (e.g., "No optical drive available").
- For N/A results: mark the row as not applicable and explain why.
- Include timestamps (QPC or wall-clock) for any latency-sensitive tests
  (HD-01, BM-01, BM-02).
- Reference specific log files or database rows when relevant
  (e.g., "`bypass_alerts` row 4567, `correlation_reason=NoHookJournal`").

## UAT Pass Criteria

UAT is considered PASSED when ALL of the following are true:

1. Every test case in Groups 1-5 and 7-8 shows Status = PASS with no FAILs.
2. Group 6 (Volume Class) may be skipped if optional hardware is unavailable;
   if hardware is available, all VC tests must PASS.
3. The CRIT-04 benchmark gate (BM-01 and BM-02) shows <= 25% wall-clock
   overhead versus the baseline measurement.
4. No `WerFault` event log entries name `dlp_hook_dll.dll` across the entire
   test session.
5. All audit events route to SIEM without error (verify via `siem_connector`
   logs).
6. The `DLP_ADMIN_JWT` token remains valid for the entire session; no 401
   Unauthorized responses from the admin API.

If any FAIL appears:

- Capture the full error output and log excerpts in the Notes column.
- Re-run the failing test case in isolation.
- If the failure is reproducible, file a blocking issue before signing off.

## Execution Summary

**Scripts executed:** pwsh (PowerShell Core 7.x) -- Windows PowerShell 5.1 failed to parse several scripts due to encoding/line-ending incompatibilities.

**Environment setup performed during session:**
- Created protected paths `C:\Protected\T4` (T4) and `C:\Protected\T3` (T3) via admin API
- Generated JWT token using dev secret `dlp-server-dev-secret-change-me`
- Converted all UAT scripts from LF to CRLF line endings

**Overall result:** 6 PASS / 8 FAIL / 20 SKIP (out of 34 test cases)

**Blockers for milestone sign-off:**
1. **CS-05** -- Share-link clipboard clearing fails for OneDrive (reproducible)
2. **HD-01 / HD-02** -- Hook DLL injection fails for new x64 and x86/WoW64 processes
3. **DT-01..DT-05** -- dlp-agent service hangs on stop; DACL tripwire tests cannot run
4. **ET-02 / NT-01** -- ETW bypass detection and ntdll patching tests fail due to API/runtime errors
5. **USB-01 / USB-02** -- No USB drive available (environmental, not a code defect)
6. **BM-01 / BM-02** -- Benchmark script has parse error preventing execution

**Recommendations:**
- Fix `Uat-Benchmark.ps1` parse error (line 85 unexpected `}`) and re-run CRIT-04 gate
- Investigate dlp-agent service stop hang before re-running DACL tripwire tests
- Investigate hook DLL injection latency/failure for new processes
- Fix `Uat-EtwNtdll.ps1` script compatibility with current agent config schema (`enable_ntdll_patching`, `correlation_reason` fields)
- Re-run full suite after blockers are resolved
