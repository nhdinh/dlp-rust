## Cross-Phase Integration Findings

### Blockers

1. **INT-BLOCK-01 — Hook DLL BypassAlert -> Agent Bypass Correlator**
   - `dlp-hook-dll/src/ntdll_patcher.rs` calls `emit_bypass_alert()`, but the function does not exist.
   - `dlp-common/src/hook_ipc.rs` shows `IpcPayloadV1` has no `BypassAlert` variant.
   - `dlp-agent/src/hook_ipc.rs:265` deserializes every frame as `HookRequest`, so any bypass-alert frame would be dropped.
   - **Affected:** ETW-03, ETW-04, ETW-05

2. **INT-BLOCK-02 — Volume Class Transmission -> ABAC Evaluator**
   - `dlp-hook-dll/src/trampolines.rs:357-371` discards `_source_volume_class` and `_destination_volume_class`.
   - `HookRequest` has no volume-class fields.
   - **Affected:** DRIVE-03, DRIVE-04

3. **INT-BLOCK-03 — Fail-Mode ISOLATED -> RESYNC Background Thread**
   - `dlp-hook-dll/src/background_thread.rs` implements the thread and polling loop.
   - Automatic `ISOLATED -> RESYNC` transition runtime behavior is unverified.
   - **Affected:** FAIL-01, FAIL-02, FAIL-03

### Warnings

1. **INT-WARN-01 — Bypass Correlator -> Enforcement Mode Gating**
   - `dlp-agent/src/bypass_correlator.rs` has no references to `global_enforcement_mode`.
   - Audit mode should suppress bypass alerts (`triggers_alert=false`), but correlator always emits alerts.
   - **Affected:** MODE-01

2. **INT-WARN-02 — ApprovalCache -> Hook IPC Enforcement Override**
   - `dlp-agent/src/hook_ipc.rs:334-345` has a TODO with commented-out approval override logic.
   - `ApprovalCache` is implemented but not consulted in the hook DLL decision path.
   - **Affected:** WORKFLOW-04 (v0.11.0, out of v0.10.0 scope)

### Verified Correct Wiring

- Admin TUI SystemMenu navigation to Protected Paths / Bypass Alerts / Audit Integrity.
- Bypass alert batch serialization between agent and server.
- DACL tripwire gating on monitor mode.
- Secrets encryption (HARD-01) wired into all new admin endpoints.
- Agent heartbeat -> policy sync -> enforcement mode propagation.
