## Cross-Phase Integration Findings

### Blockers

1. **INT-BLOCK-01 — Hook DLL BypassAlert -> Agent Bypass Correlator**
   - `dlp-hook-dll/src/ntdll_patcher.rs:630` emits `BypassAlert` over the named pipe.
   - `dlp-agent/src/hook_ipc.rs:265` deserializes every frame as `HookRequest`, so `BypassAlert` frames are dropped.
   - `dlp-common/src/hook_ipc.rs:75-92` shows `IpcPayloadV1` has no `BypassAlert` variant.
   - **Affected:** ETW-03, ETW-04, ETW-05

2. **INT-BLOCK-02 — Volume Class Transmission -> ABAC Evaluator**
   - `dlp-hook-dll/src/trampolines.rs:357-371` discards `_source_volume_class` and `_destination_volume_class`.
   - `dlp-common/src/hook_ipc.rs:95-116` shows `HookRequest` has no volume-class fields.
   - **Affected:** DRIVE-03, DRIVE-04

3. **INT-BLOCK-03 — Fail-Mode ISOLATED -> RESYNC Background Thread**
   - `dlp-hook-dll/src/background_thread.rs` implements the thread and polling loop.
   - Automatic `ISOLATED -> RESYNC` transition runtime behavior is unverified.
   - **Affected:** FAIL-01, FAIL-02, FAIL-03

### Warnings

1. **INT-WARN-01 — ApprovalCache -> Hook IPC Enforcement**
   - `dlp-agent/src/hook_ipc.rs:334-345` has a TODO with commented-out approval override logic.
   - `ApprovalCache` is implemented but not consulted in the hook DLL decision path.
   - **Affected:** WORKFLOW-04 (v0.11.0, out of v0.10.0 scope)

2. **INT-WARN-02 — Bypass Correlator -> Enforcement Mode Gating**
   - `dlp-agent/src/bypass_correlator.rs` does not read `global_enforcement_mode`.
   - **Affected:** MODE-01

3. **INT-WARN-03 — LabelService -> Agent File Classification**
   - `dlp-server/src/label_service.rs` exists but `dlp-agent` does not query it.
   - **Affected:** LABEL-01, LABEL-02, LABEL-03 (v0.11.0, out of v0.10.0 scope)

4. **INT-WARN-04 — DeviceHealth -> ABAC Subject Wiring**
   - Wiring is correct across 8+ call sites; recovery path from Tampered -> Healthy is unverified.
   - **Affected:** DEVICE-01, DEVICE-02, DEVICE-05 (v0.11.0, out of v0.10.0 scope)

5. **INT-WARN-05 — ChainBreakDetected -> Syslog Queue**
   - Queue insertion verified; drain-loop runtime confirmation needed.
   - **Affected:** SYSLOG-01, SYSLOG-02, TAMPER-03, TAMPER-04 (v0.11.0, out of v0.10.0 scope)
