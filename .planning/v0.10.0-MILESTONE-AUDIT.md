## Cross-Phase Integration Findings

### Blockers

#### 1. DIFF-02 — Diagnostic snapshots not pushed from hook DLL deny paths
- **Source phase:** 58 (Differentiators Bundle)
- **Consumer phase:** 48 (Hook DLL deny paths)
- **Evidence:** `dlp-hook-dll/src/diagnostic_ring.rs` exports `push_snapshot`; `dlp-hook-dll/src/trampolines.rs` deny branches in `classify_and_log_path` and `classify_and_log_handle` return `Some(DenyReturn)` without calling it.
- **Impact:** `PullDiagnostics` returns empty snapshots; Self-Health Dashboard and diagnostic history have no hook DLL data.

#### 2. DIFF-03 — SHA-256 content hashes not computed on blocked writes
- **Source phase:** 58 (Differentiators Bundle)
- **Consumer phase:** 48 (HookWriteFile / HookWriteFileEx deny branches)
- **Evidence:** `dlp-hook-dll/src/hash_compute.rs` exists; `dlp-hook-dll/src/trampolines.rs` write deny branches return `fail_closed!(BoolFalse)` without calling `compute_content_hash`. `dlp-common/src/hook_ipc.rs` `HookResponse` has no `content_sha256` field.
- **Impact:** Block events lack content evidence; cannot support forensic hash-based investigation.

#### 3. DIFF-04 — Health snapshots not emitted from hook DLL to agent
- **Source phase:** 58 (Differentiators Bundle) / 58.4
- **Consumer phase:** 50 (Fail-mode state machine) + agent health handler
- **Evidence:** `dlp-hook-dll/src/perf_telemetry.rs` has `emit_state_transition_immediate` but lacks `record_cache_hit`, `record_cache_miss`, `emit_health_snapshot`, and `send_health_snapshot` helpers specified in Phase 58.4 plans. `dlp-agent/src/service.rs` `health_handler` returns a default snapshot.
- **Impact:** Self-Health Dashboard shows stale/default counters; operational visibility into hook DLL health is missing.

### Warnings

#### 4. DRIVE-03/04 — Volume class missing from handle-based operations
- **Source phase:** 56.1
- **Consumer phase:** 48 `classify_and_log_handle`
- **Evidence:** `dlp-hook-dll/src/trampolines.rs` documents that `HandleHookRequest` lacks `source_volume_class` / `destination_volume_class`. Volume-class ABAC conditions evaluate against `None` for handle-based operations.
- **Impact:** Policies using volume-class conditions may not fire on handle-based file operations.

#### 5. HookReplaceFileW passes None for volume classes
- **Source phase:** 56.1 / 58.2
- **Consumer phase:** 48 `HookReplaceFileW`
- **Evidence:** `HookReplaceFileW` passes `None, None` for volume class parameters.
- **Impact:** REPLACE operations do not evaluate volume-class policies.
